## 以后

- 需要保留的中间产物，先写清楚"谁在什么条件下读它"，再决定留在盘上；**没有读者的二进制不算证据**。
- 任何删除脚本必须满足两条：① 删除前的候选清单**非空**且数量打印出来；② 谓词依赖的输入
  （比如这里的引用列表）先断言非空。这两条缺一条就不要执行删除。
