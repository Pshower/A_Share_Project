# 调仓控制器初始化强度研究协议

日期：2026-10-14。状态：训练前登记。实现与准入后冻结，运行结果另写报告，不事后改变本协议。

## 问题与边界

前一轮129维两动作控制器完成131,072 RL步：筛选没有改变确定性动作；确认只有2026 seed42跳过一次原定调仓，省费用但净收益降低。两确认折配对平均相对20日动量为-0.942373个百分点，没有胜出。因此本轮不认定初始化强度是唯一失败原因，也不认定更多探索必然更好。

本轮仅检验初始化距离是否影响可学习的调仓行为及扣成本收益。不同时改变网络、输入、奖励、持仓上限、执行机制或训练方法。若没有开发增量，停止本批确认，保留失败结果，再另行登记phase与市场交互研究。

## 唯一变量

比较 `calendar_margin` 为0.5、1.0、2.0。继续使用可训练线性Actor、64/64 Critic、12,805参数和标准SB3 categorical PPO。

三档确定性初始化都必须逐订单、现金、费用、股数与净值精确等于未修改的20日动量。仅Actor日历参数不同，Critic及其余Actor初始参数应一致；日历不是forward永久先验。margin2必须在本轮重新实际训练，旧结果只用于复现核对，不能充作本轮样本。

初始优选动作概率分别为sigmoid(0.5)、sigmoid(1)、sigmoid(2)，约62.25%、73.11%、88.08%；随机训练中的非基线动作概率相应约37.75%、26.89%、11.92%。降低margin会改变真实探索、成交和费用，不是免费提高学习能力。

## 共同设置

继承[原调仓协议](ppo_timing_protocol_20261014.md)的数据、129维因果输入、两独立账户、固定M20股票选择与数量、HOLD/REBALANCE两动作、240步episode和48种起始分层。使用现有新浪300股20特征数据及各自训练截止前scaler，不下载行情。

资本、Broker、冻结、T+1、整手、K20、佣金与滑点不变；基线仍为未修改的20日动量，不选择更弱基线。评价初始cash/equal/concentrated/random四账户，与真实初始股数和现金匹配。

固定log_net奖励、gamma=.995、LR3e-4、n_steps512、batch128、epochs5、GAE.95、clip.2、targetKL.03、ent0、vf.5、gradclip.5，CPU单线程、最多两worker。只评价注册预算终点，不挑早期checkpoint。

## 筛选与准入

2023/2024 Q2各训练三档margin，seed42、每trial8,192步，共六trial、49,152 Agent RL步。对应独立基线推进另计49,152步，不伪称额外RL。所有筛选trial完成并封存后才选择。

按最差折四账户平均基线差、两折平均差、最坏账户回撤、总费用加滑点依次排序；完全平局优先更大的margin。不得依据某账户、某早期快照或幸运样本改规则。

选中margin只有同时满足以下条件才进入本批确认：

- 两开发折的四账户平均净ROI基线差分别至少0.0001，即0.01个百分点。
- 至少一折的终点评价有真实确定性宏动作变化及不同经济账本，而非浮点误差或仅参数变化。

这只是节约无增量配置的确认开销，不是胜出证明。未准入则记录screen_failed，确认实际trial和RL步为0，不补挑排名第二配置；进入下一项研究时另行登记。

## 条件确认

若准入，固定选中margin和所有共同参数，在2025/2026 Q2各自从头训练seed42/123/2026，每trial16,384步，共六trial、98,304 Agent RL步，独立基线步单列。本批最高十二trial、147,456 Agent RL步；未准入只有六trial、49,152步。以实际计数为准。

每确认折先平均每seed四账户，再汇总三seed。胜出标准与原协议不变：每折平均基线差为正、至少2/3 seed为正、两折平均优势至少0.5个百分点、自身初始化增量为正，最坏账户回撤不超过10%且相对基线恶化不超过2个百分点。全部条件同时满足才视为候选。

所有Q2历史窗口已有研究曝光，只是本轮选择未使用的时间确认，不是从未见过的盲测。2026-07-01以后的保护期不参与绩效或特征观察。HFQ模拟与固定历史成分股限制不因研究胜出而消失，不自动部署真实账户。
