# 等权溢价的指数对照：一次自我更正

日期：2026-11-08
状态：**这条更正推翻主报告的一个主要结论**。

关联：[全市场 CAPM 检验](capm_full_market_20261108.md)、[实施进度](implementation_plan.md)
工具：`tools/equal_weight_crosscheck.py`；产物：`reports/runs/equal_weight_crosscheck/`

---

## 1. 怎么发现的

起因是一个与本研究无关的问题：找有没有能拟合 1/N 的 ETF。为此抓了几个等权指数的历史，
其中 `000982`（中证 500 等权）有完整的 2019-2024 数据。

把它和同一个指数的市值加权版本 `000905` 放在一起看，得到 **+0.59pp/年**。
而主报告里自建面板给出的等权溢价是 **+3.99pp/年**（全市场）甚至 **+7.92pp/年**（同一档位）。

**差了 7 到 13 倍。** 这个差距不能放着不管。

## 2. 对照设计

三个条件同时满足才能算真正的对照：

| 条件 | 满足方式 |
| --- | --- |
| 成分相同 | `000905` 与 `000982` 覆盖同一批 500 只成分股，只差加权方式 |
| 无选样偏差 | 指数是**实时计算**的，历史里含当时成分，成分走了就换 |
| 区间相同 | 2019-01-02 ~ 2024-12-31，1,455 个共同交易日 |

面板一侧用同样的档位（按中位流通市值排名的第 301–800 名，500 只）构造市值加权与等权两个组合。

## 3. 结果

| 档位 | 面板市值加权 | 面板等权 | **面板溢价** | 指数市值加权 | 指数等权 | **指数溢价** | 判定 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 中证500 档 | +7.40% | +15.32% | **+7.92pp** | +5.60% | +6.19% | **+0.59pp** | **不成立** |

差值 **+7.33pp**，容差设 1pp，判为 `unsupported`。

**注意市值加权那一列只差 +1.80pp**——那基本等于股息率（面板用 `hfq` 复权价，指数是价格指数不含息）。
**也就是说同一个面板，市值加权版本几乎精确复现了指数，等权版本却高出 9 个点。**

## 4. 机制：等权拿到的是算术平均

| 量 | 值 |
| --- | ---: |
| 横截面日均收益的平均（等权的日收益就是这个） | **+15.36%** |
| 个股买入持有中位数 | **+6.50%** |
| 个股买入持有平均 | +7.74% |
| **组合年化波动** | **21.2%** |
| **个股中位年化波动** | **41.4%** |

差额 **8.86pp**，而 σ²/2 = 0.414²/2 = **8.56pp**——**这就是方差拖累**。

单只股票波动 41%，扣掉 σ²/2 之后只剩 6.5%；组合波动只有 21%，只扣 2.2%。
**等权组合的收益 ≈ 个股日收益的算术平均，而不是个股收益的中位数。**

这一步是真的：`equal_weight_portfolio` 的日收益确实就是横截面均值，月频再平衡给 14.97%，
日频给 15.36%，两者一致——**构造没有多算**。

## 5. 排除掉的替代解释

| 假设 | 检验 | 结果 |
| --- | --- | --- |
| 档位选错了 | HS300 档 / CSI500 档 / CSI1000 档 / 小盘尾 **四档分别测** | **+6.96 / +7.92 / +7.79 / +7.88pp**，与档位无关 → **排除** |
| 缺失数据（停牌、退市） | 只保留全期完整数据的股票重测 | 档内本无缺失，**数字完全不变** → **排除** |
| 分红口径 | 市值加权只差 1.80pp，约等于股息率 | 能解释 2pp，**解释不了 9pp** |

三个都排除后，剩下的方向只有一个：

> **市值加权把权重压在「今天最大的几只」上，而这几只大概率 2019 年就已经很大；
> 等权把 0.2% 摊到每一只，因此最大程度暴露在「这支股票今天还在这个档里」这个筛选条件上。**

“今天还在中证500档” = 六年里没崩、没退市、没被挤出。**面板按当前市值选股，等于把这个筛选写进了宇宙。**
市值加权只吃到这个偏差的一小部分，等权全吃。

**这和 1/N 的结构有关**：它给每只股票同样的权重，所以**对「谁在池子里」最敏感**。
一个策略如果必须靠“幸存者池”才成立，那它的优势就不能算作策略本身的性质。

## 6. 不能主张的（关于这次更正的边界）

1. **我没有直接证明**是选样偏差造成的。我只有**排除法 + 方向 + 跨档一致性**。
   直接证明需要历史成分股名单，用它重建组合会重新引入同一偏差（今天列出的成分本身就是幸存者）。
2. **全市场的等权溢价仍然未知**。能用的无偏等权指数只有 000982 这一条（500 只中盘）；
   沪深 300 等权（000984）在新浪源上 2021-02-04 就断了，中证 2000（932000）404。
   **所以只能说“中证500 档的无偏等权溢价是 +0.59pp”，不能说“全市场是 0.59pp”。**
3. **0.59pp 是毛额**。指数点位不含再平衡成本；按实测换手 0.53 倍、31bp 往返，净额约 **+0.4pp**。
4. **样本仍是一个 6 年窗口、一个市场。** 这 0.59pp 也不是什么长期常数。

**对本项目方向的影响**：`1/N 做 beta 底座` 的建议**不变**，但它的正当性现在**完全**来自
DeMiguel 那条（估计误差下的稳健性），**不来自收益**。这反而是更稳的理由——因为它不依赖一个 6 年样本的符号。

## 8. 方法教训

这次错误不是算错，是**缺了一个外部校验**。

自建组合与自建组合比较，会同时继承两边的同一偏差，**看起来像内部一致，实际上是在自我确认**。
唯一能证伪的是**第三方计算的、不共享同一选样过程的序列**——指数。

所以下一节把它做成回归测试：**任何“等权 vs 市值加权”的面板结论，必须同时报出同档指数对照，
否则不允许进入结论。**
