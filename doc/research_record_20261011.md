# A 股日频强化学习交易研究记录

更新日期：2026-10-11。研究范围：2026-09-25 至 2026-10-11 已完成的训练、回测、架构改进与机制对照。

## 研究目标与主要结论

目标是在每日收盘后，根据所选股票池的历史行情、当前账户和交易可用性，生成下一交易阶段的保持、买入、减仓或退出请求。模型不能只输出抽象配置，还需要经过资金、股数、冻结持仓、T+1、整手和成本约束，形成可核验的账户变化。

目前已经完成本地数据加工、共享股票 Actor/Critic、PPO 训练、模拟成交、回测、模型持久化与研究审计。研究从目标权重逐步转向股票增量、明确交易方向及独立的买入优先级，并引入仅训练期使用的收益排序辅助任务。

现有结果支持继续研究行情与账户分离、数量与排序解耦，但还没有获得通过最新跨年度门槛的每日实盘配置模型。最新二乘二实验中，独立优先级、普通 PPO、8,192 步配置的跨折平均净收益为 **+1.1904%**，种子样本标准差为 **3.2714 个百分点**；相对同轮共享排序 PPO 改善 **2.2565 个百分点**，但风险和跨年度学习增量不合格。它不是全部历史研究的统一“冠军”，也不是预期实盘收益。

### 复权与执行价格口径

`data/raw` 中的“原始文件”指进入仓库的采集文件，不等于未经复权的交易所报价。现有主要实验使用后复权行情构造特征；成交和估值读取独立、未标准化的价格表，但该表仍为 HFQ 研究报价。

**未标准化与不复权是两个不同概念。** 逆 Z-score 只能还原相应特征，不能取消复权。HFQ 价格与 100 股整手共同影响购买力、现金留存和容量检查，因此当前回测是 `hfq_research` 经济代理，不能解释为真实成交收益。全股票池同源不复权报价、权威公司行为与历史交易状态尚未形成完整实际成交链路。

## 数据处理方法

### 清洗与版本化

处理顺序为：股票名单校验、唯一来源选择、日期与代码检查、OHLCV 质量检查、历史特征计算、训练期标准化、宽面板及掩码生成。

代码必须是唯一的六位字符串；每股必须匹配唯一 HFQ 文件。重复 `(date, code)`、来源歧义和代码不一致会阻断构建。日期按时间排序，非有限值和不合理负值按规则标记缺失，并检查正价格与 OHLC 关系。无效完整行情不能生成有效特征，但独立有效的开盘报价不会仅因收盘缺失而被删除。

早期首只股票重复、混入不复权序列的问题已经修复，并使用现有原文件离线重建。重建汇总由 622,381 行变为 622,246 行，实际末日为 2026-06-26；旧文件名中的年份不是数据真实日期的证据。

输出包括 `panel_data.parquet`、`prices.parquet`、`valid_mask.parquet`、`source_mask.parquet`、`scaler_params.json`、`source_audit.csv`、`quality.csv` 和 `manifest.json`。已有数据版本与实验目录拒绝覆盖，保存股票、特征顺序和原文件 SHA。

证据：[预处理实现](../src/data/preprocess.py)、[实施记录](implementation_plan.md)。

### 当前二十项特征

令 `C`、`O`、`H`、`L` 分别为后复权收盘、开盘、最高、最低价，`V` 为统一股数成交量。所有特征仅使用决策日及以前的数据。

| 特征 | 实际定义 |
| --- | --- |
| `return`、`log_return` | `C[t]/C[t-1]-1`；`log(C[t]/C[t-1])` |
| `range_ratio`、`body_ratio` | `(H-L)/C[t-1]`；`(C-O)/O` |
| `volume_ratio`、`turnover` | `V/MA20(V)`；来源换手率百分数 |
| `rsi_14` | 14 日平均上涨量 / 平均上涨与下跌量之和，范围按比例表达，不乘 100；分母为零时取 0.5 |
| `macd_ratio`、`macd_signal_ratio` | `(EMA12(C)-EMA26(C))/C`；该差值的 EMA9 除以 C |
| `bb_position` | `(C-MA20(C)+2*STD20(C))/(4*STD20(C))`；零波动时取 0.5，不保证总在 0 至 1 内 |
| `momentum_5/10/20/60` | 各窗口 `C[t]/C[t-w]-1`，共四项 |
| `close_ma_ratio_5/10/20/60` | `C/MAw(C)-1`，共四项 |
| `volatility_20/60` | 日收益的 20/60 日滚动标准差，`ddof=0` |

基础特征为相对收益、趋势、波动和量价状态，不直接把股票代码或绝对收盘价当作预测特征。研究使用的是这 20 项；工作台支持追加白名单指标不代表财务、新闻、行业排名或分钟数据已经进入这些正式实验。

### 标准化与缺失值

每项特征使用共享 Z-score：`z=(x-mean)/std`。均值、标准差只由配置训练股票及训练截止前的完整股日拟合，`ddof=0`，近零标准差替换为 1。它不是每股分别拟合的 scaler；验证和推理只应用训练 scaler，不重新拟合。

旧 298 股版本拟合 314,172 个完整股日，19 股版本拟合 24,099 个，新浪全版本截至 2026-03-31 拟合 572,322 个。后期历史折重新使用对应训练截止前的样本拟合，不能拿 2026 年 scaler 直接当作早期折的训练 scaler。最新排序研究复用已封存的折 scaler，不再重拟合。

特征面板保留 NaN，不前后向填充。送入神经网络时将不可用数值填零，同时保留有效性掩码；零只是输入占位，不代表真实零收益。历史收盘前向填充仅用于已有资产估值，不据此开放交易。日期轴是本地行情日期并集，不是权威交易所日历；最新对照统一使用过去五日完整特征掩码。

模型动作是权重、增量或交易请求，不是标准化价格预测，所以不需要对动作“逆标准化”。股数换算和模拟成交始终读取独立价格表。

## 模型设计

### 输入与共享股票结构

典型行情输入为 `stock_features[B,N,L,F]`，当前主要研究 `F=20`、`L=1`。L=1 是最新一组历史指标，不等于只含一天信息；指标包含 60 期回看，`momentum_60` 和 `volatility_60` 至少需要 61 个收盘观测。L=5 实验展开历史轴输入 MLP，没有使用 GRU 或 RNN。

账户输入包括股票及现金权重、应收比例、有效与买卖掩码。后期还加入一手市值占净值、可卖权重、冻结标志、精确总股份与可卖股份、合法整手区间、方向权限、topN 和剩余名额。未知的下一日执行价、停牌或限价行情不进入当前观测；已知的 T+1 和锁定到期信息可以用于推算下一执行日可卖股数。

每只股票复用同一编码器和交易头，没有按股票代码单独设置神经网络参数。组合摘要使个股决策可以结合整个股票池和账户。结构的置换性质及参数共享不等于已证明未见股票有效；已保存实例的空间、顺序、来源和 scaler 固定，不能直接更换池规模。旧模型须显式迁移，新 priority 模型目前拒绝跨契约迁移。

### 架构与动作演进

| 阶段 | 网络输出与执行语义 | 已发现的主要问题 |
| --- | --- | --- |
| 目标权重 | N 个股票分数加现金分数的 Gaussian latent，经掩码、softmax 和单股上限得到目标权重 | 重复同权重仍可能再平衡，没有真正独立“不下单”；整手与现金投影改变请求 |
| 股票增量 | N 个受状态掩码约束的 Gaussian，`0.05*tanh(a)` 申请市值比例增量；现金为剩余 | 确定性增量常接近零；买入整手和微额卖出不对称 |
| 整手交易 | 2N 存储方向与条件数量；HOLD、BUY、REDUCE、EXIT；BUY 数量 latent 同时参与排序 | 可明确保持股数和退出，但稠密请求大量被资金/名额过滤，数量上尾影响选股 |
| 数量与优先级分离 | 3N 存储方向、条件 quantity、BUY priority；独立 priority Normal 或 quantity 拷贝对照 | 训练噪声选择偏差减小，但确定性均值仍高度相关，尚非预算感知稀疏 selector |

HOLD 保留股数，而不是强行保留权重；价格变化仍会改变持仓比例。EXIT 仅在下一执行日全部持仓可售时申请完整退出，部分可售只能 REDUCE，不能绕过 T+1 或冻结。后期 topN 约束新开仓名额，已有超 K 持仓不会被强制清掉，冻结资产仍占位，所以实际持仓数可以超过 K。最终实际持仓由请求映射和 Broker 成交决定，**不是神经网络直接预测出来的下一持仓**。

初始 `SharedStockNetwork` 将行情和持仓标志一起编码，市场摘要会随账户变化。后来的 `SplitTradeNetwork` 使用纯行情 encoder 和独立账户 encoder：行情 `L*F→256→128`，账户 11 维映射到 128 维，经 `tanh(m+a)` 融合；纯市场均值 128 维、持仓汇总 128 维、现金、应收和七维配置组成 265 维 context。股票 body 接收 393 维输入，输出方向、数量和后来的优先级；Critic 从 context 估计价值。

同参数归因研究对比纯行情/融合摘要与 Critic 特征梯度 shared/detached。detached 只截断 Critic 到特征的梯度，不删除 Critic，也不是改成独立模型。摘要研究对比 mean、单 learnable query attention 和 variance 残差，零初始化新增分支以保持相同初始函数。

早期框架默认共享 MLP 为 128/64；10 月 3 日容量矩阵对比 256/128 与 2048/1024，最新 Split/priority 使用 256/128。20 特征、相应研究设置下，容量矩阵目标权重小/大模型为 **155,525/9,501,701** 参数；增量 **124,547**；整手 **126,343**；Split **125,063**；摘要三臂总参数 **141,575**；最新 priority **125,322**。总参数相同不等于有效容量相同：最新四格活跃 Adam 张量数为 **17/19/20/22**。

代码证据：[初版 Policy](../src/agents/ppo_policy.py)、[增量 Policy](../src/agents/delta_policy.py)、[整手 Policy](../src/agents/trade_policy.py)、[行情账户分离](../src/agents/exploration_policy.py)、[摘要网络](../src/agents/market_summary_policy.py)、[Priority Policy](../src/agents/priority_policy.py)。

### Actor 与 Critic

Actor 输出请求概率分布。训练时采样，确定性评价时取类别 argmax 和连续均值。2N/3N 动作不是全坐标独立 Gaussian：方向是 categorical，数量和优先级有条件 Normal，也包含 HOLD、EXIT、固定 REDUCE 的零原子及 coupled 的拷贝原子。

PPO 保存原始采样动作和 old logP，以该动作计算概率比。不能拿裁剪、映射或成交后的数量替代原动作；联合 logP 精确求和，不按股票数平均。KL 约束请求概率分布变化，不是持仓变化罚项，同一持仓也可能由不同请求分布产生。

每个 trial 独立训练自己的 Actor 和 Critic，只在模型内部共享编码。Critic 估计当前策略的折扣未来组合回报，不逐笔给买卖订单打分。历史模拟产生本次轨迹的奖励，但不能给出所有状态、所有未来策略的价值；Critic 的训练目标还含末端 bootstrap 和 GAE 估计。

## 训练方法

### 奖励与 PPO 更新

日频流程为 t 日收盘观察和决策、t+1 开盘尝试成交、t+1 收盘估值。奖励保持为扣成本后的组合净值收益。下式示意非终止的连续转移；实际 GAE 包含终止/reset 掩码和 TimeLimit 修正：

```text
reward[t] = equity[t+1] / equity[t] - 1
delta[t] = reward[t] + gamma * V(next_state) - V(state)
advantage[t] = delta[t] + gamma * lambda * advantage[t+1]
critic_return_target = advantage + old_value
ratio = exp(new_logP - old_logP)
```

真实终止时后续价值为零，优势不跨越 reset；时间上限截断使用 `terminal_observation` 的价值做 bootstrap，而不是读取重置后账户的价值。PPO 使用 clipped surrogate、价值 MSE、熵项、KL 检查和全局梯度裁剪更新 Actor/Critic。日奖励不等于只优化次日，因为折扣回报与 GAE 汇总后续轨迹。成本已经进入净值，只扣一次；没有额外微单处罚或明确回撤奖励。10% 回撤是后期候选门槛，不是 Critic 自动施加的惩罚。

核心使用 PyTorch 与 Stable-Baselines3 PPO，最新辅助 subclass 基于本机 SB3 2.7.1 train 流程。旧 CPU 环境 `Graduate` 保留，后续研究在 `AShareGPU` 运行，PyTorch 2.7.1+cu126。最新正式实验使用 CUDA，不能把早期小模型 CPU 测速结论推广到所有容量和 batch。

### 初始化与训练经历

早期 R1 为持续动量先验：根据最新 `momentum_20` 对有效可买股票排序，神经网络学习小幅残差。Actor 尾层零初始化，但先验每次决策都会使用，不是只在训练开始作用一次。随机矩阵同时去掉先验、改变 Actor 初始化和残差限制，不能把全部差异仅归因为随机初始化。

后期不再使用持续动量先验，采用较小 Actor gain、条件随机数量与优先级。训练不是都从零持仓开始：包括 cash、equal、concentrated 和 random 四类已结算初始账户，随机账户使用 Dirichlet 权重和不同股票敞口；初始配置受单股上限与整手约束，现金是剩余部分，初始持仓不额外收取历史建仓费。

训练长度也按轮次改变：10 月 3 日先验/随机矩阵及 10 月 4 日增量为 8,192/65,536 步；10 月 5 日整手为 8,192/32,768；10 月 6 日探索与 10 月 7 日摘要为 2,048/8,192；同参数归因为 2,048/4,096；最新为 8,192/16,384。这些短快照均是同一长轨迹前缀，不是分别从头训练。9 月 27 日旧 19 股容量测速与 10 月 3 日新浪 300 股容量矩阵是不同研究。

每个 256 步 episode 内连续持仓向未来推进；结束后重新抽取历史起点和账户，网络参数继续学习。相同历史可因不同日期、初始组合、topN、随机动作和策略产生不同经历，但不会创造新的独立行情。最新日期、账户类别、具体账户与 K 随机流分离；64 个长训练片段中四类各 16 个，近期窗口与账户组合未分层均匀，近期 cash 只有 1 至 3 个片段/seed。

已有训练还探索了季度均衡采样、L=5、log-net reward、gamma=0.995 和数量噪声退火；部分仅为单种子 pilot，不能写成已通过多种子确认的当前默认方法。

### 最新固定超参数与辅助任务

| 项目 | 2026-10-11 正式设置 |
| --- | --- |
| 折与种子 | 2023/2024，42/123/2026 |
| 设计与预算 | 动作耦合/解耦 × PPO/rank辅助，24 trial；8,192/16,384 共享前缀 |
| 网络与初始化 | hidden 256/128，125,322 总参数，Actor gain 0.1，quantity/priority log_std=-0.7 |
| PPO | LR=3e-5，n_steps=512，batch=128，epochs=5 |
| 回报与约束 | gamma=0.99，GAE lambda=0.95，clip=0.2，targetKL=0.03 |
| 损失与执行 | entropy_coef=0，vf_coef=0.5，max_grad_norm=0.5，CUDA，torch_threads=1 |
| 状态覆盖 | 256 步 episode，四账户，recent_every=4；训练 K=10/20/40，主评价 K=20 |
| 辅助学习 | lambda_rank=0.05，Huber delta=0.1；每接受的联合 Adam 抽 1,024 个训练股日 |

辅助 signal head 只读取单股 market encoder，不读取账户或同日市场摘要，学习给定单股特征的期望相对排名。它不是完整的动态截面建模，也不直接成为交易先验。独立 NumPy RNG 在 KL 检查通过后抽样，不消耗 PPO、日期或账户随机流。

```text
loss = PPO_clipped_loss + vf_coef * value_MSE + entropy_term
       + lambda_rank * rank_Huber
```

本轮实际 **393,216 RL 步、1,536 episode、15,360 次 joint Adam**，其中 **7,680 次含辅助任务**；**7,864,320 次监督股日曝光**不计作新行情、RL 步或额外 optimizer。48 快照的步数和 589,824 包含 196,608 短前缀，不重复算训练。每 trial 的训练、保存与诊断计时约 1,232 至 1,377 秒；累计不是双 worker 墙钟时间。

## 测评方法

回测比较持有、等权、动量、未训练初始化和训练模型，保存每日净值、股数、现金、订单、费用与滑点。评价指标包括累计/年化收益、波动、Sharpe、最大回撤、换手、成本与现金比例，不能仅用训练 loss、Critic MSE 或辅助 rank loss 判断交易模型优劣。

最新统一模拟资本为 100 万元、佣金 0.0003/最低 5 元、卖税 0.0005、滑点 0.001、成交量参与率 0.01、100 股单位、单股及 BUY/REDUCE 单步名义额 5%。非完整退出的经济门槛来自最低费用与佣金比例约束；冻结持仓占用资金和名额。该固定制度只保证内部数学一致，并非逐历史日期税费、各板块最小单位或真实成交容量的完整恢复。

最新评价先平均每 seed 四种账户，再平均同 seed 两折，最后求三 seed 均值和 `ddof=1` 样本标准差。账户、折与共享前缀快照不是额外独立种子。还报告自身初始化增量、动作与方法主效应、简单效应、交互和短长差异。

最新候选须在两个折均满足：最坏账户回撤不超过 10%、自身初始化增量平均为正且至少 2/3 seed 正、平均 ROI 超过同执行机制 20 日动量。代表模型固定为 2024/seed42，不挑最赚钱 seed。

必须分清三种状态：**观察最高**是本窗口统计排序；**研究 qualified**按当轮门槛判断；**部署**需要另外的实际运行与账户证据。9 月 R1 的门槛、10 月 6 日每日动量门槛和后来两折 20 日动量门槛不同，不能回填成一个统一资格。目标权重动量与整手 `EconomicRule` 即使同名，机会集和请求机制也不同。研究报告不自动晋升默认模型，本记录不推断用户当前手动选择的工作台模型。

以下按四账户、同 seed 两折、三 seed 的层次聚合，ROI 为百分数，SD 为百分点；不是显著性保证。

| 配置 | 8,192 步平均净 ROI ± SD | 16,384 步平均净 ROI ± SD |
| --- | ---: | ---: |
| coupled PPO | -1.066099 ± 1.160042 | -1.161539 ± 1.895211 |
| coupled rank_aux | -1.219838 ± 1.412212 | -0.588144 ± 1.840187 |
| decoupled PPO | +1.190440 ± 3.271436 | -0.608901 ± 1.643927 |
| decoupled rank_aux | +0.881897 ± 2.742447 | -0.548201 ± 1.505629 |

动作主效应短/长为 +2.179137/+0.296290 个百分点；辅助方法主效应为 -0.231141/+0.317047 个百分点。辅助任务在 2023 长预算组改善，在 2024 退步。普通 decoupled PPO 加长平均下降 1.799341 个百分点，三 seed 均下降；更多训练不等于更高收益。

所有八配置在 2023 的最坏回撤超过 10%，在 2024 的平均自身初始化增量为负。固定代表 2024/seed42 的最佳均值配置实际为 -3.335610%，不能以配置均值替代单个模型效果。

训练时 coupled 数量与优先级相关为 1，decoupled 约 0.0015，随机数量上尾的优先偏差明显减小。但确定性部署的同日相关仍为 0.9449 至 0.9706，不能称推理完全解耦。192 条模型评价路径中，2,036,389 个原始 BUY 请求最终形成 82,344 次 BUY 成交，约 4.04%；资金与名额投影仍主导，Broker 后高成交率不表示动作瓶颈已解决。

## 验证与研究限制

最新完成 264 条固定评价路径、15,576 个评价步。最终离线回归 **1,293 通过、13 联网排除、11 既有警告**；独立审计核验 24 原生试验、标签边界、统计、1032 个 NPZ 和 72 个模型 ZIP，70,728 个归档成员 CRC 全部通过。这证明实现和证据内部一致，不证明现实盈利。

最新研究曾出现一份轨迹的读取 SHA/CRC 异常，之后原路径在没有人为改写的情况下恢复为已登记原 SHA，缓存及绕过缓存读取一致。根因未知；没有当时损坏 raw 的现场备份，保留的是明确标注的事后精确重建变体。两 worker 退出后只透明更正两处旧哈希登记，原轨迹和模型写入为零；凭据的路径标签错误另以 sidecar 勘误，原凭据保留。完整历程见 [最新报告](reports/ppo_priority_rank_20261011.md)，不称硬件问题已修复。

[独立最终审计](../reports/runs/ppo_priority_rank_20261011_16k/final_audit.json) SHA256：`89bc5f465eada6a845812b9f538886fc510dfcaecd392e54100b3f1f93379ce2`。这是最新实验冻结机器证据的签章，不是本综合记录或全部旧实验的统一签章。

还需保留的限制包括：固定未来股票名单、未做真正未见股票留出、反复曝光历史窗口、少量种子、HFQ 股数与价格经济代理、历史公司行为及交易制度缺口。原生 logP 审计验证有限性、合法支持、来源和前缀；未保存所有旧网络参数，不能声称每步旧神经密度都被重新计算。

## 结论与后续方向

现有研究建立了从数据到策略、从请求到成交、从训练到审计的可复核框架。主要经验是：共享股票结构提供参数复用能力，纯行情摘要降低账户对市场表征的混入；独立优先级改善了部分同轮比较；持续先验、更多步数、更多参数或辅助损失都不能自动等同于学习优势。

下一轮优先检验无放回、预算和名额感知的稀疏 selector，让可行交易参与选择而非先生成大量请求再过滤；对比加入同日市场摘要条件的辅助头及分层时间与账户调度。风险目标、真实未复权成交和公司行为账本应分别建立对照。GRU、BC 和这些 selector 尚未实现，不能与已经实现的单股 rank 辅助任务混为一谈。

训练、研究记录和工程验收已完成，不代表每日真实账户配置目标已经完成。当前模型只适合历史开发研究，收益结论需要在新的时间及股票留出、实际执行数据和成本压力条件下重新验证。
