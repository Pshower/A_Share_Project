## 文档规范

1. **命名**：`主题_YYYYMMDD.md`，日期是写下结论的那天，不是研究的起始日。
2. **首段三行**：标题、`日期：…。状态：…`、一条能复现的工具或数据。
3. **结论前置**：第一节必须是「结论」，数字要带口径（样本区间、频率、是否含成本）。
4. **更正不改写历史**：发现错误时在原文顶部加「更正」，写清旧值、新值、原因；不要直接改掉正文数字。
5. **归档**：一条研究线关闭时，报告移进 `doc/archive/`（同时改写链接），索引里保留一行描述——归档是证据，不是垃圾。
6. **检查**：动过文档就跑 `python -B -m tools.doc_lint`（断链、缺标题、指向已删工具、未入索引）。
