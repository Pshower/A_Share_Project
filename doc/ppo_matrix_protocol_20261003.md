# 股票配置智能体二乘二实验协议

2026-10-03。用户要求在不增加原始行情的情况下，扩充训练经历和网络容量，比较短步数与长步数、小模型与大模型的组合。本轮解释“长部署”为长训练步数。

## 数据与比较范围

沿用已下载新浪300股和 `sina_hs300_study_20260927`，保留原scaler、股票顺序及HFQ模拟交易设置。训练仅截至2026-03-31；2026-04至06月60个交易步用于开发比较。这个窗口此前已经使用过，结果不得称为独立最终测试。2026-07之后保持隔离。

四格均采用R1的20日动量排序先验、最多20只配置、单票5%上限、初始log_std=-3、先验强度4、残差幅度0.25。除网络宽度和训练预算外，PPO学习率1e-5、每次采集512步、batch128、每次最多5轮更新、gamma0.99、GAE lambda0.95及KL保护一致。

## 容量与预算选择

小网络使用现有R1的256/128，约15.55万参数。大模型在实际新浪300股训练输入上逐进程做容量试跑，候选1024/512、2048/1024、4096/2048；先测小模型作为速度基准。每次容量试跑最多512步，单独记录实际步数、显存峰值和耗时，不计入正式矩阵表现。

大模型选本轮候选中完整运行且满足显存余量的最大模型，显存峰值reserved须低于初始可用显存的85%及总显存75%的较小值。若候选中出现OOM，记录失败，不将未完成试跑称为通过。

短预算固定8192步。长预算在32768、65536、131072步中，按容量试跑吞吐预估选择单轮约8小时计算规划内最大的预算，并预留评估时间；所有选择在读取正式比较成绩之前固定。如果最小长预算仍超出规划，记录预估并保留最小长预算，不根据收益提前停止或缩小已登记预算。训练步数没有数学意义上的最大值，本轮采用明确上限以完成可比较的实验。

每格使用42、123、2026三个种子。相同模型和种子从头训练到长预算，在8192步更新完成后保存短预算快照；因此长短两格具有完全相同的训练前缀。共训练两种容量乘三个种子，短快照已包含在长预算内，避免额外重复训练。

## 经历多样性与诊断

每段最多256个交易步，沿用cash/equal/concentrated/random四种初始账户和随机历史起点；每四段有一段靠近训练末端，以覆盖晚上市股票。账户在段内延续，段结束后重置账户与日期，网络参数继续学习。

新增独立审计包装器，记录实际初始持仓、现金、起点、账户哈希与初始状态哈希，统计独特账户、独特初始状态、实际日期覆盖及各账户模式步数。自动reset后尚未执行的账户不计入经历数。没有新增市场行情，重复轨迹不冒充新的独立市场样本。

保存完整训练诊断，包括优化器更新、参数变化、价值损失、解释方差、KL、裁剪比例和探索尺度；额外对同一个rollout回报目标计算更新后Critic拟合指标，明确这些是训练轨迹诊断而非独立验证精度。
