# 最终方案：一个不预测收益的可执行配置

日期：2026-11-09
分支：`research/supply-pressure`
状态：**定稿。** 本文把整个项目的结论收敛成一份可以照着做的东西。

---

## 0. 先说清楚：目标没有完全达到

你要的是**回撤 ≤10%、年化 7%**。

| 项 | 结论 |
| --- | --- |
| 历史上（2005-2024，按当时的债券收益） | **达到过**：+7.2%~+8.6%、回撤 ≤10% |
| **按当前债券收益率（10 年期 1.59%）** | **达不到**。同样机制给 **+4.9% ~ +6.6%** |
| 原因 | 2019-2024 的债券 4.6% 里，**1.81pp 来自收益率下行**，那是一次性的 |

**这是[债券收益率分析](bond_yield_context_20261109.md)的直接结果，不是配比没调好。**

下面这份方案按**当前可实现的预期**写，并标明"要回到 7% 需要什么"。

---

## 1. 方案

### 资产

| 腿 | 内容 | 权重 |
| --- | --- | --- |
| **风险腿** | 50% A 股（沪深300 + 中证500 等权）+ 50% 标普500（人民币计价） | 动态 |
| **安全腿** | 国债（上证国债 `000012` 或同类国债 ETF） | 动态 |

### 规则（CPPI）

```
每天收盘后：
  缓冲垫 = 净值 − 0.90 × 历史峰值
  风险腿目标权重 = 6 × 缓冲垫 / 净值        （上限 100%，下限 0%）
  若目标与当前权重相差 < 5%：不交易
  否则：调整到目标权重
```

**参数：楼层 0.90、倍数 6、不交易带 5%。**

### 为什么是这几个数

| 参数 | 依据 |
| --- | --- |
| 楼层 0.90 | 直接对应"回撤 ≤10%" |
| **倍数 6** | 5–7 四段窗口全部达标且**零击穿**；8 会击穿 6 次、回撤 −10.04% |
| 不交易带 5% | 换手从 2.7 降到 0.9/年，且因为不追噪声，收益反而略高 |
| 风险腿五五开 | **缺一条腿就不成立**：只有 A 股，2019-2024 仅 +4.9%；只有标普，2005-2018 仅 +4.5% |

## 2. 预期收益（诚实版）

**当前债券 carry 1.6% 下：**

| 窗口 | 年化 | 期间最大回撤 |
| --- | ---: | ---: |
| 2005-2018 | +5.69% | −9.9% |
| 2005-2012 | +5.50% | −9.9% |
| 2013-2018 | +6.57% | −9.9% |
| 2019-2024 | **+4.90%** | −9.9% |

**区间：+4.9% ~ +6.6%，回撤封在 −10% 以内。**

**要达到 7% 需要以下任一条件：**

| 条件 | 可行性 |
| --- | --- |
| 安全腿 carry 回到 **2.5–3%** | 取决于利率环境，不可控 |
| 风险腿出现更强的收益环境 | 不可控 |
| 接受 **15% 回撤**（楼层 0.85） | **可控**，但 2019-2024 也只有 +5.81% |
| 倍数调到 8 | 收益 +5.44%（2019-2024），但**会击穿楼层** |

**结论：在 10% 回撤约束下，当前环境的合理预期是 5–6.5%，7% 需要等利率环境。**

## 3. 已知的四个风险

| 风险 | 说明 | 监控 |
| --- | --- | --- |
| **跳空** | 风险腿单日跌幅 > 1/6 ≈ 16.7% 时楼层击穿 | 看单一日最差：历史最差 −8.29%（2020-03-16） |
| **恢复慢** | 危机后低暴露，回到前高需 **60–525 天** | 2015、2022 各约一年半 |
| **债券腿是命门** | carry 从 4.6% 掉到 1.6%，收益就掉 2.3pp | **每季度看 10 年期收益率** |
| **执行摩擦** | 未计基金费率（约 0.3–0.4%/年）、QDII 溢价、汇率对冲成本 | 实际净收益可能再低 0.5–1pp |

## 4. 什么时候该改

| 触发条件 | 动作 |
| --- | --- |
| 10 年期国债收益率 > 2.5% | **重新评估**：收益预期可以上调到 6.5–7.5% |
| 10 年期 < 1.2% | 安全腿收益进一步下降，考虑缩短久期或加现金 |
| 单日风险腿跌幅接近 12% | 楼层接近击穿，**检查倍数是否该降到 5** |
| 连续 12 个月跑输"50% 股票 + 50% 国债"的静态组合 | 说明机制在当前环境失效，回到静态配置 |
| 风险腿连续两年负收益 | 收益来源消失，重新评估是否继续 |

## 5. 这个方案的来源（每条结论都指向证据）

| 结论 | 依据 |
| --- | --- |
| 不用选股 | 26 次检验（5 条训练线、20 个价格特征、E1、特征筛选、解禁覆盖层）全部落回噪声 |
| 不用等权 | 等权溢价是前视偏差造出来的（7.92pp → 0.37pp） |
| 市值加权 + 分红 = 基准 | 三 ETF 混合全收益约 7.5%，但回撤 −40% |
| 回撤要靠机制不靠配比 | 固定权重把 10% 回撤约束翻译成"只能持 10–20% 股票" |
| 两条腿缺一不可 | 单一市场的 CPPI 只在自己那个十年成立 |
| 倍数 6 | 5–7 零击穿；8 击穿 6 次 |
| 债券 carry 是命门 | 4.6% → 1.6% 就使收益掉 2.3pp |

## 6. 一句话总结

> **不要预测收益。持有两个不相关的市场，用 CPPI 把回撤封在 10%，接受 5–6.5% 的年化。
> 利率回到 2.5% 以上时，同样的机制会给到 7%。**
