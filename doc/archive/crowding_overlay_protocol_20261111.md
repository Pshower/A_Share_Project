# 预登记：把"融资融券拥挤度"做成规避 overlay

日期：2026-11-11
状态：**预登记，写在运行之前**。本文只固定规则；结果另写报告。
上游：[融资融券 IC](margin_ic_20261111.md)（IC −0.0403、t −4.64）、
[组合层结果](margin_portfolio_result_20261111.md)（多头书 −1.06%、t −0.15，但空头腿 +0.71%、t 2.39）。

---

## 1. 这次问的是另一个问题

融资融券信号作为**多头选股**已被预登记判定关闭：IC 通过，但 30 只多头书跑不赢自己的基准。
当时的诊断显示效应几乎全在**空头腿**——增速最快的 10% 之后跑输（+0.71%/20 日、t 2.39）。
A 股融券不现实，所以唯一可能的用法是：**把拥挤股从已有的书里剔掉**。

**这是一个新问题，不是把旧的失败换个说法救回来。** 判据、作用对象、统计量全都不同：
旧的是"这本书能不能跑赢基准"，新的是"同一本书剔掉拥挤股之后，能不能比它自己原来更好"。

## 2. 固定的构造（运行前写死）

| 项 | 取值 |
| --- | --- |
| 基础书 | **E1 反转构造**（20 个价格特征全取负号、秩等权、top 30、跌出前 60 才换、20 日持有） |
| 票池 | **PIT 动态前 1,800**（`data/clean/e2_dynamic1800`，与 E2 完全一致） |
| 拥挤定义 | `融资余额` **20 个交易日变化率**（滞后 1 日）在该日池内的**分位 ≥ 0.90** |
| overlay | 被判定为拥挤的股票，**当日所有特征置为缺失**——它变成不可选，书用下一个可用名次补齐 |
| 对照 | **完全相同的书、不加 overlay**；两者逐日配对 |
| 成本 | 同一 broker（佣金万三/最低 5 元、印花税千五、双边滑点 10bp、整手 100、300 万本金） |
| 窗口 | 2019-01-02 ~ 2024-12-31（融资余额自 2019 起；这也是已花窗口 V） |
| 配对统计 | 每 **20 个交易日**一个不重叠块，取两本书的块收益之差；t = 均值 /(标准差/√块数) |

**关键设计选择，先说清楚**：overlay 是"把特征置缺失"而不是"把票换成别的"。置缺失让这只票在当日
**不可选**（环境的 `valid_mask` 要求特征全有限），书自动由下一名补齐——这与"跌出前 60 才换"的缓冲规则不冲突，
也不需要另写一套选股逻辑。

## 3. 判据

| 判据 | 要求 |
| --- | --- |
| 配对差（overlay 书 − 原书） | **> 0** |
| t | **≥ 2.5** |

**两条都过才算通过。** 不设"阈值换成 0.8 或 0.95 再试"、"换个持有期再试"、"只剔除前 3 只再试"。

## 4. 失败之后怎样（现在写死）

**不通过 → 关闭"融资融券拥挤度"这一族**（规避用途），与多头用途一起结束，不再有第二次。
后续任何"用融资余额做别的事"的想法，都必须另写预登记。

**通过 → 它仍然只是"值得进影子"的候选**：W 是已花窗口，不能当样本外证据；
正确下一步是在 S2 影子里加一个并行的规避分支并行记录（只花日历时间），而不是在已花样本上调参。

## 5. 成本必须诚实计入

剔除会带来额外换手：被剔除的名字要卖、补进来的要买。broker 会按同样的费用和滑点扣掉，
所以配对差是**税后**的。这一点必须在结果里写清楚——否则 1%/年的理论增益很可能被换手吃掉。

## 6. 不能主张什么

- 不能拿"空头腿 t 2.39"去反推"overlay 一定有效"：overlay 只作用于书里恰好落在前 10% 的那几只
  （种子书上实测是 **4/30**），触及面和截面对 IC 是两回事。
- 不能因为通过就说"融资融券能用"：它仍然只是规避规则，不是收益来源。
