## 1. 归档

`stock_individual_fund_flow` **不接受日期区间**，只返回最近约 120 个交易日。所以只能滚动采集。

**频率选每周，不是每日。** 一次拉取能回溯约 120 个交易日，每周跑一次就与上一次重叠约 115 天，
**没有任何交易日会落在两次运行的缝隙里**。每日跑是浪费，且更容易触发限流。

首次归档结果：

| 项 | 值 |
| --- | ---: |
| 请求 | 1,799 只 |
| 成功 | **1,787** |
| 跳过（已在最新日） | 12 |
| 失败 | **0** |
| 行数 | **215,880** |
| 区间 | 2026-04-27 ~ 2026-11-06 |

存储是**只追加 + 按 (code, date) 去重**：重跑不会重复计数，后来修订的数据不会覆盖先前的观测。

## 2. 共线性检验

| 因子 | 构造 |
| --- | --- |
| 资金流 | `主力净流入-净占比` 的 20 日滚动均值（占比口径，不需要流通市值序列） |
| 动量 | 同一份数据里 `收盘价` 的 20 日涨跌幅 |

同一批日期、同一批股票，算截面相关：

| 口径 | 均值 | 标准差 | t | \|相关\|>0.5 的日期占比 |
| --- | ---: | ---: | ---: | ---: |
| Pearson | **+0.379** | 0.070 | 54.7 | 4.95% |
| **秩相关** | **+0.385** | 0.089 | 43.4 | 15.8% |

（101 个交易日，每日中位 1,798 只）

## 3. 判定

**阈值写在检验之前：|相关| > 0.5 判为冗余。实际 0.385，未过阈值。**

| 结论 | 说明 |
| --- | --- |
| **不冗余** | 0.385 对应约 **15% 的共享方差**，仍有 85% 是独立的 |
| **但也不独立** | 0.385 远不是"无关"，它是**中等偏高**相关 |

方向值得注意：相关是**正的**——资金净流入与过去的上涨同时出现。这与反转因子的方向一致
（过去的涨 → 未来的跌），所以资金流的 **IC 预期也是负号**，这一点在测 IC 时要事前写定。

## 4. 真正的限制：只有 0.42 年

| 用途 | 数据够不够 |
| --- | --- |
| **截面相关** | **够**。101 个截面 × 1,798 只 ≈ 18 万个观测 |
| **IC 与 t 统计** | **不够**。0.42 年只够约 5 个不重叠的 20 日块，t 没有意义 |

所以这一源地结论是：**过了共线性筛，但还不能判其有效性。**
归档每周继续，积累到一两年后再测 IC——**这正是归档存在的理由**。

## 5. 不能主张的

1. **不是"资金流有效"**。共线性低只说明"不是反转的另一种刻度"，不说明有 alpha。
2. **不是"资金流无效"**。IC 根本没测。
3. **0.42 年、一段行情**（2026-04 至 2026-11）。相关本身也可能随时间变化。
4. **口径未验证**：`主力净流入-净占比` 的分母是成交额还是流通市值、供应商是否改过算法，**都没有核实**。
