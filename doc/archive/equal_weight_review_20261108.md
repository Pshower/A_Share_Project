## 1. 仓库近期关于“等权（1/N）投资效果”的四层结论盘点

近期多轮研究从不同口径检验了 1/N 等权组合，表面数字跨度很大，实质指向同一套结构：

| 场景 | 观察到的等权表现 | 真实原因与有效性判定 |
| --- | --- | --- |
| **291 股池 + 100 万本金**（`daily_advice_program.md`） | 2023/2024 两折仅 `+0.28%` / `+0.53%`，大幅落后 20 股动量 | **不可执行**：每只分摊 3,436 元买不起 100 股整手，73%~74% 资金被迫留现金；不能充当多股策略门槛 |
| **32 股池 + 100 万/300 万本金**（`ppo_excess_20261106.md`、`baseline_capm_20261107.md`） | 选择窗年化 `+10.64%`、测试窗 `+23.85%`；对 `000300` 的 CAPM $\alpha$ 达 `+16.82%` / `+14.35%` | **池内与 PPO 无差别**：剥离 $\beta$ 后 PPO 与等权 $\alpha$ 几乎完全重合（`+17.01%` vs `+16.82%`），净收益差仅来自换手费；高 $\alpha$ 水位来自 32 只幸存成分股的选样偏差（零决策 `buy_hold` $\alpha$ 最高达 `+17.23%`） |

## 2. 深层机制复核：对现有报告的三项补充与修正

### 2.1 中证500档面板算出 `+7.92pp` 假溢价的真正根源，是“按全样本中位市值静态选档”的前视效应

[等权溢价的指数对照](equal_weight_crosscheck_20261108.md) 将面板 `+7.92pp` 与指数 `+0.59pp` 的差距笼统归因于“现存股票幸存偏差 + 算术平均方差拖累”。二次复核代码发现，**7.33pp 差距的直接来源是 `tools/equal_weight_crosscheck.py::band_frames` 用全样本中位市值 `(traded * shares).median()` 静态截取第 301–800 名**：

1. **反向条件偏误（Berk 规模条件效应）**：
   把“2017–2024 全样本中位市值同处第 301–800 名”作为固定入池条件时：
   - **2019 年初市值很小、靠 2019–2024 暴涨才进入中位 301–800 名的赢家**，在 2019 年初被市值加权赋予极低权重，却被等权赋予完整 $1/500$ 权重；
   - **2019 年初市值很大、因 2019–2024 暴跌才掉入中位 301–800 名的输家**，在 2019 年初被市值加权赋予极高权重，却被等权仅赋予 $1/500$ 权重；
   - 实测静态中证500档内，**2019 年初对数市值与 2019–2024 累计对数收益的相关系数高达 $r = -0.370$**。
2. **同一面板上的动态 PIT 对照实验**：
   在**完全同一张 5,056 股面板**（含完全相同的现存股票集合）上，只要把分档规则改为**每个调仓日按前一日市值（$\text{cap}_{t-1}$，无前视）动态选取各档位**（2019-01-02 ~ 2024-12-31，每 20 日调仓）：

   | 档位 | 静态全期中位市值选档（CW / EW / 溢价） | **动态 PIT 滞后市值选档（CW / EW / 溢价）** | 真实指数对照（CW / EW / 溢价） |
   | --- | ---: | ---: | ---: |
   | HS300 档 (`0:300`) | `+10.71%` / `+17.67%` / **`+6.96pp`** | `+8.26%` / `+8.15%` / **`−0.10pp`** | — |
   | **CSI500 档 (`300:800`)** | `+7.40%` / `+15.32%` / **`+7.92pp`** | `+7.42%` / `+7.86%` / **`+0.44pp`**（半年频 **`+0.34pp`**） | `+5.60%` / `+6.19%` / **`+0.59pp`** |
   | CSI1000 档 (`800:1800`) | `+6.48%` / `+14.27%` / **`+7.79pp`** | `+7.55%` / `+7.62%` / **`+0.07pp`** | — |
   | 小微盘档 (`1800:5056`) | `+3.09%` / `+9.03%` / **`+5.93pp`** | `+13.15%` / `+14.43%` / **`+1.27pp`** | — |

   可以看到：
   - 消除“全期中位市值静态选档”的前视偏差后，**面板自身算出的中证500档等权溢价就是 `+0.44pp`（月频）/ `+0.34pp`（半年频），与真实指数对 `+0.59pp` 直接吻合**；面板两侧高于指数约 `1.7~1.8pp` 恰好对应 `hfq` 含息与价格指数不含息的股息率差。
   - **前 1,800 只大中盘股在各自规模档位内部几乎不存在等权溢价（`−0.10pp ~ +0.44pp`）**。
   - 同理，`tools/capm_backtest.py::largest` 的宽度扫描（`top_k`）也使用了全期中位市值静态排序，导致前 300 / 800 / 1,800 只子面板上的等权溢价被夸大到 `6.3~6.9pp`；改为调仓日滞后市值动态取前 K 只后，前 300 / 800 / 1,800 只的等权溢价仅剩 **`+0.37pp` / `+0.52pp` / `+0.59pp`**。

### 2.2 对“等权拿到算术平均、指数没有”这一表述的修正

`equal_weight_crosscheck_20261108.md` 第 4 节及 `tools/equal_weight_crosscheck.py` 将面板等权（`+15.32%`）高于个股买入持有中位数（`+6.50%`）的差额归结为方差拖累 $\frac{1}{2}\sigma^2$（个股中位波动 `41.4%` vs 组合波动 `21.2%`），并把小标题写为“等权拿到的是算术平均，指数没有”。

这一点需要严格区分：

- **分散化消除个股方差拖累是所有多股组合的共性**：无论真实等权指数 `000982`、市值加权指数 `000905` 还是面板组合，只要持有 500 只股票，组合波动率都降到了 `21.0%~21.2%`，都同等地消除了约 $\frac{1}{2}(\sigma_i^2 - \sigma_p^2) \approx 6.3\text{pp}$ 的单股方差拖累，`000982` 在调仓周期之间同样复利横截面算术均值；
- **因此方差拖累差解释的是“为什么 500 股组合高于单股中位数”，不能解释“为什么静态面板等权比 `000982` 或 `000905` 高 7~9pp”**。后者完完全全来自 2.1 节的全期中位市值前视选档。

### 2.3 全市场（`0:5056`）无分档截断时，1/N 仍高出 `+3.99pp/年` 的真实结构

当覆盖全部 5,056 只股票时，不存在分档上下界截断，静态与动态 PIT 结果一致（2019-01 ~ 2024-11 市值加权 `+8.86%` vs 1/N 净 `+12.85%`，差 `+3.99pp/年`）。结合 2.1 节的动态 PIT 分档表可以清楚看到这 `+3.99pp` 从何而来：

- 排名前 1,800 只的大中盘股占全市场流通市值约 **87%**，年化收益在 **`+7.4%~+8.3%`**；
- 排名 `1800:5056` 的后约 2,400 只小微盘股仅占全市场流通市值约 **13%**，但在 2019–2024 期间年化高达 **`+13.15%`（市值加权）/ `+14.43%`（等权）**；
- 全市场市值加权组合只给后 2,400 只小微盘股配 **13% 权重**，而全市场 1/N 给它们配了 **57% 权重**（`2400 / 4214`）。

因此，全市场面板上的 `+3.99pp/年` **不是同规模水平上的“等权加权溢价”**，而是**把近六成仓位压在最小 2,400 只微盘股上的规模风格暴露 + 未退市小票幸存偏差**；而且在 100 万–300 万本金与 100 股整手约束下，同时等权持有 4,200 只股票在现实中根本无法执行。

## 3. 对后续工具、基准与实验的具体建议

### 建议 1：消除分档校验与宽度扫描中的全期中位市值前视
- **对象**：`tools/equal_weight_crosscheck.py::band_frames` 与 `tools/capm_backtest.py::largest`。
- **做法**：保留现有静态实现作为“含前视分档对照”的同时，增加按每个调仓日 $t-1$ 滞后流通市值动态截取 `[lo, hi]` 或 `[:top_k]` 的 PIT 口径，并在 `equal_weight_crosscheck` 报告中并列展示“静态中位市值选档（`+7.92pp`）vs 动态滞后市值选档（`+0.44pp`）vs 真实指数对（`+0.59pp`）”，使假溢价的产生与消失在工具层直接可复现。

### 建议 2：严格分离“池内选股归因基准”与“实盘可投资 beta 底座”
- **池内选股归因基准（用于检验策略有无人为选股增量）**：
  - 在固定股票池（如 `research_v3` 的 298 只）上评估 E1、Ridge 或 PPO 时，基准必须是**同一股票池、同一调仓周期（20 日）、同一本金（300 万）与同一整手/费用约束**下的可执行等权组合或同持仓只数（top 30）随机等权组合中位数；
  - 只有这样才能将池内幸存偏差、规模倾斜和整手现金留存同时对齐。
- **实盘可投资 beta 底座（用于衡量被动替代成本与收益）**：
  - 实盘或前瞻影子运行的被动底座应使用**真实指数（`000300` / `000905` / `000982`）**；
  - 严禁将含前视选档的面板等权或不可执行的 4,200 股全市场 1/N 当作实盘被动基准。

### 建议 3：在唯一待执行实验 E1 中增加“市值分位与规模归因”诊断栏
- **背景**：[研究方向复核](research_direction_20261107.md)已将下一步收敛为单个 go/no-go 实验 **E1**（20 日持有、298 只全池、20 个价格特征全部取负号按秩等权、top 30 等权、跌出前 60 才换的缓冲带、300 万本金、真券商成本）。
- **风险**：298 只池内的价格反转特征可能隐含向池内小市值或高波动股票倾斜。
- **建议**：在实现和运行 E1 时，除主判据（V 与 full 两窗口相对同池等权净超额 > 0 且合并 $t \ge 2$）外，同步输出诊断指标：
  1. 每期入选 top 30 股票在 298 只池内的**平均流通市值分位**；
  2. 对 `000300` 及 `000905 − 000300` 规模因子的双因子回归 $\alpha$ 与 $\beta_{\text{SMB}}$（直接复用 `tools/baseline_capm.py`）；
  3. 与同本金、同 30 只、同缓冲节奏的随机组合对比，确认净超额来自截面反转排序而非小盘暴露。

### 建议 4：明确 1/N 在项目中的最终定位
- **不因收益溢价缩水而放弃 1/N，但彻底改写采用理由**：
  - 在大中盘可投资宇宙内，无偏等权相对市值加权的真实净收益差只有约 **0.0~0.4pp/年**，不能指望靠“等权替代市值加权”凭空获得几个百分点的年化超额；
  - 但 1/N 依然是池内基准与被动底座的首选，理由完全在于**不需要估计期望收益或协方差、月频再平衡换手极低（0.53 倍/年、成本 0.17%/年）、避免重仓单只大票的特质风险**。这三条是结构性质，不依赖任何历史窗口的收益符号。
