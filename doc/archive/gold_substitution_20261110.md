# 用黄金替代部分标普：分散还在，但更重要的发现是窗口问题

日期：2026-11-10
分支：`research/supply-pressure`
状态：**黄金替代基本无效；这次测试暴露了一个更严重的问题——策略收益对窗口极度敏感。**

---

## 1. 为什么测这个

标普那 30% 的 QDII 溢价**测不到**（见[产品层](../etf_menu_20261110.md) §8），
所以考虑把标普权重降下来、用黄金补，看能不能保住分散化和收益。

**但黄金数据只从 2016-12-19 开始**，所以这段测试只能覆盖 **2016-12-21 ~ 2024-12-31**。

## 2. 单资产表现（这段窗口）

| 资产 | 年化 |
| --- | ---: |
| A 股（沪深300+中证500） | **+0.88%** |
| 标普500（人民币） | +14.01% |
| 黄金（上海金） | +10.39% |

**A 股这八年只有 0.88%**——因为窗口起点在 2016 年末的相对高位，中间含 2018 年（−25%）。

## 3. 四种风险腿组合

CPPI 倍数 6、楼层 0.90、不带 5%：

| 风险腿 | 债券 carry | 年化 | 回撤 | Sharpe | 7%/10% |
| --- | ---: | ---: | ---: | ---: | --- |
| A50 + SP50 | 4.6% | +4.35% | −5.44% | 0.675 | 否 |
| A50 + SP35 + AU15 | 4.6% | +4.13% | −4.92% | 0.673 | 否 |
| A50 + SP25 + AU25 | 4.6% | +4.15% | **−4.34%** | **0.708** | 否 |
| A50 + SP15 + AU35 | 4.6% | +3.97% | **−3.97%** | 0.656 | 否 |
| A50 + SP50 | **1.6%** | **+2.82%** | −5.57% | 0.244 | 否 |
| A50 + SP25 + AU25 | **1.6%** | +2.63% | −4.39% | 0.213 | 否 |

**黄金替代的效果：收益略降（−0.2 到 −0.4pp），回撤改善（−1.1 到 −1.5pp），Sharpe 基本不变。**

**不是一个能解决问题的替代。** 分散化还在，但收益上限由 A 股决定，换谁都一样。

## 4. 真正的发现：我之前的四段窗口有选择偏差

这次窗口（2016-12 → 2024-12）给出 **+2.82% ~ +4.35%**，
而我之前报的四段里 2019-2024 是 **+7.21%**。

**差在哪：这八年含 2018 年（A 股 −25%），而 2019-2024 不含。**

| 窗口 | A 股年化 | 策略年化（carry 4.6%） |
| --- | ---: | ---: |
| 2019-2024 | +5.31% | **+7.21%** |
| **2016-2024** | **+0.88%** | **+4.35%** |

**起点挪两年，策略年化从 7.2% 掉到 4.4%。**

**这说明"7%/10%"比我以为的更依赖窗口。** 我之前挑的四段——2005-2018、2005-2012、2013-2018、2019-2024——
**没有一段包含"从 2016 年末开始"这种起点**，而它恰好是最不利的起点之一。

**这是我的方法缺陷：四个窗口都从相对低位起步。**

## 5. 修正后的结论

| 说法 | 结论 |
| --- | --- |
| 黄金能替代标普、还保住收益 | **不能**。收益略降，只换来更浅的回撤 |
| 7%/10% 在 2005-2024 成立 | **只在特定窗口**。2016-2024 只有 +4.35% |
| 窗口选择是否影响了之前的结论 | **是**。四段都避开了最不利的起点 |

**准确的说法应该是：这套机制在 A 股不拖后腿的窗口里能到 7%，在 A 股走平或下跌的窗口里只有 3–4%。**

## 6. 不能主张的

1. **2016-2024 只是另一个窗口**，不比之前的四段更"真"——它只是**揭示了窗口敏感性**。
2. **黄金数据只有 2016 年后**，无法进入 2005-2015 的长检验。
3. **这一段 A 股 0.88% 是含股息后的**（加了 2.1%/年），所以不是低估。
4. **CPPI 的突发回撤（-5%）在这里很小**，因为风险腿两两相关低、且 A 股全程没大涨也没大跌。

## 7. 所以现在的建议要改

**不要按"7%"做计划。**

| 情形 | 可实现年化 |
| --- | --- |
| A 股窗口好（如 2019-2024） | +7% |
| A 股窗口平（如 2016-2024） | **+4.4%** |
| A 股窗口差 | 更低 |
| 当前债券 carry 1.6%（全部情形再减） | **−2 到 −2.5pp** |

**保守的预期是 +3% ~ +6%，回撤 ≤10%。**
