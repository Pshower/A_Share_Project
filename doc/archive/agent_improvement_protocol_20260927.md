# 稀疏与先验残差 Agent 研究协议

## 目标与边界

在同一新浪300股、同一费用和 HFQ 研究执行假设下，寻找优于上一轮近等权 PPO 的研究候选。不得把同一区间反复搜索的胜出结果说成独立测试优势；2026-07-01 之后保持不评估，不承诺一定找到实盘有效策略。

先验、动作筛选、实际 PPO 更新的贡献分开报告。若未训练的先验已经解释全部改善，结论必须写成“先验/动作设计改善”，而非“PPO 学会了超额收益”。HFQ 与一手约束尚未解决，因此即使研究指标改善，也不是现实订单发布许可。

## 预登记候选

复用本地新浪 `h_5cd4a2e818924259`，不重新下载，不混入其他源。保留净日收益奖励、256/128 共享网络、256步训练 episode、四种初始账户。

| 方案 | 动作 | 初始 log_std | 学习率 | 先验 |
| --- | --- | ---: | ---: | --- |
| D0 | 原稠密 softmax | 0 | 1e-4 | 无，匹配控制组 |
| D1 | 原稠密 softmax | -3 | 1e-5 | 无，仅减少探索扰动 |
| S1 | 仅分配至分数最高20股与现金 | -3 | 1e-5 | 无，检验仓位稀释 |
| R1 | 同 S1 | -3 | 1e-5 | momentum_20 截面排序先验，PPO 学习有界幅度的残差 |

先验强度4，残差输出系数0.25，残差股票头/现金头末层零初始化。先验只取当前观察的有效且可买股票，当日之前的20日动量，不使用未来标签。低 log_std 降低的是探索噪声，不固定最终方差。稀疏映射与先验参数写入模型契约，训练、加载、迁移和推理一致，旧模型默认保持原行为。

为避免均匀随机窗口漏掉最新上市股票，每四个训练 episode 中一个固定为训练期末尾窗口，其余随机；不超过训练截止日。增加逐股实际有效观察步数审计，区别于仅检查整个数据集是否存在有效样本。

## 实验顺序与预算

1. 开发筛选：四方案各 seed42、4096步。沿用截至2026-03-31训练、2026年4—6月开发验证。固定最终 checkpoint 做四账户比较，另评未训练初始化策略，不用筛选集挑多个 checkpoint。
2. 固定候选：各账户最大回撤不超过10%，再按四场景平均净收益选取候选；平分保留预登记较早方案。筛选不是独立证据。
3. 确认：候选重新从头训练 seeds42/123/2026、各8192步；仍比较四账户与固定基线，并保留初始化先验对照。
4. 时间敏感性：重新以截至2025-06-30数据拟合 scaler，验证2025年7—12月；候选与 D0 各 seeds42/123、8192步。该窗口是开发走步验证，不称为完全未暴露的最终测试；股票池仍按用户的2026年名单，披露选择偏差与晚上市股票掩码。

总预算上限为73,728训练步、11次训练。若候选未通过后述门槛，不继续自动扩大搜索；先报告失败原因并登记下一轮研究。此预算只是本轮防止无界试错的实验批次，不把预算耗尽等同于找到更好模型。

## “更好”的判断

优于旧 PPO 的研究候选需：确认期四账户平均收益较旧 PPO 均提升至少1个百分点，最大回撤不超过10%，并在2025年走步窗口的平均净收益高于匹配 D0；同时列明与等权、动量和未训练先验的差异。收益更高但回撤更大时必须披露，不宣称全面占优。手续费/滑点已扣除，仍单列换手与成本。

若未超过简单动量或未训练先验，只能称相对旧 PPO 改善，不证明强化学习本身带来增益。真实账户模型发布继续受未复权/公司行为、停牌状态和保留期评估门槛约束。
