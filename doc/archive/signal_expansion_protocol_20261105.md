# 新数据块横向信号筛选协议（2026-11-05）

本协议在**看到任何 IC 结果之前**登记。登记后只允许按此实现，不允许在看到分数后改口径、改窗口、改阈值，也不允许"试几个变体挑最好的"。

## 1. 问题

20 个量价特征在长样本上的截面 IC 全部落在 |IC| ≤ 0.035，`momentum_20` 为 -0.022，top−bottom 约 0。数据清单（[data_inventory.md](../data_inventory.md)）确认还存在三类从未进入模型的数据：市值与股本、业绩预告、股东户数。

本轮只回答一个问题：**这三类数据里是否存在比现有量价特征更强的日频截面预测信息？**

这是筛选，不是策略。它不产生交易规则，也不产生可部署候选。

## 2. 样本与边界

- 数据：fold 面板 `reports/runs/ppo_exploration_20261006/folds/{2023,2024}`（300 只，2017-01-03 至 2026-06-30）。
- 硬边界：`PROTECTED_START = 2026-07-01`。折面板在派生时已物理删除该日之后的行，本轮不额外读取任何 2026-07-01 之后的价格。
- 窗口与既有 IC 复核一致：每个 fold 的 `train` 窗口（起点至 `train_end`）与 `val` 窗口（`train_end` 次日 至 `val_end`）。
- 标签：`close[t+h] / open[t+1] − 1`，要求路径完整，与 `src/training/exploration_signal.py::forward_labels` 完全一致（毛收益，不含费用与滑点，与既有表可比）。

## 3. 信号定义（每种一条，不搜索变体）

时点规则统一为：`announcement_date` 之后**下一个交易日**起可用（`pipeline.md` §2 的 PIT 约定）。

### S1 `log_mcap`

- `总股本(t)` = `shareholders.parquet` 中该代码 `announcement_date ≤ t` 的最近一条 `总股本`；超过 400 个自然日无更新则置空。
- `mcap(t)` = `不复权收盘价(t) × 总股本(t)`，取 `log`。
- 用不复权价是因为总股本是实际股数，与后复权价混用会得到无意义的量级。

### S2 `log_float_mcap`

- `流通股本(t)` = `volume(t) / (turnover(t)/100)`，仅 `turnover > 0` 时有效。
- 取 21 行滚动中位数消除单日毛刺，再乘不复权收盘价后取 `log`。
- 与 S1 并列而非替代：一个用总股本，一个用逐日隐含流通股本，两者若结论不同须如实报告。

### S3 `earnings_score`

- 每条业绩预告按 `预告类型` 映射：预增/扭亏 `+1`，略增/续盈 `+0.5`，不确定 `0`，略减/减亏 `−0.5`，预减/首亏/增亏/续亏 `−1`。
- 同一代码同一报告期若有多条（不同 `预测指标`），优先取 `归属于上市公司股东的净利润`，否则取最早一条。
- 自可用日起线性衰减，**60 个交易行**后归零。

### S4 `holder_change`

- `−股东户数-增减比例 / 100`（户数减少记为正），同一代码同一报告期取一条。
- 自可用日起线性衰减，**90 个交易行**后归零。

### 对照组

- `momentum_20`：直接从 fold 面板取，作为同一张表里的量价基准。

## 4. 判据（预登记）

对每个信号、每个 h ∈ {5, 20, 60}，在四个窗口（fold2023.train、fold2024.train、fold2023.val、fold2024.val）上计算日频 Spearman 截面 IC。

一个信号被判为**有信息**，当且仅当同时满足：

1. 两个 fold 的 train 窗口在 h=20 上的 `|mean IC|` 中位数 **≥ 0.030**；
2. 上述两个窗口的 IC 符号一致；
3. 两个 val 窗口的 IC 符号与该符号一致或至少一个窗口方向正确且另一个不显著（`|IC| < 0.010`）。

不满足任一条即**关闭该方向**，不做参数调整、不换窗口重试。

判为有信息的信号只获得"进入策略门槛测试"的资格，不等于可用。

## 5. 预期与已知风险（登记时写下，避免事后叙事）

- **市值**：A 股小盘效应在 2017–2020 明显、2021 后反转，预期 IC 不稳定。若长样本 IC 强而 val 窗口反向，按判据 3 关闭。
- **业绩预告**：单期只覆盖 33–363 只，且有预告的公司本身是选择性样本。IC 高不代表可交易，因为信号只在一小部分名字上有值。
- **股东户数**：季度频率，衰减 90 行后与财报重叠，信息可能与 `earnings_score` 高度相关，须报相关性。
- **多重比较**：本轮一次检验 4 个信号 × 3 个 h，不做事后 Bonferroni 修正，但结论按预登记判据机械执行。
- **毛标签**：IC 不含费用与滑点，任何正 IC 在整手与 10bp 滑点下都可能消失。
