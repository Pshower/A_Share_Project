# 自回归结构诊断

日期：2026-11-06
状态：**找到了本项目第一个 |t| > 5 且跨窗口稳定的结构——1 日截面反转，且 T+1 可执行。**
关联：[价格特征重测](price_feature_ic_20261106.md)、[alpha 度量](alpha_measure_20261106.md)

问题是：能不能用自回归的方式构建交易模型？答案要拆成两个不同的问题，它们的功效差十几倍。

---

## 1. 为什么先量再建

截面 IC 和时序自相关是**两个不同的对象**，功效差一个数量级：

| 问题 | 有效样本 |
| --- | --- |
| 20 日截面 IC | 1436 天 ≈ **100** 个独立观测（相邻决策日共用 19/20 的收益窗口） |
| 1 日自相关 | 1454 天 ≈ **1500** 个（没有重叠） |

所以先回答便宜的、有功效的那个问题：**数据里到底有没有可用的自回归结构。**

口径：

- 数据 `data/clean/research_v3`（298 只），**end_date 2024-12-31，读不到 R 与 P**
- 时序部分用**收盘对收盘**日收益；截面部分用交易标签
- 波动率标准化用**前 60 日、shift 1**（不向前看）
- 标准误用**移动区块自助法**（20 日区块 × 400 次），保住日内的截面相关

### 过程中修掉的两个错

| 错 | 后果 | 修法 |
| --- | --- | --- |
| 方差比的 t 写成 `estimate/se` | VR=1.06 报出 t=37.5，荒谬 | 改为对 **1** 检验：`(VR−1)/se` |
| 波动率标准化无上限 | 长期停牌股的分母趋 0，一个观测把 ρ₁ 顶成 **0.81** | 截断到 ±5（标准化收益本就该接近单位方差） |

### 还有一个更关键的发现：h=1 的标准标签不可执行

`close[t+h]/open[t+1]−1` 在 h=1 时是**「次日开盘买入、当日收盘卖出」**——A 股 T+1 不允许。
所以补了一个 **开盘到开盘** 标签：买 `open[t+1]`、卖 `open[t+2]`，这是 T+1 合法的**最短往返**。

## 4. 它能不能赚钱：卡在成本上

用 `alpha_budget` 的折算关系估毛收益（30 只组合、70% 敞口）：

```
每日毛 alpha = IC × σ_cs,1日 × E[z|top 10%]
             = 0.0258 × 0.0305 × 1.755
             ≈ 0.139% / 日
```

而一次完整往返的成本（佣金 0.03%×2 + 印花税 0.05% + 滑点 0.1%×2）：

```
≈ 0.31% / 次
```

**如果每天把整本书换一遍，成本是毛收益的 2.2 倍，直接亏。**
盈亏平衡的日换手是 `0.139 / 0.31 ≈ 45%`。

所以这件事的成败**完全取决于换手**：反转排名的日间稳定性如何、实际只换掉多少只。
这不是能靠推理定下来的，必须用成本感知的回测量。

这是**下一步最该做、也最便宜**的实验：一个固定构造的 1 日反转组合，逐日调仓，
把费用、整手、T+1 全放进去，看净额。

## 5. 对 RL 的含义

前面三轮 RL 试验（原始收益、对池超额、强制满仓）全部学成"复制池子"，我当时的解释是"输入没有信号"。

**这个解释现在要修正：输入里有信号，但**

1. **方向是反的**。PPO 的 R1 先验按 `momentum_20` **正**排，而 `momentum_20` 在 1 日上是 −0.011（t −2.0）、20 日上是 −0.027。
2. **时间尺度不对**。模型 `lookback=1`、决策日频但评的是 20 日持有期；而这个效应在 **1 日**，2 日就衰减。
3. **奖励尺度不对**。0.139%/日 的优势，摊到 32 只股票的 softmax 上，是极其细小的梯度。

所以"自回归方式构建交易模型"这个方向**是可做的**，但要满足三个条件：反转方向、1 日持有期、成本必须先进模型。

## 6. 功效：R 上这一次是够的

之前算过，20 日 IC 在 R 上做不到 t=2（需要约 190 年）。**1 日不一样**：

| | 值 |
| --- | ---: |
| V 上 `body_ratio` 的 t | 5.69 |
| R 只有 359 天，t 按 √(359/1454) 缩放 | ≈ **2.83** |

**单个预登记特征在 R 上有足够功效。** 但 20 个一起测就不行（中位 \|t\| 会掉到 1.2–1.5）。

所以如果要用 R，必须**先把特征与方向定死在一个上**，一次性检验。这是 R 第一次真的有资格派上用场。

## 7. 边界

- **V 已花掉**，本表不能授权部署。它只说明"这里有结构"，不说明"这个结构能赚钱"。
- 股票池仍有**幸存者偏差**；反转效应在含退市股的全市场上通常更强，方向不确定。
- 未预登记方向，本表是描述性的。
- 自助法区块 20 日，对 VR(60) 的标准误会偏小，所以 VR(60) 的 t 不宜当结论。
- 本轮未读取 R 与 P。
