## 1. 为什么可以再测一次（而不是"换个模型再试"）

E1 不通过后，预登记写的是"**关闭'价格特征 alpha'这一族**"。在那之后又跑一次同样的信号，
必须说明为什么这不违反那一条。

**只有一条理由成立**：E1 的失败可能来自**票池**，而不是**信号**。

| 事实 | 出处 |
| --- | --- |
| E1 用的是 298 只**大盘幸存者** | `research_v3` 定义 |
| 截面反转类效应在**小而分散**的池子里 E[z] 更大 | [研究方向复核](research_direction_20261107.md) 第 4 节：top 30/298 的 E[z]≈1.76，top 30/4000 约 2.76 |
| E1 的净超额只有 +0.25%（full），t 0.07 | E1 报告 |

**如果效应~0，换池子也救不回来**；如果效应被测池子的窄截面压掉了，换池子能看到。
**这是一个可以被证伪的诊断，不是一次新的搜索。**

## 2. 明确不做什么（防止变相搜索）

- **不换特征**。仍然是那 20 个，全部取负号，秩等权。
- **不调参数**。top 30、缓冲 60、持有 20 日，全部照抄。
- **不扫池子**。只测一个预先写定的池子（第 1,800 名），没有"试试 500 只"。
- **不换成本模型**。同一个 broker、3,000,000 本金。
- **不换窗口**。仍然是 V 与 full。

**只改一个变量：票池。**

## 3. 协议（写死）

| 项 | 取值 |
| --- | --- |
| 票池 | **按调仓日前一日流通市值排名，取全市场前 1,800 只**（PIT 动态，不做全期静态分档） |
| 特征 | 20 个全部取负号，按秩等权合成 |
| 组合 | top 30 等权，持有 20 个交易日 |
| 缓冲带 | 跌出前 60 才换 |
| 成本 | 仓库同一 broker；本金 3,000,000；佣金万三/最低 5 元/印花税千分之五/双侧滑点 10bp/整手 100 |
| 基准 | **同池（1,800 只）可执行等权**，同本金同调仓同成本 |
| 诊断 | ①池内市值分位 ②对 `000300`+`000905−000300` 的 β_size ③同持仓只数随机对照 |
| 窗口 | V = 2019-2024，full = 2017-2024 |

## 4. 门槛：提高到 t ≥ 2.5，且两个窗口各自都要过

**理由：这是同一家族的第二次检验、同一批数据。** 每多测一次，假阳性概率就上升一次；
不提高门槛，第二次的 t = 2.1 和第一次的 t = 2.1 不是同一件事。

| 判据 | 要求 |
| --- | --- |
| V 窗口净超额 | > 0 **且 t ≥ 2.5** |
| full 窗口净超额 | > 0 **且 t ≥ 2.5** |
| 随机对照 | 净超额须高于随机中位数，且落在 p90 之外 |

**三条全过才算通过。** 任何一条不过即判失败。

## 5. 失败之后会怎样（现在写死）

**失败 → 永久关闭"价格特征 alpha"这一族，不再有 E3。**

不设"如果这次是池子的选择不合适再试第三个池"——那不是检验，那是搜索。
池子选第 1,800 名是因为它是**可执行的上界**（再往下的容量和整手不支持 3M 本金），
不是因为它历史上好看。**这个理由在运行前就成立，不受结果影响。**

## 7. 跑它的前提

`research_v3` 的 20 个特征只覆盖 298 只。要跑第 1,800 名，必须先建一份**新的特征面板**：

- 价格来自 `data/clean/panel_full`（5,056 只，2017-2024，已下载）；
- 特征用仓库自己的 `src/data/preprocess.py::add_features` 计算，**不另写一套定义**；
- 建成独立数据集，**不改动 `research_v3`**（它的哈希被 `run_suite` 校验）。

在面板建成之前，E2 不能运行。
