# 20 个价格特征在新框架下的截面 IC

日期：2026-11-06
状态：**旧统计量在量级上站得住，在显著性上站不住；方向全部为负。**
关联：[alpha 度量](alpha_measure_20261106.md)、[基准超额试验](ppo_excess_20261106.md)

这个问题是：那 20 个喂给 PPO 的价格特征，用修正后的框架（滞后 h 阶 Newey-West）重测，
`|IC| ≤ 0.035` 这个旧结论还成不成立？以及——它和经济门槛 0.0048 是什么关系？

两点必须说明：

- 该数据集 **end_date 就是 2024-12-31**，所以这个工具**读不到**保留窗 R（2025-01~2026-06）与保护窗 P。不是靠截断，是数据本身没有。
- 面板特征用的是**池化训练统计量**做的标准化。那是每个特征上的一个仿射变换，**不改变同日内的排序**，因此秩 IC 与用原始值完全一致。

## 3. 三个结论

### 3.1 旧的量级结论基本成立

旧的说法是"20 个特征全部 `|IC| ≤ 0.035`"。在 `full` 窗口上，最大是 `momentum_20` 那个量级：
20 日 **0.0311**、60 日 **0.0358**（`turnover`）。基本吻合。

`V` 窗口上出现 0.0412，比旧值高——那是子样本波动，不是旧结论错了。**量级这一条过关。**

### 3.2 旧的显著性结论不成立，而且错得很具体

**60 日持有期上，20 个特征没有一个是显著的**（lag-h 下 0/20）。

但如果还按预登记写的 lag-5，会变成 **5 个（V）/ 4 个（full）** 显著。也就是说，
**旧框架会在同一个样本上凭空造出 4–5 个"显著因子"，实际一个都没有。**

这不是抽象批评——安慰剂对照（`alpha_measure` 第 3 节）在 lag-5 下也给过 t = −2.57。

### 3.3 最关键：这些特征不是"太弱"，是"确认不了"

经济门槛是 **0.0048**。**13/20 个特征的 |IC| 超过它**，20 日最高 0.0412 是门槛的 **8.6 倍**。

所以"IC 太小所以没价值"这句话对这些价格特征**不成立**。卡住的不是量级，是**确认**：
有效日只有 100–170（h=20），要把 0.03 做到 t=2 需要约 3500 个独立观测。

**这修正了我上一轮的说法。** 正确的表述不是"没有信号"，而是：

> **量级够、方向一致、但在任何可得样本上都确认不了。**

---

## 4. 方向：全部为负

表里**每一个**强特征的 IC 都是负的，两个窗口、两个持有期、20 个特征一致。这是一个**反转**结构，不是动量。

这件事对前面的工作有直接影响：**PPO 的 R1 先验是「按 `momentum_20` 正排」**，而 `momentum_20` 自己测出来是 **−0.027**。
也就是说，那个先验的方向和数据是反的。这不是调参能修的，是设计前提错了。

### 但我不能拿这个去建策略

`V` 已经花掉了，而我**刚刚在 `V` 上看到方向**。现在用它做一个反转策略再在 `V` 上回测，就是标准的
事后选择。所以这条发现的地位是：

- **是假设的发生器，不是证据。**
- 它之所以还有一点分量，是因为符号在 20 个特征 × 2 个持有期 × 2 个窗口上**完全一致**——
  这不是从一堆候选里挑出来的方向，是一个系统性的模式。
- 但它要在**没被用来形成假设**的样本上确认。

---

## 5. 那就意味着 R 也不够

即使把反转假设预登记、一次性在 R 上检验，功效也不够：

| | 值 |
| --- | ---: |
| R 决策日 | 359 |
| h=20 有效日（按 V 实测的重叠系数外推） | ≈ 26 |
| 日 IC 波动（实测中位） | 0.143 |
| R 的 SE | ≈ 0.028 |
| 真 IC = 0.03 时的 t | ≈ **1.07** |

**连真有效应都测不出来。** 所以 R 花下去换回来的仍是一个"不显著"，而那个"不显著"无法区分
"没有效应"和"测不出效应"。

**唯一能确认它的路径是前瞻影子运行**：把反转构造固定下来，从今天起逐日记录，攒够年份。
这也是为什么前面几轮反复回到同一条结论。
