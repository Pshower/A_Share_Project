# 并行分册：同一套规则，四种冻结权重（2026-11-18）

## 0. 问题

S2 影子现在只记录**一种构造**：20 个特征各取截面分位、等权平均、取最小的 30 只、跌出前 60 才换、持有 20 个交易日。

"等权"当初是**为了不过拟合**才选的，不是因为它最优。但想验证"换权重会不会更好"，我们**没有样本可用**了：
V 窗（2019-2024）已花、R 窗（2025-2026H1）已花、P 窗（2026-07~）已动。

所以这里换一条路：**不拟合，只并列记录**。四种权重现在就写死，各自一本账，只花日历时间。

> 纪律：本文写定之后，**权重不许再改**。改任何一个数字都是新的预登记，要另开一份文档。

## 1. 四个方案

| 变体 | 权重定义 | 为什么设它 |
| --- | --- | --- |
| **A** | 20 个特征，每个 1/20，等权 | **对照组**。必须与主账本 `e1_rule.composite` 逐位一致；不一致就是这套 harness 错了，不是市场 |
| **B** | `return` 0.5 + `momentum_5` 0.5 | 只用反转两因子。V 窗里唯一有稳定 IC 的一族 |
| **C** | `return` 0.4 + `momentum_5` 0.4 + `volatility_20` 0.2 | 反转 + 低波。检验"低波优先"能否改善组合层 |
| **D** | 不看任何特征，按 `crc32(日期+代码)` 取均匀数 | **随机对照**。如果 A/B/C 都跑不赢 D，说明这套构造没有信息 |

选股规则、持有期、带宽全部与主账本相同（`top 30` / 跌出前 60 才换 / 持有 20 个交易日），
唯一变化的是**打分怎么加权**。

### 为什么没有"符号"

四个方案里所有特征的系数都是正的。方向已经写进特征本身：对一本反转书来说，
1 日涨幅越高、波动越大，就是越"该卖"的一端，所以分位越高、分数越高。
这一点与 `e1_rule` 的注释一致（"lower score is the buy"）。

## 2. 记录在哪

```
reports/shadow/variants/A_shadow.jsonl   A_state.json
reports/shadow/variants/B_shadow.jsonl   B_state.json
reports/shadow/variants/C_shadow.jsonl   C_state.json
reports/shadow/variants/D_shadow.jsonl   D_state.json
```

- 每行一天，字段与 `e1_shadow.jsonl` 同构（`status` / `panel_date` / `book` / `score` / `interval` / `benchmark` / `construction`）；
- **主账本 `e1_shadow.jsonl` 不受任何影响**，构造参数一个字没动；
- 工具：`python -B -m tools.shadow_variants [--variants=ABCD] [--dataset <path>] [--force]`。

A 与主账本的关系：**A 是"规则"的对照，不是"书"的对照**。主账本从 2026-11-10 起持有一本书，
四个变体从 2026-11-18 各自开一本新书，所以第一天的名单本来就会不同——比的是**同一段日历上的收益**，
不是同一天的持仓。

## 3. 判据（预登记）

1. **不看前 60 个交易日**。四个变体都从 2026-11-18 开账，一个 20 日持有期才走了 0 天。
2. 首次比较在 **不少于 60 个交易日**之后（约 2027-02-中旬），且必须用**组合层收益**：
   各变体自开账起的**链式净值**与同池等权、沪深300 对比，不看 IC、不看单日。
3. 判定阈值（照抄 E1 那套）：**净超额 > 0 且 |t| ≥ 2.5**（以日为块做配对 t），
   同时回撤不差于 A 0.5pp 以上。
4. **A 必须与主规则一致，但比的是打分不是名单**：A 从 11-18 开账、主账本从 11-10 开账，
   两者的 20 日周期永远相差三个交易日，名单本来就不会相同（第四轮审查指出过这一点）。
   正确的对照是**同一 panel 日期上的分数**：A 的 `blend` 与 `e1_rule.composite` 必须逐位一致
   （最大差异 3.3e-16，`tests/test_shadow_variants.py::test_variant_a_is_exactly_the_frozen_rule` 守着）。
   若哪天这条测试红了，先查 harness，不许解释成"市场变了"。
5. 任一变体若要改权重，等于新开一份预登记，旧账本封存不删。

## 4. 第一批记录（2026-11-18，四本都是开账日）

| 变体 | 名单数 | 与 A 重合 | 与 B 重合 |
| --- | ---: | ---: | ---: |
| A | 30 | — | 16 |
| B | 30 | 16 | — |
| C | 30 | 16 | 24 |
| D | 30 | **4** | 2 |

- **A 与 B/C 重合 16 只**，B 与 C 重合 24 只——两种反转口径都指向同一批股票；
- **D 与 A 只重合 4 只**（297 只池子里随机取 30，期望重合 3.0 只），说明随机对照确实是随机的；
- A 的打分与 `e1_rule.composite` 的最大差异 **3.3e-16**，名单前 30 完全一致——对照组是同一套规则。

**这四行什么都不能证明**，只是说明记录链路是通的。
