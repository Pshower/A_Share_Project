## 2. 怎么算的（只有一个自由度）

```
缓冲垫        = 净值 − 0.90 × 峰值
风险腿目标    = 6 × 缓冲垫 / 净值            （夹在 0% ~ 100%）
风险腿内部    = 25% 沪深300 + 25% 中证500 + 50% 标普500（人民币）
安全腿        = 100% 中短国债；--cash-safe 时改为 50% 国债 + 50% 货币 ETF
是否调仓      = |风险腿目标 − 当前风险腿| ≥ 5% 才动，否则持有
```

这就是 [统一策略最终规格](unified_strategy_final_20261115.md) 的第 2 节，没有第二套逻辑。

## 4. 怎么落到账本

```bash
python -B -m tools.daily_allocation            # 只读：打印建议、写 latest.json
python -B -m tools.daily_allocation --apply    # 落账：先卖后买 → 写成交 → 按当日收盘重新记账
```

- `--apply` 只会在**触发带宽**时产生成交；今天是 0 笔，但会重记当日快照并写一条决策日志
  `reports/runs/daily_allocation/decisions.jsonl`。
- 写入走的是账本自己的校验（`record_trade` 会拒绝超卖、超过现金的买单、非整手）。
- 页面的接口是**只读**的：`GET /api/recommend/unified?book=paper` 只返回建议，不下单。

## 5. 数据时效（必须看）

页头显示「数据截至」——它是本地缓存里**所有腿共同的最后一个交易日**，本次是 **2026-11-13**。
缓存来自 `python -B -m tools.fund_vehicles --refresh`，**不联网就不会前进**。
所以页面上的"今天"永远是"数据截至日"，不是墙上的日期。
