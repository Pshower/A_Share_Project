# AKShare 下载范围扩展

日期：2026-09-26。先核对官方文档和本机 AKShare 1.18.64 的签名，再实施白名单适配；不自动升级 AKShare，也不由助手触发真实采集。

## 本轮范围

| 数据 | 接口 | 目的 |
| --- | --- | --- |
| 个股资料 | stock_individual_info_em | 名称、行业、股本等背景信息 |
| 个股资金流 | stock_individual_fund_flow | 量价研究的补充观察 |
| 分钟行情 | stock_zh_a_hist_min_em | 盘中历史归档 |
| 指数日线 | index_zh_a_hist | 后续基准与市场状态研究 |
| 分红记录 | stock_history_dividend_detail | 后续公司行动核验 |

来源：[AKShare 股票接口](https://akshare.akfamily.xyz/data/stock/stock.html)、[指数接口](https://akshare.akfamily.xyz/data/index/index.html)。官方限制：1 分钟行情近 5 个交易日且不复权；资金流近 100 个交易日。分钟开盘可能为 0，不能补造 K 线。分红派息字段为税前口径。

本轮新增的是下载、审计、预览和导出，不是自动接入 PPO 或真实账户。指数点位不是股票价格；当前资料不是历史时点基本面；资金流是供应商分类统计；分红数据尚未核验每股基准、到账日期与税务规则。

## 后续候选

可继续评估业绩报表 `stock_yjbb_em`、全市场行情 `stock_zh_a_spot_em`、五档报价 `stock_bid_ask_em`，以及官方文档中的行业板块、融资融券、公告、龙虎榜和交易日历。前两项属于全市场 / 报告期范围，不应伪装成单股票的小请求。

后续接入先核对本机版本和真实返回样本：财报按公告可得时间而非报告期末对齐；板块归属需历史成分而非今天的名单；指数基准要区分价格与全收益；公司行动须补足账户处理字段。未满足这些条件的数据只用于展示，不进入训练或回测撮合。

## 实现安排

1. 新增“联网行情 / 扩展数据”，类型、代码、日期 / 分钟周期、资金流交易所均由用户选择。
2. 每批最多 20 个代码，显式网络许可，供应商来源可见；新浪分红不作为东方财富失败时的隐藏替代。
3. 单独保存于 `data/online/supplements/`，记录接口、请求、SDK 版本、采集时间、实际覆盖及文件哈希。保留供应商字段和单位，不应用日线成交量乘 100 规则。
4. SDK 中没有 timeout 的接口在独立子进程内限时执行；取消时停止自有子进程，父进程异常退出时子进程自行退出，避免遗留采集。
5. 分项成功 / 失败 / 空返回，显式重试仅补失败项。部分失败和取消保留已完成数据；不假定请求成功意味着历史完整。
6. 文件列表、表格分页预览、JSON / CSV 导出均读取本地，不再请求供应商。CSV 对可能被表格软件解释为公式的文本做转义，原值留在 JSON。
7. 不提供任意接口名或 URL，不自动采集全市场；默认测试使用模拟适配器，不把模拟成功当作真实接口验收。

## 操作入口

工作台：`http://127.0.0.1:8766/#market?kind=supplements`。选择“扩展数据”，选类型、填写代码，明确勾选供应商授权，再提交。

- 日期范围仅约束分钟和指数日线；资料、资金流及分红返回接口实际可提供的范围，不伪装成支持任意日期筛选。
- 分钟采集请求窗口最多 31 个自然日，所有分钟周期本轮均请求未复权；这不是接口提供完整 31 日历史的保证。
- 资金流一批共用一个交易所，跨交易所的代码应分批提交；指数输入的是指数代码而非股票池。
- 改变数据类型会清除新请求授权。重试历史批次使用单独授权，防止把东方财富的新请求授权复用为新浪旧批次重试。
- 每个 SDK 调用之前共享限速；SDK 内部可能包含多个请求，不承诺其内部每个 HTTP 请求都被本项目单独限速。
- 单代码 SDK 进程限时 45 秒；连续 3 项失败后剩余项记录未采集，每批软时限 1000 秒。监督进程 1100 秒兜底，和日线下载共用历史下载槽，不占用训练槽。
- 空返回单独标记，不能据此断言该证券没有分红或没有行情。`history_complete=false`、`model_ready=false` 始终保留。
- 协作取消保存已完成项。硬杀、断电或文件系统失败时不保证当前批次已发布；残留临时文件不是成功归档。

终端也可由用户手动运行，例如个股资料：

```powershell
conda activate AShareGPU
$today = Get-Date -Format yyyy-MM-dd
python -B -m src.data.supplement --type profile --codes 000001 --start $today --end $today --allow-network
```

`--type` 可取 profile / fund_flow / minute / index_daily / dividend。资金流加 `--market sh|sz|bj`；分钟加 `--period 1|5|15|30|60`。`--resume s_...` 必须使用与原批次完全相同的参数，不能换成新的当前日期。上述命令未由助手执行采集。
