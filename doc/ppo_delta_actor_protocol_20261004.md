# 股票增量Actor研究协议

日期：2026-10-04。状态：机制、pilot选择规则与正式预算已预登记，运行源码及机器协议须在执行前绑定。本文件不表示训练或回测已经完成。pilot未通过时不启动正式训练。

## 研究问题与比较边界

上一轮先验策略几乎复现固定动量配置；无先验随机策略则出现高换手、大种子差异与频繁KL提前停止。本轮研究以持仓增量代替每日完整目标权重，建立可表达保持股数、减仓与退出的股票Actor，并先验证更新稳定性。

股票池有`N=300`个股票坐标，Actor输出N个股票增量，移除现金动作坐标。现金继续作为账户状态供Actor与Critic观察，由股票交易、费用、应收结算及公司行为决定。减少股票可增加现金，保持现金不需要单独的现金评分。

本轮同时改变动作语义、状态输入、持仓数量条件、初始化及可能的探索/学习率设置。新旧结果是不同研究机制的同数据比较，不能把收益差全归因于单独删除现金头，也不能声称与旧八格完全同机制。

## 增量动作与零动作语义

每个股票坐标表示对该股现有持仓的增加、减少或保持。原始latent为`a_i`，申请的市值比例增量为`delta_i = 0.05 * tanh(a_i)`，即`max_delta_weight=0.05`。股数映射与执行遵守登记的价格时点、整手/整数、资金及数量约束；任何额外死区不得在看开发收益后加入。

Gaussian只对采样前状态确定的可行动股票坐标采样。完全由状态冻结或无法进行任何合法交易的坐标确定性置零，并从log-probability、熵及joint KL中省略；部分锁定且仍存在合法买卖方向的坐标保留。资金和名额可能因其他坐标的卖出而变化，不能把依赖采样动作的后续裁剪伪装成固定状态mask。

topN筛选是动作相关的落地步骤。所有状态可行动的已采样坐标仍进入PPO概率与KL计算，即使它们后来未被topN选择；不能只保留选中股票的log-probability。掩码、原始样本、旧log-probability和更新时的条件分布必须对应同一观察，不能用下一状态重算支持集。

严格验收`a_i=0`表示对股票i不生成主动交易。整向量为零时，现有股数保持不变、交易费用与滑点为零；价格变化自然改变市值权重与净值。已知公司行为导致股数、现金或应收变化仍正常记账，不能把它们当作Actor交易。

零动作不能先转换成旧收盘目标权重、再由旧broker按次日开盘价格重算股数，否则价格漂移仍可能触发交易。买卖订单以明确的股数增量/保持标志落地，执行时重新检查资金、费用、可买可卖、整手与成交量约束。

单票5%约束的适用方式须与零保持语义一致：新增/加仓不得主动突破登记上限，已有持仓因价格漂移、事件或冻结超限时不通过伪造零动作交易强制归位。已有超限持仓及容许的减仓/加仓规则必须在契约中说明，并报告实际例外。

小gain初始化只使Actor输出接近零，不自动保证每个状态的确定性均值恰好为零。分别检验“人为零动作”的严格保持与“未训练网络均值动作”的真实行为；不能把近零网络输出当成已经验证的纯保持策略。

## 冻结状态与部分锁定

对股票记录当前持仓、可卖股数/比例、不可卖剩余股数/比例，以及当前可知的买卖与数据掩码。被冻结的部分与可交易部分应可区分，不能仅有一个无法解释部分锁定的二值标签。

正增量必须遵守可买标记；负增量不得超过执行时实际可卖股数。零增量在可买、不可买、可卖、不可卖及部分锁定状态中均保持原持仓。对缺失决策特征或价格不能暗中生成虚构值，具体掩码行为需在测试与契约中固定。

冻结股票只要存在无法通过本次交易全部卖出的剩余股数，就占用一个持仓名额。部分锁定也占一个名额；不能只统计“完全不可卖”股票，也不能将未成交的计划清仓当作已释放名额。

当日收盘决策、次日开盘执行的结算时序应明确：可依据已知T+1与锁定到期规则判断下一执行日将解锁的股数，不读取未来行情。执行日资金、状态或成交量不足时按真实结果保留持仓，并记录冻结/未成交原因。

## topN条件与数量松弛

`topN`作为显式观察条件进入Actor与Critic，表示新增持仓受到的总持仓数量上限目标，现有及冻结股票均占用名额。训练episode从10/20/40中均匀抽样，episode内保持该条件。正式推理及主开发比较固定为20，不按验证收益选择10或40。

观察同时包含实际持仓数、冻结持仓数和可用数量松弛，归一化方式与字段顺序进入契约。数量松弛根据实际剩余持仓计算：只有确认全部卖出的股票才释放名额；新建仓按执行后数量预算检查，已有持仓加仓不能被误算成建立一只新股票。

若初始或既有股票数量超过预算，或者冻结股票已经超过topN，应保持零动作身份，阻止新增股票并披露超限/松弛原因，允许合法减仓。不能一边承诺零动作保持股数，一边为满足数量上限偷偷强制清仓；也不能将这些冻结例外描述为全程持仓必定不超过topN。

topN条件抽样使用独立且可审计的RNG，不消耗原历史起点/初始账户RNG；其种子派生规则随运行源码记录于机器协议。对应种子的初始账户、日期与状态哈希继续与旧研究对齐；若实现导致采样序列变化，先修复或明示协议变更，不能伪称完全同经历。

训练记录10/20/40各自的实际episode/步数、冻结数、超限数与松弛分布。主结果只使用固定topN20；允许在同一开发窗口分别报告topN10/40敏感性，全部公开并标明辅助比较，不用它们挑最有利的topN、替换主结果或选择幸运seed。

## 初始化、pilot与阶段冻结

主路线使用小网络宽度256/128，股票Actor最后线性层使用小gain `0.01`与零bias；Critic初始化独立说明，不能因Actor小gain顺带静默改变价值头。无显式动量先验，保留原动量特征。

联合KL保护保持`target_kl=0.03`。监控同一状态可行动坐标条件分布的joint近似KL，最多包含N个股票坐标；不能用除以N或可行动数量的单维平均数替代同一个阈值。SB3的提前停止不回滚已经发生的更新，需报告实际Adam更新与计划更新之比，而不仅是环境步或配置epochs。

pilot只使用截至2026-03-31的训练数据，不能执行开发/保留期收益比较来选择pilot设置。固定seed42，四个配置分别从头训练2,048步，使用相同账户/历史起点流与独立topN课程流：

| Pilot | 学习率 | 初始log_std | 初始标准差约值 |
| --- | ---: | ---: | ---: |
| P1 | `1e-5` | `-3` | 0.049787 |
| P2 | `1e-5` | `-1.5` | 0.223130 |
| P3 | `1e-6` | `-3` | 0.049787 |
| P4 | `1e-6` | `-1.5` | 0.223130 |

每个pilot采集4个512步rollout，最多计划80次Adam更新；四配置合计8,192个训练期环境步，独立归档，不混入正式成绩。

pilot合格条件全部满足：

1. 参数、梯度、动作、概率及登记诊断有限，工程不变量与保存加载检查通过。
2. 实际优化器步数大于零。
3. 存在真实成交，即仅对`filled_shares != 0`记录求和的`grossfills = sum(abs(filled_shares) * execution_price)`大于零；未成交缺价记录不参与，避免`0 * NaN`污染。这仅验证动作落地，不是获利门槛。
4. 最后四分之一rollout更新记录的joint `approx_kl`均值不超过0.045。对固定2,048步pilot，这就是最后512步rollout对应的平均诊断，不能另挑较小minibatch值。

在合格配置中，依次选择实际优化器步数更多、末四分之一joint KL更低、初始标准差更低、学习率更高的配置。排序使用未四舍五入数值；不依据训练奖励、value_loss、开发ROI或任何后期收益选择。最终正式配置采用所选学习率与初始log_std，其余机制保持本协议。

若四配置均不合格，停止正式训练计划，先修复稳定性并登记新版本协议；不自动关闭KL保护、改候选集或扩大预算。通过均值KL条件也不等于每次minibatch均未超阈值，仍需记录提前停止、clip fraction、实际工作量、动作饱和、真实成交与掩码行为。

## 正式训练与对照

pilot通过后，三种子各从头训练至65,536步，更新后保存8,192步短快照。共3次真实训练、6份比较快照、196,608正式环境步；快照步数和221,184含重复短前缀，不作为训练量。pilot模型不作为正式warmstart，正式三种子重新初始化。加上四pilot为204,800步；其他工程更新若有，须单独授权与登记，不混入正式训练量。

短快照为同一次新Actor训练的严格前缀；保存加载检查保护训练随机状态。正式验证四账户均使用相同初始输入、资金与种子，每个模型独立回测。

必须保留每个seed自己的未训练小gain初始化对照，以及对相同初始股数完全不下单的“保持股数”基线。旧`buy_hold`在第一日会配置目标权重，不自动等同于本轮纯保持基线。初始化收益与训练后增量分别报告，不将未训练产物作为正式候选。

旧对照使用已完成prior/random的小网络短、长两格，匹配seed42/123/2026、8,192/65,536步和四账户；同时保留旧先验初始化、每日及20日调仓动量、等权、买入持有和现金目标。原始模型与登记结果不覆盖、不补训。

数据、账户和名义环境预算可对齐，但动作映射、状态条件、现金处理、Actor初始化及pilot选定的优化/探索设置可能不同。须逐项披露差异，并报告真实更新工作量；不能将比较写成纯网络容量实验或单一Actor组件的因果实验。

## 验收与研究候选门槛

工程验收先于pilot与正式结果：

1. 零动作严格保持股数、无主动订单/交易费用，在涨跌价、已有超权重/超topN、全部冻结及部分锁定案例中成立；自然事件变化另记。
2. 买卖方向、可卖数量、部分锁定、资金含费用、买入整手、成交量及实际数量预算一致；不可成交时不能靠重写持仓伪造完成。
3. topN已进入观察与模型，10/20/40课程可复现，推理20固定；数量松弛真实可审计，缺失/超限明确处理。
4. 模型完整契约与真实观察/动作维度一致，参数有限、实际更新、保存加载、股票排列一致性与源码/数据哈希通过。旧301维模型不能静默加载成新300维动作模型。
5. 不暴露训练截止之后的数据给训练provider；开发评估仅到2026-06-30，不执行保留期绩效。

正式完成后，沿用开发候选门槛：全部种子/账户最大回撤幅度不超过10%；四账户平均后，三种子相对各自初始化的平均学习增量为正且至少两个种子为正；候选平均净ROI高于匹配预算的旧prior小网络。只比较固定短/长快照，不看收益后改门槛或改topN。合格格按平均净ROI排序，完全平局依次较小最坏回撤、较低费用加滑点、较短预算；展示模型固定使用seed42，不选择最高收益seed。

若无合格候选，完整报告失败。即使相对旧prior或初始化改善，仍须披露与每日/20日动量的差距；没有未见评估和真实执行适配，不晋升实盘默认。平均成本已含在净收益中，不重复扣减，也不事后增加成本门槛。
