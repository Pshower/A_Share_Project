# 无先验随机初始化二乘二实验协议

日期：2026-10-03。状态：运行前预登记。用户授权在既有新浪300股数据上，从头训练无先验随机初始化模型，并与已完成的R1先验矩阵比较。本协议登记后固定设置与判断门槛；不承诺新模型一定优于对照。

## 研究问题与范围

旧矩阵增加训练预算和共享MLP容量后，四格平均净收益仍未超过初始化动量先验。旧模型的目标选股与先验高度重合，目标权重变化很小。本轮检验：去掉显式动量先验，以随机Actor初始化和更自由的Actor输出训练，是否在同一开发窗口改善净收益，以及改善是否来自实际训练。

这不是只删除一项先验的单因素消融：当前网络在有先验时使用`4*rank(momentum_20) + 0.25*tanh(stock_head)`，现金为`0.25*tanh(cash_head)`；无先验时使用未经该残差限幅的股票与现金头输出。Actor末层也由零初始化变为PyTorch `nn.Linear`默认随机初始化。因此，本轮比较的是“随机初始化、无显式先验、取消原残差限幅”的整套机制，不能把收益差全部归因于其中某一项。

`initial_log_std`只是可学习探索参数的初值，不是把全程标准差锁定为0.0498。相同初始latent噪声也不等于相同目标权重或成交探索强度：随机评分、top20边界与取消限幅会改变动作映射结果。

本轮不同时增大标准差、加入熵奖励、改变奖励或扩展特征。301维高斯熵在现有PPO损失中求和，股票共享的`log_std`承担300个股票坐标的熵梯度；高探索与熵系数应另行预登记，不能混入本轮后再解释为无先验的效果。

## 共享前缀与训练量

每个容量/种子真实训练一次至65,536步，在完成8,192步的优化器更新后保存短快照。共6次正式训练、12个固定快照、393,216个实际环境步。快照步数和442,368含重复短前缀，不能作为训练量。

保存、加载检查须保护Python、NumPy及Torch CPU/CUDA随机状态，不改变后续探索和minibatch顺序。每个种子的大小模型应具有相同的初始账户、历史起点与账户/日期状态序列；短episode记录严格等于长记录前缀。长减短描述同一训练继续学习后的变化，不是两个独立样本。

工程准备为两种容量各1,024步、512/1,024步快照，累计2,048步，单独存入工程烟雾目录。新一轮正式加准备共395,264步；旧矩阵不补训。两轮正式训练合计786,432步，联合统计不重复计算任何短前缀。

记录逐股有效观察、不同历史决策日期、独特初始账户、独特账户/日期状态、各模式episode与步数。更多轨迹与账户不能冒充新增独立历史行情。

## 初始化与基线对照

无先验随机网络的确定性初始策略随容量和种子变化。必须保存并逐一评估六份未训练初始化模型，各有相同四账户；每份作为对应短、长快照的共同初始化对照。不能用一个随机初始化报告代替所有种子，也不能复用旧R1纯先验的初始化收益作为随机模型的学习起点。

初始化评估使用确定性均值动作，与正式快照的评估方式一致。未训练产物必须明确标记，不作为已训练候选、最终冻结或发布入口。报告同时给出随机初始化本身的收益及训练后减初始化的差值，防止把偶然有利的初始化当作学习收益。

保留以下对照：旧R1初始化先验、匹配容量/预算/种子的旧R1训练模型、每日动量、20日调仓动量、每日与20日等权、买入持有和现金目标。每日动量用于同频比较，20日调仓动量保留较强规则对照。

规则基线可在完整数据、日期、股票顺序、账户、费用及指标定义一致并通过哈希校验后复用。六份随机初始化必须独立绑定自身模型哈希；旧先验模型与原始结果保持原样。共同基线复用不增加独立样本数。

## 联合比较与统计口径

新2x2与旧prior 2x2构成八格描述性比较。先在同一容量/预算/种子内平均四个账户，再跨三个训练种子计算均值、样本标准差、范围及正向种子数。账户场景不是独立训练种子。逐账户及逐种子结果同时公开，避免均值掩盖单一账户贡献。

主要指标为已扣费用与滑点的累计净收益；同时报告Sharpe、最坏账户回撤、费用、滑点、日均总换手、实际现金、目标现金、持仓数与未成交原因。最坏回撤取全部种子/账户的最大幅度，不用平均回撤替代风险门槛。未定义指标保留null，不当作零。

固定报告以下配对差值，单位为百分点(pp)：

- 每格、每seed的random训练后减本模型随机初始化。
- 每格、每seed的random训练后减匹配旧prior训练结果，以及减旧初始化先验。
- 每种机制内的长减短、每种预算内的大减小，以及容量/预算交互差。
- random与prior各自的学习增量之差；初始化起点不同，原始收益差与学习增量差分别解释。
- random相对同频每日动量与20日调仓动量的差值。

完整目标记录可用于选股重叠、股票加现金权重L1、动作随日期变化及目标/实际仓位差。若orders.csv因无订单股票而未包含完整目标，应排除这些日期并报告覆盖数，不能把缺失目标补成零。固定状态动作检查仅为抽查，不冒充全回测轨迹。

三种子与60步开发窗口不足以宣称统计显著或普遍泛化。结果排序不能以幸运seed、单一账户或中间checkpoint替代预定比较。

## 研究候选选择门槛

选择只在全部预定训练与评估完成后进行。比较使用8,192与65,536步固定快照，不按中途验证成绩增加、缩短预算或选择checkpoint。

1. 完整性门槛：新四格均有42/123/2026及四账户，实际步数、源码与数据契约、模型/报告SHA、参数有限性、真实优化器更新、保存加载、初始序列与共享前缀审计通过。缺项或失败只报告失败，不静默删除种子。
2. 风险门槛：候选格全部种子及四账户的最大回撤幅度不超过10%。该值沿用既有开发研究风险门槛，不是未来损失保证。
3. 学习增量门槛：先按四账户平均，再配对对应随机初始化；三个种子的平均净收益增量严格为正，且至少两个种子增量为正。
4. 匹配旧模型门槛：候选格的三种子四账户平均净收益严格高于匹配容量/预算的旧prior格。

通过以上门槛的格仅标记为开发研究候选。按未四舍五入的平均净收益排序；完全平局依次选择较小最坏回撤、较低费用加滑点、较短预算、较小容量。不从一个格内挑出最高收益seed作为整体胜出证据；展示模型选择四账户收益最接近该格三种子均值的代表种子，并注明不是最高收益seed。

若没有格通过门槛，报告“本轮未获得合格研究候选”，不强行选优或自动扩大搜索。即使通过，若仍未超过每日或20日调仓动量，也只能称相对随机初始化/匹配旧prior改善，不能称全面最优或已经证明强化学习优于强规则策略。真实账户发布仍须独立的未见验证及执行适配，本轮不晋升实盘默认。

## 诊断版本与来源差异

旧prior正式矩阵训练源码为`ce2db04`；其额外`critic/*`曾在live buffer清零后采集。旧原始模型、audit、CSV与`summary_raw.json`继续保留，旧派生汇总已排除短快照全部`last/critic/*`及所有`tail_mean/critic/*`。联合比较沿用该排除规则，不恢复无效指标。

新一轮使用`critic_diagnostic_capture=rollout_end_copy_v2`：在rollout_end复制真实observations、returns、values，在实际优化器更新后读取缓存计算额外Critic拟合。新协议保存实际训练提交、逐文件source hash、配置、软件/设备与数据契约；不得把新随机模型标记为与旧prior相同的源码版本。

SB3的`train/value_loss`、`train/explained_variance`、KL及clip fraction和真实优化器步数继续报告。新v2额外诊断可以描述训练轨迹拟合，不与旧被排除的值组成对照；更低value_loss或更高EV不能单独解释收益差，也不能识别Critic的独立因果贡献。

源码差异须在联合报告说明。设计上保留PPO优化、奖励、环境、成本与特征；初始化/Actor机制和诊断采集不同，不能宣称所有代码完全相同。保留原`target_kl`保护并记录实际优化器更新，不因未达到配置轮数而临时关闭保护。
