# 预登记：市场级融资余额增速能不能当 CPPI 的风险闸门（第二版，无分母）

日期：2026-11-14。状态：**预登记，写在任何信号‑收益统计之前**。
这是[第一份协议](market_leverage_protocol_20261114.md)的**继承件**，不是替代：第一份的结论（比率形式 `failed`）
已经写进[结果](market_leverage_result_20261114.md)，本文不重开它。

## 1. 为什么要第二版

第一版的信号是 `r20 = ln(lev_t / lev_{t-20})`，`lev` = 融资余额 / 流通市值。它失败，但留下一个**没测到的样本**：
两市宏观保证金序列从 **2010-03-31** 开始，2015 杠杆牛与股灾都在里面，**分母（流通市值）却只有 2017-01 起**，
所以比率形式永远够不到 2015。

第二版把分母**去掉**：

```
s20_t = ln( balance_t / balance_{t-20} )        balance = 上交所 + 深交所融资余额（元）
```

`balance` 是交易所官方合计（`macro_china_market_margin_sh/sz`，2010-03-31 ~ 2026-11-05，
缺失日由 `stock_margin_szse(date)` 补齐）。**这是一个新变量，所以另立预登记**，而不是在第一份里偷换主变量。

| 用途 | 文件 | 覆盖 |

（余额从 70 万元级起步），这一段不进入检验。

## 3. 变量

### 3.1 信号

```
s20_t = ln( balance_t / balance_{t-20} )      20 个交易日
```

预期方向**为负**：融资余额快速堆积 → 未来更弱。与第一版、与个股层面既有结论（IC −0.0403，取负）方向一致；
这是先定的，不是从数据里挑的。

### 3.2 目标

| 名称 | 定义 |
| --- | --- |
| `fwd20_t` | `ln(close_{t+20}/close_t)`，`000300` |
| `dd20_t` | `-(min_{t<s≤t+20} close_s / close_t - 1)`，未来 20 日**最深回撤幅度**，越大越差 |

### 3.3 窗口

- **主检验：2012-01-03 ~ 2026-06-30**。起始推到 2012 是**事前**决定：前 20 个月是市场诞生期，
  余额在两年里涨了几个数量级，那不是杠杆，是制度上线，留着它等于让一个制度性跳变主导整条序列。
- **P 段（2026-07 起）不读**。
- 分段（T2）用 2012-01~2018-12 与 2019-01~2026-06 两段。

## 4. 判据

### 4.1 有效性守卫（先判；任一不过 → **整轮作废**，既不算通过也不算失败）

| 守卫 | 要求 | 理由 |
| --- | --- | --- |
| **G1 事件覆盖** | 窗口内 `s20 > 0.50`（20 日涨 65%）的交易日 **≥ 20 天**，且 `s20` 的**最大值落在 2014-06-01 ~ 2016-12-31** | 这一版存在的唯一理由就是把 2015 测进去。测不到，就别假装测了 |
| **G2 动量伪装** | `corr(s20_t, 过去 20 日 000300 收益)` **≤ 0.85** | 融资余额随价格涨落是机械的。若相关超过 0.85，"杠杆增速"其实就是过去收益，T1 会退化成动量检验 |

两条都不通过 → `void`，并在结果里写清是哪一条、差多少。

### 4.2 四条判据（**全部通过**才算通过）

| 编号 | 内容 | 门槛 |
| --- | --- | --- |
| **T1（主判据）** | `fwd20` 对 `s20` 回归斜率，Newey-West lags = 20 | 斜率 **< 0** 且 **t ≤ −2.5** |
| **T2（分段）** | 2012-2018 与 2019-2026H1 两段斜率 | **两段都为负** |
| **T3（回撤）** | `dd20` 对 `s20` 回归斜率，NW(20) | 斜率 **> 0** 且 **t ≥ +2.5** |
| **T4（换代理）** | `399317` 重算 T1 | 斜率 **< 0** 且 **t ≤ −2.5** |

四条是合取。**任一条不过即关闭这一族**——包括第一版的比率形式，两者一起关。

### 4.3 诊断（不参与判定）

5 日版本、60 日版本、仅上交所的版本、比率版本（已知 `failed`）、分年斜率。
它们只用来描述"如果换个窗口会看到什么"，不允许被拿来替换主变量。

## 5. 样本记账：这一版**没有任何干净样本**

必须说难听的话：这一版的窗口 2012-2026 **横跨了全部三个样本段**——
设计窗 D（2005-2018）被 CAPM 用过，V（2019-2024）被截面族与第一版用过，R（2025-2026H1）被 E1/E2 的评估用过。
**所以本检验的结果一律标注为 in-sample，不能称为样本外验证。**

- 门槛**不因为**"样本都用过了"而放宽，仍是 t ±2.5。
- 唯一的干净样本 **P（2026-07 起）保持未动**，留给方案层。
- 即便四条全过，结论的上限也只是"值得前向影子跟踪"，**不是"可以接进实盘"**。
