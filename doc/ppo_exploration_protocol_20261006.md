# PPO七方向探索预注册

日期：2026-10-06。状态：设计预注册，尚未运行本轮真实诊断或训练。本文固定探索问题、数据边界、预算及判断方法；代码验收后再绑定源码、数据、配置和模型哈希启动，不能把计划视为完成证据。

## 本轮目的

上一轮整手交易Actor已经消除非完整清仓的微额成交，但长训练平均净收益反而低于短训练。此次先区分信息、表示、动作部署、经历覆盖与目标设计问题，再进行固定预算的结构对照；不以扩大网络或重复训练作为默认答案。

本轮回答七个问题：

1. 现有20个特征是否含有可测的未来收益排序信息？
2. 随机采样训练与确定性部署是否存在显著行为落差？
3. 连续5日输入是否优于单日输入？
4. 将市场编码与账户编码分离是否改善学习？
5. 季度均衡采样能否提升经历覆盖和学习结果？
6. 股票池及资金规模变化时，动作是否仍可执行？
7. 奖励、折扣和截断是否与目标净值及回报计算一致？

## 阶段A：固定低成本诊断

阶段A不得根据结果删选正式cell、修改正式预算或自动增加数据。本节的模型前向、冻结模型回测、账户reset和Ridge拟合均不计作PPO优化步；分别登记次数、种子、日期和计算时间。

### D1：特征信号

三个历史折分别用训练期共享scaler和固定Ridge（`alpha=1`，含截距），预测未来1、5、20个交易日收益。输入为当日收盘可知的原20列特征；目标统一为下一交易日开盘买入至第h个交易日收盘的价格收益。h=1代表下一日开盘至下一日收盘，不是收盘至次日收盘。

标签路径上的价格须有效，训练标签终点不得跨训练截止，验证标签终点不得跨6月30日；不填补未来价格，不以零替代无效标签。各折、各h明确报告训练/验证有效行数、日期数和股票覆盖；跨h样本不同，不能直接把指标差异全归因于期限。

固定报告预测误差、逐日横截面Spearman IC、IC均值/分布、有效样本量及预测高低分组实际收益差。日期内样本过少或目标恒定的IC单独标记，不当作零IC。费用未扣的标签及分组收益只是信息诊断，不是可成交策略净收益。Ridge结果不得用于挑选正式cell或调alpha，也不能把微弱/无信号认定为所有非线性特征均无价值。

### D2：随机训练与确定性部署

冻结上一轮 `ppo_trade_actor_20261005` 的三个seed短/长六份模型，在其训练期内固定 `2026-01-05` 至 `2026-03-31`，各用cash/equal/concentrated/random四账户、K20进行：

- 确定性：类别argmax及有效size均值。
- 随机性：完整原混合分布采样，固定动作种子 `[101,202,303,404,505]`，保留全部结果，不能挑收益最好的路径。

共 `6 * 4 * (1 + 5) = 144` 个完整账户轨迹。账户初始化固定相同种子与起始日期；动作RNG独立，不能改变初始账户。模型参数和优化器均不更新。

报告净ROI、回撤、真实成交/拒绝原因、费用、换手、现金、HOLD及BUY/REDUCE/EXIT比例、原始方向概率和条件size分布。另在相同冻结观察上测方向argmax差距、条件均值/std、采样请求到实际成交的过滤落差，以区分分布差异和后续账户轨迹差异。

完整随机轨迹和确定性轨迹经历不同状态，不是同状态动作因果估计；训练期内回测只是in-sample部署诊断，不是候选效果证据，不建议随机实盘交易，不按本项收益切换默认部署方式。

### D3：输入窗口和编码结构

在训练截止前固定观察做L1、L5及L1市场/账户分离编码的结构探针：检查输入形状、参数数量、有限输出、股票置换等变性、无有效市场股票时的稳定性、持仓变化对市场与账户摘要的作用，以及未来价格/特征扰动不改变当日观察。

正式参数量预期为baseline L1 `126343`、baseline L5 `146823`、split L1 `125063`。实际计数必须验收绑定；split少1280参数，L5多20480参数，均不是精确容量匹配的纯单因素实验。L5使用原MLP展平时间序列，不在本轮偷换为GRU/时序卷积。

所有正式cell统一要求最近5日特征历史完整，使用相同warmup、交易有效性mask和可用日期。L1只读取最后一日特征，但不能因更短窗口额外获得交易机会。市场/账户分离cell只将原行情编码与账户/执行信息编码分离，不增加外部特征、先验或改变合法动作支持。

### D4：采样经历覆盖

对照原 `recent_every=4` 与 `quarter_balanced` 起点算法，起点RNG `seed XOR 0x510A`、账户mode RNG `seed XOR 0xA110`、逐episode账户RNG `SeedSequence([seed,0xACCD,episode_index])` 和K条件RNG `seed XOR 0x7A43` 各自独立。账户按每四episode的独立随机排列覆盖四模式，不同有效股票数不会消耗后续episode的账户/模式随机流。固定三seed的相同episode数量和256步长度做reset覆盖检查，不交易、不更新参数。

报告每日期/年/季度访问次数、唯一决策日期、重复率、近期份额、可用起点和四账户出现次数。季度均衡按可用起点所属自然季度抽样，而不是按未来结果抽样；不足256步的末端起点不合法。账户mode序列和账户随机流必须与算法无关，但不同起点的价格/有效股票不同，实际股数和机会集不保证相同。

正式训练时保留原生episode日期和初始账本。相同步数只控制优化预算，不意味着两采样算法看过完全相同日期；日期覆盖变化正是该cell的干预。

### D5：奖励与截断

现有奖励 `r_simple = NAV_next / NAV_prev - 1` 已含佣金、卖出税、滑点及账本事件；Critic拟合折扣未来奖励，不独立重复处罚费用。核验原始轨迹的 `prod(1+r_simple)-1 = final_NAV/initial_NAV-1`。

若NAV为正，`r_log = log(NAV_next/NAV_prev)` 满足未折扣总和等于净值比的对数。净值为零或负数必须显式处理失败，不使用任意epsilon悄悄改变目标。`gamma<1` 的逐日简单收益或log收益都不与最终复利ROI完全等价；log变换改变PPO目标，不是保持原策略最优性的无害奖励整形。

分别核验真实数据终点terminated、256步人为truncated和SB3 TimeLimit bootstrap：不能把人为截断当零未来价值，也不能越过训练边界读取terminal observation或下一个价格。奖励恒等式仅用环境原始奖励，不将SB3添加的bootstrap量当日收益。保存一段解析可验证的GAE/return对照及Critic回报尺度，区分环境reward、训练return和原始净ROI。

### D6：股票池与资本可执行性

使用旧seed42的8,192步冻结模型，对N=30/100/300与capital=25万/100万/400万，在原训练provider固定索引 `[-52,-32,-12]`、cash/random账户进行54个固定观察行为可行性探针，不推进环境或运行受保护期，不按收益选股。子集选择为原模型contract顺序前N，只建立该子池的独立初始账户，不假装能丢弃真实账户的池外持仓；保存完整股票代码及排序。

N改变时明确创建对应新observation/action space与相同网络结构，再复制共享 `state_dict`；不直接把旧2N动作checkpoint应用到新N，不训练新优化器，加载前后逐参数核验。复用该旧模型原scaler及特征顺序，不能在子集重新拟合后冒充同模型泛化。

报告合法BUY/REDUCE/EXIT机会、仅HOLD股票、最低5000元与整手门槛可行比例、5%单票上限、K20限制、请求/成交过滤和资金缺口。该探针使用原300池的子集，不构成“未见股票泛化”证据；只支持变长输入与资本约束的工程结论。资金变化改变机会集，不能据某一规模的费用或收益选择默认资金规模。

### D7：验证方案

三个历史fold构成回溯性稳定性诊断；正式PPO只在2025fold执行固定结构对照，不凭2026Q2旧结果选择cell。统计先平均每seed四账户，再计算三个seed的均值及样本SD；账户不是独立训练seed，不能冒充12次独立实验。

正式cell使用自身未训练初始化控制、真实保持初始股数、每日动量和20日动量。规则策略必须通过同一 `stock_trade` 整手、最低金额、5%限额、K条件及实际Broker执行路径，披露其请求生成规则、排序、无法成交原因和初始超K持仓处理。若无法在一致机会集下构造规则，先停止并修订协议，不能悄悄回退旧目标权重执行器。

旧2026Q2结果只作带日期、scaler、预算及机制差异的背景，不能与2025Q2正式净ROI配对，也不能宣称新架构在不同年份的差值是因果提升。

## 三个单轴pilot

2025fold、baseline_l1结构、seed42各2048步，从独立相同初始化开始：

| pilot | 唯一变化 | 不变项及限制 |
| --- | --- | --- |
| log_net | 奖励变为净值log收益 | gamma仍.99；原始simple净ROI同时保留 |
| gamma_0995 | gamma变为.995 | simple奖励、GAE.95及其他设置不变 |
| size_anneal | rollout起点人工调整共享log_std | 初始-.7，线性到-2.0；仅size探索，不改类别概率或部署argmax |

size_anneal在训练步t的rollout起点设置 `-.7 + (-2.0 + .7) * clip(t/(2048-512),0,1)`，因此四个rollout起点0/512/1024/1536，最后一个使用-2.0。优化器在rollout更新时仍可更新log_std；记录设定值及实际sigma，不能声称std全程固定。rollout采样期间不再改变std，旧logP必须对应当时的真实分布。

三个pilot共6144实际PPO步，不参与正式候选排名，不通过探索结果自动延长预算或接入默认模型。可与baseline_l1 seed42的2048前缀作相同预算、相同日期/账户流程的描述性单轴对照；只有一个训练seed，不能据此确认稳定增益。

本轮总实际RL预算为 `98304 + 6144 = 104448`；诊断与评估另计。正式快照步数相加不代表实际训练量。CPU/GPU或参数量/吞吐对照如有，只作固定观察性能测量，不把不同架构、共享GPU负载或端到端时间差认定为硬件训练速度结论。

## 候选门槛与报告

正式候选单位为cell及训练预算（2048或8192）。使用主K20：全部三seed四账户最坏回撤不超过10%，四账户先平均后的自身初始化增益均值大于0、至少2/3 seed增益大于0，平均净ROI高于同机制每日动量。合格候选依次按净ROI、更小最坏回撤、更低成本、更短预算及固定cell名称排序；展示seed固定42，不挑幸运seed。无合格候选明确记为null。

候选仅表示本轮回溯性研究通过门槛，不升级实盘/工作台默认。辅助K、D2采样收益、D6资金规模和三个pilot不参加正式选模。没有真实盲测或未复权成交/公司行为支持时，不宣称日常实盘模型已达标。

报告必须包含：七项问题的证据与未解决点；原始净ROI和gross/费用/滑点分解；全seed/账户/K结果；初始化/保持/规则基线；请求与真实成交行为；Critic误差/解释方差及其不能证明策略盈利的限制；日期覆盖与重复率；参数量/Adam/实际步数；元数据、数据/scaler/模型/源文件哈希；失败、偏离和未执行事项。只报告统计分布，不挑最好子集或采样路径。
