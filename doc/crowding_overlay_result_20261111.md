# 融资融券拥挤度作为规避 overlay：配对 t 1.29，不通过

日期：2026-11-11
状态：**未通过**。按[预登记](crowding_overlay_protocol_20261111.md)第 4 节，关闭"融资融券拥挤度"这一族（规避用途）。
工具 `tools/crowding_overlay.py`；产物 `reports/runs/crowding_overlay/`

---

## 1. 问的是另一个问题

融资融券作为**多头选股**已经判过：IC −0.0403（t −4.64）过门槛，但 30 只多头书 −1.06%（t −0.15）不通过。
当时的诊断显示效应集中在空头腿。A 股不能融券，所以唯一剩下的用法是**从已有的书里剔掉拥挤股**。

这次比的是**同一本书剔掉拥挤股之后，比它自己原来好多少**，不是"能不能跑赢基准"。

## 2. 做法（按预登记，一字未改）

- 基础书：E1 反转构造（20 个价格特征全负、秩等权、top 30、跌出前 60 才换、20 日持有）
- 票池：PIT 动态前 1,800（与 E2 完全一致）
- 拥挤：`融资余额` 20 日增速（滞后 1 日）在该日池内分位 **≥ 0.90**
- overlay：这些股票当日**特征置缺失** → 环境自己的有效性规则把它们排除 → 书由下一名次补齐
- 两个臂跑**同一份代码、同一批日期、同一个 broker**，只有面板不同
- 统计：每 20 个交易日一个不重叠块，取两本书的块收益之差，97 个块

被置缺失的面板日占比 **4.0%**（与"前 10% 里只有一部分股票有融资余额"一致）。

## 3. 结果

| 项 | 值 |
| --- | ---: |
| 块数 | 97 |
| 平均块差 | **+0.063%** |
| 年化 | **+0.77%** |
| **t** | **1.29** |
| 正的块占比 | **36%** |
| 基础书年化 | −4.28% |
| overlay 书年化 | −3.55% |

判据：块差 > 0 **且** t ≥ 2.5 → **t 1.29，不通过**。

## 4. 为什么这个"正号"不能信

- **97 个块里只有 35 个是正的（36%）**，中位数差 **0.0000**。
- **收益全部来自 5 个块**：最大的 5 个块差合计 **+0.0646**，而总和是 **+0.0611**。
  也就是说，把最好的 5 个块拿掉，整条"改进"就是负的。
- 最大的两个块是 2019-02-26（+2.03%）和 2024-07-04（+1.79%）——两次都是**恰好有几只拥挤股在那 20 天里大跌**。

**这不叫尾部改善，这叫几个样本点。** 如果它是真的尾部保护，正的块应该集中在基础书最差的那几段；
但实际上基础书最差的 2018 年那几个块，overlay 差值是 **0.0000**——因为融资余额数据从 2019 年才有，
那几段两个臂完全相同。指望它防的险，它根本不在场。

## 5. 判定

**不通过，关闭"融资融券拥挤度"这一族。**

到这一步，融资融券这条线上的三个用法全部结束：

| 用法 | 结果 |
| --- | --- |
| 截面 IC | 过（−0.0403，t −4.64） |
| 多头选股 | 不过（−1.06%，t −0.15） |
| 规避 overlay | 不过（+0.77%，t 1.29） |

**唯一通过的仍然是那个不能直接交易的 IC。** 这是一个完整、干净、但令人失望的负结果。

## 6. 不能主张什么

- 不能把"t 1.29 + 正号"说成"有苗头"：中位数是零、正块只有 36%、去掉 5 个块就翻负。
- 不能换个阈值（0.8 / 0.95）再试一次——那正是预登记里禁止的动作。
- 不能把这套逻辑换个标的（股东户数、龙虎榜）再套一遍而不重新登记：
  每个源都要有自己的预登记，判据同样写在"它实际作用的那一层"。
