## 2. 主检验：沪深300

`σ* = 20.9%`（设计窗 σ20 中位），规则平均暴露 **0.943**，触发上限 1176 天、**触发下限 0 天**（共 1456 天）。

| 指标 | 规则 | 同暴露对照（恒定 0.943） |
| --- | ---: | ---: |
| 年化收益 | +3.44% | **+4.37%** |
| 年化波动 | 18.07% | 18.19% |
| Sharpe | +0.190 | **+0.240** |
| 最大回撤 | **−46.1%** | −43.6% |
| Calmar | **+0.075** | **+0.100** |
| 累计净值 | 1.2242 | 1.2919 |
| 累计换手 | 8.11 | 1.63 |
| 累计成本 | 1.23% | 0.23% |

同期沪深300 本身：+32.51%（年化 4.81%）、波动 19.30%、最大回撤 −45.60%。

三个必须点出来的事实：

1. **回撤变大了，不是变小。** 规则 −46.1%，对照 −43.6%，指数本身 −45.6%。一个号称按风险缩放的规则，在最需要它的地方**比不加修饰还差**。这是判据 1 失败的直接原因。
2. **不是成本杀的。** 累计成本 1.23%，六年只有 1.23 个百分点；而收益差了 5.6 个百分点。规则是在**信号层面**输的，不是被摩擦吃掉。
3. **下限一次都没触发。** 我上一轮预警过"撞到 0.20 下限就变成真实择时"，实测触发 0 天——规则全程只是一次**温和的仓位倾斜**（平均 0.943），而即便是这么小的动作，方向也是错的。

## 3. 一致性检查：300 只等权（受幸存者偏差影响）

| 指标 | 规则 | 对照 |
| --- | ---: | ---: |
| 年化收益 | +20.60% | +21.23% |
| 最大回撤 | −23.3% | −22.8% |
| Calmar | +0.884 | +0.930 |

方向与指数一致：规则略差。但请注意这个年化 21% 与指数 4.81% 的差距——**那不是策略能力，是 2026 年沪深300 名单回填到 2019 年的幸存者偏差**。任何在股票池上做的择时评估都在和一个虚构的收益序列比较，这也是我把主检验放在指数上的原因。

## 4. 敏感性：不是节奏或标的的偶然

| 变体 | Calmar（规则 / 对照） | 判定 |
| --- | ---: | --- |
| 每日刷新 | 0.064 / 0.100 | 未通过 |
| **每 20 日刷新（登记口径）** | **0.075 / 0.100** | **未通过** |
| 每 60 日刷新 | 0.081 / 0.100 | 未通过 |
| 上证综指，每 20 日 | 0.125 / 0.186 | 未通过 |

四个变体全部失败，且差距量级相近。这不是选错刷新频率或选错指数。

## 5. 为什么失败：机制的收益方向反转了

诊断（描述性，不用于再调参）：

| 窗口 | σ20 与未来 20 日收益的相关 | 低波动组 | 中 | 高波动组 |
| --- | ---: | ---: | ---: | ---: |
| D 2005–2018 | **−0.081** | **+1.81%** | +0.81% | +0.87% |
| V 2019–2024 | **+0.012** | **−0.04%** | +1.11% | +0.32% |

阶段一验证的是"波动可预测"——那件事在 V 段依然成立。但**波动高低与后续收益的关系在 V 段翻转了**：D 段低波动之后是最好的行情（+1.81%），V 段低波动之后是最差的（−0.04%）。

规则在低波动时满仓、高波动时减仓。D 段这样做是对的，V 段正好反过来：2019–2020 高波动的上涨被减仓，2021–2023 低波动的下跌被满仓。

这也解释了为什么回撤反而变大：2022 年初的急跌中，20 日窗口加 20 日刷新让规则**慢半拍**——跌完之后才减仓，反弹之后才加仓，做成了"高卖低买"的反面。

## 6. 不做什么

按规划第 8 节，只有在"失败可归因于 **D 段内可独立观察到的结构性原因**"时才允许用保留窗 R 复测。本轮不满足：

- 失败原因是**波动-收益关系的符号在 V 段反转**；
- 这个反转在 D 段内看不到，它是 V 段的新事实；
- 用它去改规则，等于用 V 段结果重新设计，再拿 R 段验证——那是两次拟合。

因此**不动用 R 段，不重启 L1**。阶段三（趋势）已在阶段一出局，阶段四（宏观否决）的上层前提（L1 或 L2 存在）也已消失。

## 7. 这一轮实际得到了什么

- **波动可预测是真的**（自相关 0.71），但**可预测 ≠ 可获利**：需要"低波动后续收益更好"这个额外假设，而它的符号不稳定。
- 择时规则的失败**不是成本问题**，六年只有 1.23 个百分点的摩擦。
- 300 只股票池的 21% 年化里有很大一块是幸存者偏差——**这可能是本轮最有价值的一个数字**，因为它同时否定了"用股票池检验择时"这条路。
- 我们花掉了唯一一次验证机会，换回一个机制清楚的负结果。
