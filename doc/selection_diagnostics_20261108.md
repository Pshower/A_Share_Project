## 1. 问题：一个基准被拿去回答两个不同的问题

“策略有没有增量”和“不买这个策略该买什么”是两个问题，需要的基准不一样。用同一个对象回答，
就会出现这次的情形：**一个含前视选档的面板等权组合，被当成了实盘可投资的 beta 底座。**

| 问题 | 需要什么基准 | 用错的后果 |
| --- | --- | --- |
| 策略在池内有没有选股增量 | **同池、同调仓日、同本金、同整手约束**的可执行等权 | 把整手留存的现金、规模倾斜记成策略的本事 |
| 不买它该买什么 | **真实指数**（`000300` / `000905` / `000982`） | 用不可执行的组合夸大替代品的收益 |

## 2. 规范

### 2.1 池内选股归因基准

必须同时对齐五件事，缺一不可：

1. **同一股票池**（例如 `research_v3` 的 298 只）；
2. **同一调仓日与调仓周期**；
3. **同一本金**（例如 300 万）；
4. **同一整手约束**（100 股/手）与**同一费用**（佣金万三、最低 5 元、印花税千分之五、双侧滑点 10bp）；
5. **同一持仓只数**的随机等权组合中位数——这是"没有选股能力"的零假设。

**只有第 5 条能把"选股"从"选到多少个名字"里分离出来。** 一个 top 30 的策略，
如果随机抽 30 只的中位数本来就赢等权，那策略的超额不是选股，是持仓只数。

### 2.2 实盘可投资 beta 底座

- 用**真实指数**：大盘 `000300`、中盘 `000905`、等权 `000982`。
- **禁止**把以下两样当作可投资基准：
  - 含**前视选档**的面板组合（`largest` / 中位市值分档）；
  - **不可执行**的全市场 1/N（4,200 只等权在 100 万本金下买不起整手）。

### 2.3 整手不是小事（实测）

用 `tools/selection_diagnostics.py` 在同一面板上模拟，300 万本金：

| 组合 | 持仓数 | **留存现金** |
| --- | ---: | ---: |
| 随机 30 只 | 30 | **32%** |
| 全池等权 | 299 | **65%** |

**300 万买 299 只等权，平均 65% 的资金根本投不出去。** 所以"1/N 组合"在中小本金上不是一个可执行对象，
它是一串数字。任何拿它当基准的报告都必须披露这个留存率。

## 3. E1 的三项诊断（建议 3 的具体化）

E1 是[研究方向复核](research_direction_20261107.md)收敛出的唯一 go/no-go 实验。它的主判据不变，
但必须同时输出以下三项，否则无法区分"选股有效"与"选到了小盘"：

| 诊断 | 怎么算 | 判据 |
| --- | --- | --- |
| **① 市值分位** | 每期入选 top 30 在 298 只池内的**流通市值分位均值**，首三分之一对末三分之一 | 若从 ~0.5 漂到 <0.35，说明是规模漂移 |
| **② 规模归因** | 对 `000300` 与 `000905 − 000300` 做双因子回归，看 α 与 β_size | β_size 显著为正 → α 里混着规模 |
| **③ 随机对照** | 同本金、同 30 只、同调仓日、同缓冲节奏的随机组合，抽样 200 次 | 策略净超额须高于随机中位数，且落在 p90 之外 |

**这就是建议 3 的全部内容，已经实现为工具**（见第 4 节）。

### 3.1 为什么②必须做

在同一面板上用**随机** 30 只（从市值前 300 名里抽）测一次双因子回归：

```
alpha  +0.0003 (t +1.91)   beta_market 0.690   beta_size +0.231 (t +11.14)
```

**一个完全随机的组合，规模暴露就显著到 t = 11.14。** 因为它排除了巨型股，
对 `000905 − 000300` 天然正暴露。**任何只做单因子 α 的池内归因，都会把这 0.23 的规模暴露记成 α。**

### 3.2 为什么③必须做

同一组合的随机抽样（30 次）：

```
random median +9.80%   p10 +6.04%   p90 +11.24%
```

**随机 30 只的年化中位数就能到 +9.8%，p10–p90 跨度 5.2pp。** 一个策略如果净超额落在
这个区间里，它证明不了任何事——**不是因为它不好，是因为这个池子在这个持仓只数下本来就这么分散。**

## 4. 工具

```powershell
python -B -m tools.selection_diagnostics --books selections.json --capital 3000000 --draws 200
```

`selections.json` 的格式：

```json
{"rebalances": [{"date": "2019-01-02", "codes": ["600519", "000858"]}, ...]}
```

输出四块：

| 字段 | 含义 |
| --- | --- |
| `selected` | 该选择的年化与**留存现金比例** |
| `executable_equal_weight` | 同池可执行等权的年化与留存现金 |
| `random` | 随机对照的中位数、p10、p90、策略击败比例 |
| `size_percentile` | 市值分位（均值、首/末三分之一） |
| `attribution` | 单因子与双因子的 α、β_market、β_size 及其 t |

## 5. 不能主张的

1. **这套工具不能把 E1 变成显著的。** 它只是让"显著"这个词有意义。
2. **随机对照的分布依赖池子和本金。** 换池子、换本金，p10–p90 就变，必须重算，不能引用本文的数字。
3. **留存现金比例是对 300 万本金说的。** 本金越大留存越低，但单只权重也越小，冲击成本接管。
4. **本文没有跑 E1**，也没有新数据。所有数字来自 `data/clean/panel_full` 上的构造性演示。
