# 训练日期与本地行情关联

更新：2026-09-26。新工作台任务采用日期交集；已有模型、数据版本和历史报告不改写。

## 1. 日期来源

训练页原先只显示数据版本的固定训练 / 验证截止日，选股后不重新计算。现在通过只读本地预检，同时显示：

- 建版时原始下载覆盖：来自该版本的逐股 source_audit，可能长于清洗版本的研究区间。
- 版本内实际价格覆盖：从已保存的 prices.parquet 中检查有效开盘、收盘和成交量。
- 特征及观察窗口有效起始：从 panel_data.parquet 检查全部特征及 lookback 窗口，指标预热期不计入训练。
- 所选股票的共同特征覆盖，以及实际采用的共同连续训练起止日。

价格及特征文件须通过版本 manifest 哈希检查。原始覆盖是建版时记录，原始文件图表会另外校验当前文件哈希；不能用修改后的原文件冒充旧版来源。

## 2. 多股取交集

新工作台任务默认 `training_date_policy=intersection`。每个日期必须满足所有所选股票价格有效、每只股票全部特征完整、所需观察窗口完整。

保留原始日历顺序，不把中间缺数据的日期删除后拼接成“下一交易日”。实际训练使用截至该版本最后训练记录的共同连续区间；若区间中断，从中断后重新满足窗口条件的位置开始。有效区间不足两条记录时拒绝提交。

为保留训练 / 验证隔离和 scaler 契约，不会把训练截止日期自动移入验证期，也不会把截止日期向前缩短后仍使用包含更晚训练数据的 scaler。若原训练截止日没有共同数据，页面指出具体股票，要求调整选股或构建新的日期划分及 scaler。

页面、提交 API 和训练 worker 使用同一计算规则。worker 重新从已校验的本地产物计算，并将 `training_date_policy` 与 `train_interval` 记入新模型契约，防止只改页面而实际仍按“任一股票有数据即可”训练。

不含此字段的历史任务 / CLI 配置维持原 masked 行为，用于复现；不会因此改写旧轻量实验结果。新工作台页面不提供切回旧策略的开关。

### 当前数据的实际例子

`research_v3` 训练截止为 2022-08-05，但默认轻量池内：

| 股票 | 首个完整特征日 | 在该截止日是否可参与严格交集 |
| --- | --- | --- |
| 301165 | 2023-02-21 | 否 |
| 603296 | 2023-11-08 | 否 |

因此，默认轻量 32 股在新交集规则下会被阻止，而不是悄悄丢掉两只股票或继续显示固定训练日期。这不是 GPU 故障；可调整选股，或利用完整已下载数据构建更晚日期的新版本，重新确定训练 / 验证划分。旧实验使用缺失掩码，不能追溯宣称它已经按严格交集训练。

## 3. 联网行情与已有数据

此前历史图表仅列出 `data/online/history` 快照，不会自动展示旧 `data/raw` 文件。现在“历史行情来源”可选择：

- 已下载快照：按快照股票和价格口径显示，原逻辑保持。
- 本地数据版本原始行情：从数据版本配置定位唯一原始来源文件，校验源文件哈希、股票代码和数据口径后显示，不联网。

旧研究版本的原始来源只有 HFQ，不伪造未复权数据。成交量按该版本登记的倍率转换，避免已为“股”的新快照再次乘 100。无效价格绘制断点，不当作 0 参与均线计算。

训练页“已下载数据与日期交集”可跳转到该版本的原始行情，也列出同代码的下载批次。匹配代码仅表示相关数据存在，不代表已并入当前训练版本。

从在线批次构建的新版本保留 `source_history_id`。批次审计区会列出由它构建的训练版本；未关联时明确显示“尚未构建”。完整原始下载需经过清洗、特征计算、训练期 scaler 拟合和版本发布，才出现在可训练数据版本中。

原始图表可能展示超出当前版本研究末日的已存数据，图表标为“数据版本原始来源”；训练不会因此自动使用这些日期。要扩展训练范围，仍需显式构建新版本。

## 4. 接口与验收

- `POST /api/datasets/{id}/coverage`：本地日期交集预检，输入 codes / lookback，不入队、不联网。
- `GET /api/market/datasets/{id}/bars?code=...`：哈希核验后的本地源行情。
- 覆盖单股 / 多股、窗口变更、内部缺口、不足两条、截止日缺失、实际训练范围一致、原始文件篡改拒绝等检查。
- 完整离线回归：105 项通过，13 项外部联网测试排除；3 项既有非失败警告。
- 8 项浏览器回归通过，包括选股 / 窗口日期联动、缺失股票拒绝、本地行情跳转、CUDA 无训练配置检查及既有批量 / 行情页面。有效股票配置检查的实际起止日与新契约一致；本轮不运行正式训练，不下载行情，不更改 scaler。
