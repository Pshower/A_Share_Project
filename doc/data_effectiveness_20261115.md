# 这些数据到底有多有效：一张算得出来的评分卡

日期：2026-11-15。工具 `tools/data_scorecard.py`，产物 `reports/runs/data_catalog/scorecard.json`。
上游：[数据源普查](data_sources_20261114.md) 回答"能不能取到"，本文回答"值多少"。

## 0. 结论先放这里

| 等级 | 含义 | 条目数 |
| --- | --- | ---: |
| **A（10.0）** | 检验过、有效、且已经在用 | 2 |
| **B（4.6–7.1）** | 有统计信号，但经济上不够/只能当风险信息 | 3 |
| **C（2.3–3.3）** | 检验过，与零无法区分 | 7 |
| **D（0.0）** | 拿不到 | 1 |
| **U（不评分）** | **从未检验——不知道，不是低分** | 4 |

**只有两项是 A：利率（国债收益率/LPR）和 ETF 净价/分红。** 其余能赚钱的用法，全部是从这两项派生出来的执行细节。

## 1. 评分规则（先说清楚，再看表）

三个维度分开算，**不加成一个"质量分"**——否则会看不出是哪一项失败：

| 维度 | 权重 | 取值 |
| --- | ---: | --- |
| 证据强度 | 0.5 | A=10、B=6.5、C=2.5、D=0、**U=不评分** |
| 可交易性 | 0.3 | 是=10、部分=6、否=0、**未知=不评分** |
| 可得性 | 0.2 | 由探测记录算出：最新 ≤5 个交易日=10、≤45 天=7（月频）、无日期列=5、应答但无样本=6、被拒=0 |

**两条硬规则：**

1. **未检验不给中间分。** 给"没测过"打 5 分，等于把它排在"测过且失败"的家族前面，那是错的。
   所以 U 类的 `effectiveness` 是 `null`。
2. **证据强度只用本仓库自己的预登记结果**，不引用外部文献的"通常认为"。每个 B/C 级都附报告链接。

## 3. 五个读法

### 3.1 A 级只有两项，而且都是"已经在用"的

利率和外币净价/分红之所以是 A，不是因为它们神奇，而是因为**它们已经被用在正在跑的系统里**：
方案的预期收益由 carry 决定，账本的每一笔成交与分红都由 ETF 价格验证过。
**A 级的含义是"已落地且无争议"，不是"能预测市场"。**

### 3.2 B 级里最值得记住的是融资融券：4.65 分

它的 IC 是**全仓库唯一过了预登记门槛**的东西（−0.0403，t −4.64，覆盖 77%），
但做成 30 只多头书，扣成本后 **−1.06%（t −0.149）**。

**这是本仓库最重要的一对数字**：统计显著（t −4.64）与经济可用（t −0.15）之间隔着成本、集中度与持有期。
它说明"IC 门槛 0.031"对"30 只多头"这种用法**偏松**——而这个结论是数据给的，不是推测。

### 3.3 C 级七项，形态各不相同，但结果一样

- 股东户数：**方向极稳（六年同号）、t 很大（−7.01），但量级只有门槛的 91%**；
- 龙虎榜：IC 差 0.0002 到门槛，**t 只有 0.83**——"差一点"是幻觉，真相是没信号；
- 业绩报表：IC 0.0041，**门槛的 13%**，连方向都谈不上；
- 价格特征族：单个最弱，组起来测试窗 −4.97%；
- 市场级杠杆：两轮四判据，全部 t 在 ±0.6 内。

**共同点：不是"没测"，是"测了、而且明确不行"。**

### 3.4 U 级四项：不知道，不等于中等

这是本文最容易被误读的一栏。资金流只有 0.42 年数据；宏观月度、指数 PE、行业/持仓从未在本仓库检验。
**它们既没有被证明有效，也没有被证明无效**——所以不给分。

其中两项有清楚的可测路径（指数 PE 对多年收益、宏观对 regime 分档），见下一节。

### 3.5 D 级不是"不重要"，是"拿不到"

分钟线、实时快照、历史 IOPV。前两项被数据源拒绝，第三项**结构上就不对外发布**（只能从今天开始累积）。
这与"测过无效"是两回事：**未来的网络或 provider 变化可能让它们重新变得可得**。

## 4. 由此得到的三个判断

1. **现在的收益来自 beta 与执行，不来自"信息"**：A 级两项都是定价与执行，不是预测。
   这与整个项目"接受 beta + 风控"的定位一致，也是 alpha 关闭后的诚实表述。
2. **想提高收益，唯一没被堵死的路是"更便宜/更准的执行与风险预算"**：
   ETF 折溢价（B）、估值（B）、利率 regime（A 的延伸）都属于这一类。
3. **要再开一轮研究，只能用 U 级里那两项有机制基础的**（指数 PE 的多年期含义、宏观 regime 分档），
   并且必须先写预登记与判据；C 级的七项不必再试。

## 5. 复现

```powershell
python -B -m tools.data_scorecard     # 读两份探测结果，算分，写 scorecard.json
python -B -m pytest -q tests/test_data_scorecard.py
```

评分口径写在代码里（`WEIGHTS`、`GRADE_SCORE`、`TRADABLE_SCORE`），改口径必须同时改本文，
否则分数与解释会脱节。
