# A 股日频强化学习交易项目实施安排

更新日期：2026-09-24

本文基于当前源码和本地数据检查结果，给出后续实施顺序。`pipeline.md` 保留为总体路线图，本文聚焦可执行任务和验收条件。已实施内容单独标记，其余任务仍为计划。

## 1. 当前状态

- 已有 AKShare 数据接口、本地缓存、批量下载、清洗、技术指标、标准化和时间切分脚本。
- 已有 `MarketDataProvider` 与 `Portfolio`，尚未组成完整交易环境。
- 本地原始数据报告覆盖 300 只股票；清洗长表覆盖 298 只股票，共 515,665 行。
- 面板覆盖 2017-01-03 至 2024-12-31，包含 1,943 个交易日、298 只股票、32 个字段。
- 原始数据报告覆盖到 2026-06-26，但预处理入口截止于 2024-12-31。文件名中的年份与实际数据范围不完全一致。
- 尚无基线策略、智能体、训练循环和策略回测闭环；配置目录为空，缺少依赖清单。

以上数字是本轮检查时的本地数据快照，不代表后续重新生成的数据。

## 2. 实施原则

- 先修正数据和记账，再建立基线回测，最后接入 PPO。
- 保留原始数据；修正后的特征产物另存版本，验证后再切换默认输入。
- 明确区分模型特征、估值价格、成交价格和可交易状态。
- 所有拟合统计量只使用训练区间，验证集和测试集复用训练参数。
- 每阶段以离线测试和本地样本验收，不执行联网测试或自动重新下载。
- 先完成单进程研究闭环，暂不引入消息队列、服务化、多智能体和实盘接口。

## 3. 阶段一：修正数据管线（最高优先级）

涉及：`src/data/`、`configs/`、`tests/`。

### 任务

1. 修复 `data_socket.py` 中向 `_fetch_with_cache()` 传入未声明关键字参数的问题，以 mock 验证参数转发、缓存和重试。
2. 下载汇总修正（部分完成）：
   - [x] 修复首只股票重复且混入不复权数据：删除循环前的不复权请求，每只股票仅请求一次后复权数据，收集后统一合并；个股文件与汇总文件使用同一批数据。
   - [x] 增加离线回归测试，检查请求次数、复权参数、汇总内容、个股文件以及空名单不覆盖已有汇总。
   - [ ] 统一股票代码契约、日期配置与文件命名。当前保留原文件名，以兼容已有本地数据读取流程。

   - [x] 使用 `python src/data/rebuild_history.py` 从 300 个本地个股后复权 CSV 重建历史汇总，不调用数据接口，不修改个股文件。汇总从 622,381 行更新为 622,246 行，覆盖 2017-01-03 至 2026-06-26；股票与日期组合无重复，写入后回读与源数据合并结果一致。

   历史汇总路径：`data/raw/stock_data_hs300_2017_2024_hfq.csv`。该数据文件按现有 `.gitignore` 规则保留在本地，不纳入 Git；离线重建脚本纳入版本控制。当前预处理读取个股文件，不依赖该汇总文件，因此本次未重新生成清洗数据。

   验证结果：`python -B -m pytest tests/test_download.py -q -p no:cacheprovider`，4 项测试通过，全部使用模拟数据，无网络请求；包含本地重建以及源文件缺失时保留已有汇总的检查。
3. 定义数据契约：以 `(date, code)` 为唯一键，股票代码使用字符串，模型特征采用显式白名单，排除原始中文“股票代码”等标识列。
4. 将价格表与标准化特征表分离。后复权价格可供研究收益计算，但真实成交、整手和涨跌停模拟需要明确原始价格及复权因子的对应关系，不能直接将复权价格视为真实成交报价。
5. 先按交易日期确定训练、验证和测试边界，仅在训练区间拟合标准化参数，并保存特征顺序、日期边界及参数版本。
6. 处理指标预热期、上市前空白、停牌和数据缺失。滚动特征只能使用当前及历史数据；验证和测试区间允许使用此前历史作为预热输入。
7. 定义有效样本和可交易掩码。价格前向填充仅可用于已有持仓估值等明确用途，不能据此认定停牌或缺数股票可交易；禁止用后向填充补历史特征。
8. 查清清洗结果缺失的两只股票，并记录过滤原因。当前固定的 2026 年股票名单用于早期历史研究存在选择偏差，应记录限制；动态历史成分股作为后续数据增强任务。
9. 修正质量报告口径：全局标准化并不要求每只股票分别满足均值为零、标准差为一。
10. 建立最小依赖清单和统一配置，记录日期、股票池、特征、数据版本及路径，逐步替换硬编码。

### 验收条件

- 同一股票同一天无重复，代码格式一致；交易价格为有限正数，特征与价格的日期和股票顺序一致。
- 修改验证或测试区间的数据，不改变训练区间的标准化参数和特征结果。
- 输入模型的有效观测没有 NaN 或无穷值；无效资产通过掩码明确标识。
- 股票标识列不进入数值特征；缺失股票与缺失日期均有可解释记录。
- 使用本地数据生成版本化长表、面板、切分结果和质量报告，无需访问网络。

## 4. 阶段二：完善记账与交易环境

涉及：`src/envs/market.py`、`src/envs/portfolio.py`，新增成交模拟和 Gymnasium 环境模块。

### 任务

1. 让市场数据提供器分别返回特征、估值价格、成交价格和掩码，支持按数据集日期边界读取。
2. 修正交易成本计算：按各资产买卖金额绝对值之和计费，避免买卖抵消后费用为零。
3. 校验权重维度、有限值、非负性和总仓位；现金不足时调整实际成交，费用计入可用现金约束。
4. 先卖后买，处理买入整手、可卖数量和 T+1；记录订单、成交、费用、现金及持仓变化。
5. 明确时间顺序：交易日 t 收盘后观测和决策，t+1 开盘成交，t+1 收盘估值；初始版本每日最多调仓一次。
6. 为停牌、涨跌停、滑点和成交量约束预留并实现清晰接口。现有数据不足的约束须显式标注为简化假设，不能宣称已经真实模拟。
7. 实现 `reset()`、`step()`、观测空间、动作空间及终止逻辑。首版奖励采用扣费后的组合收益，避免重复扣减成本。

### 验收条件

- 用可手算的两只股票短序列验证现金、持仓、市值、费用与收益。
- 等额换仓仍产生费用；计入费用后现金不透支，持仓不为负。
- 无交易且价格不变时净值不变；价格不变且发生交易时净值仅减少对应成本。
- 当前决策不能读取下一交易日价格；最后一个交易日正确终止。
- 被掩码禁止的交易不成交，成交与未成交原因可追踪。

## 5. 阶段三：建立基线与回测闭环

涉及：新增 `src/backtest/`、基线策略模块和报告输出目录。

### 任务

1. 实现现金持有、等权买入持有、定期等权再平衡和简单动量策略。
2. 所有策略共享交易环境、成本、股票池和日期口径，避免基线与模型待遇不同。
3. 输出每日净值、收益、回撤、换手率、交易成本、持仓以及未成交记录。
4. 计算累计收益、年化收益与波动率、最大回撤、Sharpe 等指标，明确定义年化与换手口径。
5. 使用本地指数数据时加入指数基准；数据不存在时记录缺口，不自动联网获取。
6. 保存实验配置、随机种子、代码版本、数据版本和结果路径，形成一条可复现的本地运行命令。

### 验收条件

- 在固定数据上重复运行得到一致结果。
- 净值可以由现金和持仓逐日重建，累计成本可以与成交明细对账。
- 至少完成一次验证集基线回测；最终测试集不用于选策略和调参。
- 报告清楚标注固定股票池偏差及尚未实现的交易约束。

## 6. 阶段四：接入 PPO

前置条件：阶段一至三通过验收。

### 任务

1. 使用成熟强化学习库实现 PPO，首版采用简单 MLP 编码器，暂不增加 Transformer 或多智能体结构。
2. 固定资产及特征顺序，将组合权重、现金比例和有效资产掩码纳入观测；明确动作到目标权重的映射。
3. 先用短区间完成训练、保存、加载和确定性评估冒烟验证，再扩大训练规模。
4. 仅用训练集更新模型，验证集选择模型和参数，配置冻结后评估测试集。
5. 与阶段三基线比较收益、风险、换手和费用；保存模型及其依赖的数据与特征版本。

### 验收条件

- 训练与推理使用一致的特征顺序和标准化参数。
- 保存、加载后的模型在相同观测下给出一致的确定性动作。
- 输出与基线同口径的评估报告；不会仅凭训练收益判断模型有效。

## 7. 阶段五：稳健性验证与后续扩展

- 增加滚动训练和样本外回测，每个窗口单独拟合标准化参数。
- 检查不同随机种子、手续费和滑点假设下的结果。
- 补齐历史成分股、上市退市、停牌、ST、涨跌停及公司行为数据，完善动态股票池与真实交易约束。
- 在基本数据和交易约束可靠后，再评估监督学习基线、复杂编码器和风险惩罚奖励。
- 模拟盘、任务调度和实盘适配单独立项，不作为当前研究闭环的前置条件。

## 8. 建议提交顺序与离线验证

每批提交应有清晰范围，并附对应离线验证结果：

1. 数据接口参数转发与下载汇总修正。
2. 数据契约、价格与特征分离、训练区间标准化。
3. 缺失值、掩码、质量报告与本地产物版本化。
4. 组合记账、交易费用及资金约束。
5. 成交模拟和 Gymnasium 环境。
6. 基线策略、回测报告和实验记录。
7. PPO 训练与评估入口。

测试使用 mock 数据源、临时目录、合成行情及已有本地数据。原有联网测试应标记为单独的集成测试并默认排除；连接失败必须通过断言或异常明确失败，不能仅返回 `False`。本安排不包含执行联网测试或重新抓取行情。

下一批优先完成第 1 项，并为第 2 项确定数据 schema；在数据契约验收前不开始模型训练。
