# 信息源第 5 条：股东户数变化 —— 六年全部同号、t −7.01、覆盖 89%，但**没过量级门槛**

日期：2026-11-11
状态：**未通过预登记门槛**（IC 0.0282 < 0.031）。但这是仓库里第一次出现"显著性极强、覆盖极高、只差效应量"的信号，
失败方式与之前每一个候选都不同，值得单独记一笔。
工具 `tools/gdhs_ic.py`；产物 `data/online/gdhs/`、`reports/runs/gdhs_ic/`

---

## 1. 为什么值得测这一条

清单里 8 个源，此前测过的几个都卡在**覆盖**上：解禁 4.0%、龙虎榜 0.80%。
股东户数是唯一一个**同时**满足下列三条的：

| 约束 | 这一条 |
| --- | --- |
| PIT 可得性 | 接口直接给**公告日期**（不是统计截止日），披露滞后 6–8 周，天然时点正确 |
| 覆盖率 | **88.7%**（每季度全市场一次性返回，不是事件型） |
| 成本 | 25 个季度 = **25 次调用**，两分钟下完 |

## 2. 事前定下的两件事

- **用哪个量**：`股东户数-增减比例`（相对上一期快照的百分比变化）。户数的**水平**主要由股价和流通盘决定，
  **变化**才是信息。
- **方向**：**负号**——户数下降 = 筹码集中 = 看涨。写在运行之前，因为这条没有像解禁那样的机械方向。

PIT 处理：信号从**公告日**当天起可用，绝不使用统计截止日；超过 **250 个交易日**未更新的值作废，
避免停止披露的股票永远挂着一个旧数字。

## 4. 判定：不过，但失败的方式不一样

预登记判据是 **|IC| ≥ 0.031 且 |t| ≥ 2.5，方向为负**：

| 判据 | 结果 |
| --- | --- |
| 方向为负 | ✅ |
| \|t\| ≥ 2.5 | ✅ **7.01**，远超 |
| \|IC\| ≥ 0.031 | ❌ **0.0282**，只有门槛的 **91%** |

**结论：未通过。** 门槛是写在运行之前的（[信息源清单](information_sources_20261108.md) 第 4 节：
多重检验后抬到 t ≥ 2.5，IC 门槛 0.031 来自"20 日持有、8 年样本下够组合层 t = 2"），
**现在不改它**——为一个差 9% 的结果下调门槛，就是事后调参。

### 为什么这条失败值得单独记

之前每一个候选都是"**方向对、量级不够、而且根本测不准**"（业绩预告 t 0.98、龙虎榜 t 0.83）。
这一条是"**测得很准，只是幅度刚好不够**"：

- t −7.01 意味着这个 IC 几乎不可能是零；
- 六年同号意味着它不是某一段的产物；
- 89% 覆盖率意味着它能给整个池子排序，而不是只覆盖一个角落。

**它没过的不是"有没有这个效应"，而是"这个效应够不够撑起 30 只的账本"。** 这两件事在门槛上被写成了同一个
数字（0.031），但它们不是一回事。

### 它不是价格特征的另一种刻度

按资金流那一轮的规矩（[资金流共线性](fund_flow_20261108.md) 用 |r| < 0.5 判断冗余），把信号与 20 个价格特征、
以及流通市值做截面秩相关，取各期平均：

| 对照 | 平均 \|r\| |
| --- | ---: |
| momentum_60 | 0.084 |
| volatility_60 | 0.080 |
| close_ma_ratio_60 | 0.076 |
| 其余 17 个特征 | ≤ 0.073 |
| **流通市值** | **0.083** |

**全部低于 0.1。** 所以它既不是反转、也不是市值或波动的另一种说法——这是一条**正交**的信息，
这在本仓库测过的信息源里还是第一次（限售解禁覆盖 4%、龙虎榜 0.8%、业绩预告 20.4%）。

## 5. 因此不主张什么

- **不主张它可用。** 没有过预登记门槛，就不能进入任何组合，也不能写进方案。
- **不为它下调门槛、不换窗口重测。** 若要继续，唯一正当的做法是**新写一份预登记**，把"如何把 0.028 的 IC
  变成能覆盖成本的组合"作为待检验的假设（例如更宽的持仓数、与价格特征正交化之后的残差、按披露节奏建仓），
  并规定失败即关闭。
- 也不能拿它去救已经关闭的价格特征族——那是把两个失败拼成一个没测过的东西。
