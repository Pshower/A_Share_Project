# PPO 那条线留下了什么有价值的东西

日期：2026-11-14。范围：2026-09-25 ~ 2026-10-18 的 RL 研究（轻量 PPO、容量矩阵、随机初始化、
delta actor、trade actor、探索、归因、market summary、priority rank、timing 系列、counterfactual 两轮），
以及 2026-11-07 的三次事后诊断（先验归因、1/N vs CAPM、超额奖励终版）。

代码在分支 `research/supply-pressure`；`reports/runs/` 的本地产物已于 2026-11-14 被我误删
（见 [`reports/README.md`](README.md)），所以下面的数字**只能从 `doc/*.md` 的报告里复核**。

## 0. 一句话

**PPO 没有产出策略，但它产出了三样别处拿不到的东西：一个结构性发现（整手与现金拖累）、
一套"证明为零"的方法（先验归因 + β 剥离 + 随机对照）、以及一张"这些方向不必再试"的清单。**
这三样都直接塑造了现在这条 ETF + CPPI 的路线。

## 1. 结构性发现：1,000,000 元买不完 300 只股票

这是整条线里**唯一能直接搬到任何策略上的结论**，而且它是在一次"失败"里被迫发现的：

| 本金 | 参考组合（等权 300 只）的现金比例 | 实际买入只数 |
| --- | ---: | ---: |
| 1,000,000 | **28.8%** | 23.9 只 |
| 3,000,000 | **11%** | — |

- 整手（100 股）约束下，1,000,000 元连**等权参考自己**都只能投出 **71%**；相对满仓池，
  现金拖累约 **−3.3pp**。
- 于是任何"策略 A 比策略 B 好 1.5pp"的说法，在一百万本金上**先被 28.8% 的现金否掉**，
  和选股毫无关系。
- 提高本金会把现金压到 11%，但**费用从 0.87% 涨到 1.91%**——满仓不是免费的。

**这条直接解释了后来为什么不再做"选股 + 满仓"**：在可支配本金上，四只 ETF 的 CPPI 组合
（`tools/plan_orders.py`）让每一分钱都能落在整手上，不存在"想买但买不进"的残差。

## 2. 方法：怎么证明一个策略"真的是零"

### 2.1 先验归因：训练后到底改了什么

- 9 月那轮训练后的排序与初始化先验的 **Spearman +0.9999997**，top-20 **20/20 完全重合**，
  残差只占先验振幅的 **0.01% ~ 0.53%**（设计上限 6.25%）。
- 意思不是"RL 学不会截面 alpha"，而是**这一轮在结构上就没给它学的空间**：先验太强，
  可挪动的名次最多 16 位、实际只挪了个位数。
- 这个诊断比看收益曲线快得多，也更能定位"输在哪"。**任何带先验初始化的策略都应该先做一次**。

### 2.2 β 剥离：赢的是 alpha 还是水位

| 策略 | 年化 | α（一因子） | t | β | α（加规模） | t |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `buy_hold` | +10.49% | **+17.23%** | 1.71 | 0.555 | **+18.21%** | 2.03 |

- 最高的 α 属于**完全没有决策**的买入持有；加上规模因子后 α 反而**上升**——说明水位来自
  幸存者偏差与规模暴露，不是选股。
- 剥离 β 之后，PPO 与等权**不可区分**：选择窗 +17.01% vs +16.82%，测试窗 +14.27% vs +14.35%；
  净收益差距落在费用上（1.91% vs 0.87%），不在选股上。
- **这条方法的现值**：现在报 CPPI 的 +4.43%/年是**全收益**（修正后口径），本来就不含任何 α 主张；
  一旦有人问"这个 5% 是本事还是水位"，答法就是上面这套。

### 2.3 对照组：让"输"变得可解释

每一轮都配了同账户、同费用、同整手约束的参照物：

| 对照 | 它回答的问题 |
| --- | --- |
| 随机初始化八格 | 训练到底有没有超过"没训练但结构相同"的模型？**没有。** |
| 容量/预算矩阵（小中大 × 预算） | 是不是模型太小？**扩规模没有稳定增量。** |
| 多种子（42/123/2026） | 是不是种子运气？**不是，均值也没赢等权。** |
| pilot → 选择 → 冻结测试 | 选模有没有作弊？结论是这套流程本身被保留下来了。 |
| 现金/费用分解 | "输 1.5pp"里多少是现金、多少是费用？**≈3.3pp 现金 + 1.6% 费用。** |

## 3. 工程契约：可复核，不赚钱

- `daily.csv` 的列口径、`freeze`/`evaluate`/`prediction` 的 CLI、模型 metadata 里的
  data/scaler/source 三重 SHA、以及每轮机器可读的 `final_audit.json`
  （例如探索那轮：14,832 字节、2,558 项登记、24 run / 48 快照、实际 3,840 次 Adam）。
- 价值在于**任何人拿到这套产物都能重算**，而不在于它产出了收益。
- 代价也很真实：为了这套身份体系，每轮要花大量时间在"封存、审计、SHA"上，
  而 `reports/runs` 因此膨胀到 11.94 GB——**这正是它昨晚被我误删时损失如此之大的原因**。

## 4. 别再试的清单（每一轮都已关闭）

| 方向 | 结论 |
| --- | --- |
| 轻量 PPO / 多种子 / 扩容量 | 工程完成，**未胜等权** |
| 随机初始化对照 | **训练没有超过同结构随机模型** |
| delta actor（增量动作） | **未超过旧先验** |
| trade actor（整手 + 保持动作） | 无合格候选 |
| 七方向探索（奖励/观察/结构/覆盖） | 观察最佳仍弱于动量 |
| market summary / critic 归因 | 无稳定增益 |
| priority rank（排序动作 + rank 辅助） | 所有配置未过门槛 |
| timing 系列（初始化强度、规则锚定、phase 预算、credit） | 行为改变但无跨折改善；原运行还失败过一次 |
| counterfactual 两轮（配对诊断 + 因果动作价值预热） | 诊断完成，**不证明可学性**；正式轮确认未合格 |
| 独立 Ridge 因子基线 | 两折弱于动量 |

**这张表的价值等于它省下的时间**：2026-11 之后的研究（E1/E2、供给侧、信息源、融资融券、
市场杠杆）没有一条是重复这里的。

## 5. 对现在这条线的三个直接启示

1. **本金与票数必须匹配**（§1）→ 用四只 ETF 做 CPPI，而不是 300 只个股做满仓。
2. **初始化/先验决定上限**（§2.1）→ 影子 S2 用**固定规则**（20 特征全取负号、top 30、跌出前 60 才换），
   不引入任何学习成分，也就不存在"学不到"的问题。
3. **报收益先剥离 β**（§2.2）→ 现在对外只报全收益与回撤，不宣称 α；
   要宣称 α，必须先做同池、同周期、同本金的基准对照。

## 6. 诚实的边界

- 本文所有数字都来自 `doc/` 里的报告；**运行产物已不存在**，所以"复核"只能靠重跑（旧分支）。
- 模型权重没了，意味着"这个模型到底学到了什么"这类问题**现在无法再用权重直接回答**——
  而先验归因那轮恰恰证明了权重是最快的诊断入口。这是误删的真实代价。
- 因此本文的定位不是"PPO 的墓志铭"，而是**从这条线里能带走什么**的清单：
  带走方法与教训，不带走模型。
