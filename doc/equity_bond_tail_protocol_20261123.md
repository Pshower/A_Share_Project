## 1. 为什么做

[arXiv:2611.21897](https://arxiv.org/abs/2611.21897) 在 30 只美加澳股债/多资产 ETF（2020–2024，日线）上用滚动窗口比较
min-var 与 CVaR 优化（long-only 与 long-short）对等权基准：**优化的经验 VaR/CVaR 更低，但等权的
Sharpe/Sortino/Rachev 最高**。结论方向与 [allocation_robustness](archive/allocation_robustness_20261108.md)
的"简单+低换手赢"一致，但那篇只测了再平衡频率、现金比例与波动目标，**从未测过滚动优化权重本身**。

本仓的现状恰好缺这块证据：现行方案是固定 60/40（腿内 25/25/50），外加 CPPI。
"要不要把权重交给优化器"从未在本仓数据上被否证过。外部文献给了可复制的对照设计，
本仓有 2014–2026 的四腿真实基金序列——比论文的 2020–2024 多出 2015 股灾、2016 熔断、
2018 熊市、2024-09 政策行情、2025-04 关税缺口这些结构断点，还多一维论文没有的分档：
**10 年期国债收益率 <2% / 2–3% / ≥3%**（[daily_ops](../tools/daily_ops.py) 的 REGIMES 同边界）。
当前 10y≈1.58%，全部 2024-12 之后的起点都落在低 carry 档——"结构变化改变排序吗"
不是学术问题，是当前 live 建仓决策直接面对的问题。

| 手动修复（1 条） | 510500 **2022-08-29 每份 0.92 元**分红——接口丢失、`dist_510500.csv` 无此行，[plan_backtest](plan_backtest_20261112.md) 已登记为真实分红；结果文档须给出**含/不含**这条的敏感性两行 |
| 全收益口径 | 登记分红当日再投资；四腿取交集 → **2014-01-15 起** |

| 起点 | 与 [plan_backtest](plan_backtest_20261112.md) 同一月度网格：**2016-01-04 起每个自然月首个交易日**，但须先满足 504 日热身（预计首个可行起点 2016-02-01，≈128 个；比 plan_backtest 少一个 2016-01 起点，属高 carry 档） |
| 五条臂（权重和恒为 1，long-only） | ① `eqw` 25/25/25/25；② `fixed6040` 15/15/30/40（现行方案腿）；③ `invvol` 逆 504 日波动；④ `minvar` 504 日样本协方差最小方差；⑤ `cvar` 504 日 CVaR95 最小化 |
| 优化网格 | ④⑤ 在 **10% 步长单纯形网格**（286 个点）上取最优——两臂同一网格、同一再平衡日、同一成本，消除求解器差异；这是对论文的**声明偏离**，网格近似误差进"不能主张"节 |
| 再平衡 | ①② 每 **252** 个交易日；③④⑤ 每 **63** 个交易日，自起点起算（频率本身不重要：[allocation_robustness](archive/allocation_robustness_20261108.md) 实测五规则差 <0.2pp） |

| 分档 | 起点日 10y（`asset_panel.yields()` 对齐前推）按 [daily_ops](../tools/daily_ops.py) REGIMES 同边界：<2% / 2–3% / ≥3% |
| 逐起点指标 | CAGR（242 步/年）、波动、Sharpe（rf=0）、Sortino（MAR=0）、最大回撤、日 VaR95、日 CVaR95、Rachev（最好 5% 日均值 ÷ 最差 5% 日均值绝对值）、年换手、年成本拖累 |
| 基准臂 | `eqw`——论文的等权基准即对照 |

## 3. 判据（三条，运行前写死；其余全部表为描述性，不作判定）

| # | 假设 | 通过条件 | 论文预测 |
| --- | --- | --- | --- |
| H1 | 优化压低尾部 | `minvar` 与 `cvar` 的 CVaR95（**负数口径**）中位数均 **高于** `eqw`（更接近 0 = 尾部更浅），且逐起点"臂 > eqw"的占比 **≥70%** | 通过（论文：优化的经验 VaR/CVaR 更低） |
| H2 | 优化不占风险调整优势 | `minvar`、`cvar` 任一臂满足 [Sharpe 中位差 > **+0.05** 且优于 `eqw` 的起点占比 **≥60%**]，则 H2 **被推翻**；否则 H2 成立 | 成立（论文：等权 Sharpe/Sortino/Rachev 最高） |
| H3 | 低 carry 档现行方案不输 | <2% 档起点内，`fixed6040` 的 CAGR 中位 **≥** `minvar`、`cvar`、`invvol` 各自的中位 | 无外部预测（论文无利率分档） |

三条全是组内比较，无 p 值多重性校正可用（起点窗口互相重叠，配对 t 的独立假设不成立）——
所以判据只用**中位数与方向一致率**两个机械量，不用显著性。这就是本仓对
[arXiv:2611.18934](https://arxiv.org/abs/2611.18934)"报告多重性"一条的诚实处理方式：
**有重叠起点的扫描做不了干净的显著性检验，那就不用它。**

## 4. 之后怎样（现在写死）

- **H1 通过且 H2 成立**：2611.21897 在本仓菜单复现。权重继续不交给优化器，
  `minvar/cvar` 不进入方案候选。**不改 LEGS、不改 CPPI 参数。**
- **H2 被推翻**：优化臂进入"组合层影子"候选清单（只花日历时间），与
  [shadow_variants](shadow_variants_20261118.md) 的处置同哲学——**不写进 live、不写进收益预期**。
- **H3 不成立**：结果文档如实写出哪个臂在 <2% 档的中位赢了 `fixed6040`，
  并写明"22 个左右起点、单窗口、非样本外"。处置同上：进影子候选，不动现行方案。
- 无论哪条成立，**本轮不触发任何现行判据、参数或调度变更**。

## 5. 与已有结论的关系

- 若 H2 成立，[allocation_robustness](archive/allocation_robustness_20261108.md) 的"简单赢"从
  "再平衡频率/现金比例/波动目标"三个侧面扩展到第四个侧面（**权重本身**），四腿结构的外部对表完成。
- 若 H3 成立，[delivery §4](delivery_20261116.md) 的低 carry 期望表多一层"现行权重在低 carry 档
  不输优化"的佐证；它仍然不是样本外证据，2024-12 之后的起点与 [plan_backtest](plan_backtest_20261112.md)
  共享同一段已花窗口。
- 与 [unified_strategy_final](unified_strategy_final_20261115.md) 的关系：该文档定下"简单+低换手"，
  本预登记是第一次把它当**可证伪假设**而不是设计哲学来检验。

## 6. 不能主张的（先写下来）

1. **指数级模拟**：无整手、无最低佣金、无 5% 不交易带。[plan_backtest](plan_backtest_20261112.md)
   §3 已证整手粒度能把 7 年结果移动 25%——本研究的数字用于**臂间相对比较**，绝对值不可外推。
2. **窗口已花**：2014–2026 与所有参数选择共享同一段数据，不是样本外证据。
3. **网格近似**：10% 步长可能错过真最优；两臂同网格使其对称，但"优化臂被打压"的替代解释不能排除。
4. **基金费率 0.5–1pp 未扣**，对五臂同向；QDII 溢价未建模（513500 价格含溢价噪声——缺陷，也是现实）。
5. **Sortino/Rachev 的定义不唯一**，本文用第 2 节写死的口径，换口径不重跑。
