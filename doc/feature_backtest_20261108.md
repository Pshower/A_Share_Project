# 1,800 只特征面板与特征筛选回测

日期：2026-11-08
状态：**已完成，结论是"没有特征在样本外有效"**。
工具 `tools/feature_panel.py`、`tools/feature_backtest.py`；面板 `data/clean/feature_top1800/`

---

## 1. 面板

`research_v3` 只覆盖 298 只幸存大盘股，截面离散度太窄（top 30/298 的 E[z]≈1.76，top 30/4000 约 2.76），
信号在窄截面里看不出来是正常的。所以另建一份：

| 项 | 值 |
| --- | --- |
| 名单 | 按中位流通市值取**最大 1,799 只**（1 只因数据不足跳过） |
| 特征 | **20 个**，由仓库自己的 `DataPreprocessor.add_features` 从原始 K 线计算 |
| 区间 | 2017-01-03 ~ 2024-12-31，1,943 个交易日 |
| 位置 | 独立目录，**未改动 `research_v3`**（它的哈希被 `run_suite` 校验） |

## 2. 特征筛选（只在选择窗里做）

用秩 IC（`alpha_ic.rank_ic` + Newey-West）在**选择窗 2019-2021** 上测 20 个特征：

| 特征 | 平均 IC | t |
| --- | ---: | ---: |
| turnover | −0.0473 | −1.76 |
| close_ma_ratio_60 | −0.0441 | −1.94 |
| volatility_20 | −0.0415 | −1.45 |
| macd_signal_ratio | −0.0396 | −1.79 |
| macd_ratio | −0.0377 | −1.78 |
| …（其余 15 个全部为负，\|t\| < 2.2） | | |
| body_ratio | −0.0093 | **−2.20** |

**两个观察：**

1. **20 个特征方向全部为负**——与[价格特征重测](price_feature_ic_20261106.md)一致。
2. **没有一个显著**：唯一 \|t\|>2 的 `body_ratio` 的 IC 只有 0.0093，远低于经济门槛。

所以"选有效特征"这件事，在选择窗里**本身就选不出来**。为了让流程跑完，用一条固定规则取
**|IC| 最大的前 5 个**并沿用选择窗的符号（不是挑显著的，因为没有显著的）。

## 3. 回测（E1 的同一构造）

top 30 等权、跌出前 60 才换、20 日持有、300 万、仓库同一成本模型（佣金万三/最低 5 元/印花税千分之五/双侧滑点 10bp/整手 100）。

| 窗口 | 年化 | 波动 | 最大回撤 | 平均留存现金 |
| --- | ---: | ---: | ---: | ---: |
| **选择窗 2019-2021** | **+15.60%** | 18.99% | −19.45% | 4% |
| **测试窗 2022-2024** | **−4.97%** | 21.99% | −35.46% | 8% |

**选择窗 +15.60%，测试窗 −4.97%。**

## 4. 随机对照（测试窗，30 次抽样）

| 项 | 值 |
| --- | ---: |
| 随机 30 只中位数 | **−4.43%** |
| p10 / p90 | −7.96% / +1.51% |
| 策略击败随机的比例 | **47%** |

**−4.97% 与随机中位数 −4.43% 无差别**，击败率 47% ≈ 抛硬币。

## 5. 判定

**没有特征在样本外有效。**

- 选择窗里没有显著特征（最强 |t| 2.20，IC 0.0093）；
- 用 |IC| 前 5 名建的书，在选择窗赚 15.60%，在测试窗亏 4.97%；
- 测试窗表现与随机 30 只无差别。

**选择窗的 +15.60% 是过拟合的典型形状**：同一条规则换个窗口符号就翻。这也说明了为什么
"只要选择有效的特征"这个做法本身需要先做样本外检验——**不做的话，那 15.60% 就会被当成结论。**

## 6. 不能主张的

1. **不是"所有特征都无效"**，是"这 20 个价格特征在前 1,800 只里、这段区间上无效"。
2. **样本外只有 2022-2024 一段**，且这段是单边下行市（三 ETF 混合基准同期也弱）。
3. **面板仍含幸存偏差**：名单按今天的市值取，只是比 298 只宽得多。
4. **没有做多重检验校正后的再筛选**——那只会让门槛更高，不会让结论翻转。
