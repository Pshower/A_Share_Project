本文只记录**已经存在、但没有任何东西在用**的部分，不提出新方向，也不修改任何已登记的结论。

## 1. E2 预登记还挂着，而且它的前置条件与现有面板不符

[E2 协议](e2_protocol_20261108.md) 写于 2026-11-08，明确是"预登记，写在运行之前"：把 E1 的同一信号放到前 1,800 只，
判据是 **V 与 full 双窗口净超额 t ≥ 2.5 + 随机对照**，三条全过才算通过，任何一条不过即**永久关闭"价格特征 alpha"这一族**。

事实：

- 全仓检索，"E2"只出现在它自己、[文档索引](README.md) 的条目，以及 `implementation_plan` 里**同名不同义**的 E2（那条指开盘前建议的滚动窗口）。**没有任何结果报告，也没有运行器。**
- `implementation_plan` 的"下一步"写的是"只剩 S2 前瞻影子运行"，等于把 E2 漏掉了。
- 协议第 3 节规定的池子是**每个调仓日按前一日流通市值取前 1,800 只**（PIT 动态，"不是全期静态分档"）。
- 现有 `data/clean/feature_top1800`（1,799 只、2017-2024、625 MB）是**静态**选的：`tools/feature_panel.py::select_codes`
  与 `tools/capm_backtest.py::largest` 都按**中位市值**排序取前 N。这正是协议点名禁止的做法。
- **动态选档的代码其实已经有了**：`tools/equal_weight_crosscheck.py::dynamic_band_premium` 在每个再平衡点用
  `dated.iloc[position - 1]`（滞后一日市值）重选档位，正是"没有前视"的实现。

**结论**：E2 现在**可执行，但不能拿现成面板凑**。两条路——按协议新建动态池（要覆盖"历史上曾进前 1,800、但不在静态名单里"的名字），
或正式退役。现在这种"登记了、没人跑、也没人关"的状态，是仓库里唯一一处会让后来者误以为还有未完成实验的正式协议。

## 2. 信息源清单还剩四条没测

[信息源候选清单](information_sources_20261108.md) 已经按三条硬约束（PIT 可得性 / 覆盖率 / 可检测性 IC ≥ 0.031）评过 8 个源并排了序：

| 源 | 状态 | 结论 |
| --- | --- | --- |
| 限售解禁 | **已测** | 过门槛（−0.0463，t −2.82），但只覆盖 **5%** |
| 业绩预告 | **已测** | +0.0216（t 0.98），**不过** |
| 资金流 | **已测共线** | 相关 0.42 < 0.5（不冗余），但只有 **0.42 年**数据，不够算 IC |
| 分红 | **已测** | 红利袖套：风险改善确定，收益改善取决于股息假设 |
| 融资融券 | **未测** | PIT 好、覆盖中等、机制中等 |
| 龙虎榜 | **未测** | PIT 好、覆盖低（只有异动股） |
| 股东户数 | **未测** | PIT 中（季度滞后）、机制弱-中 |
| 业绩报表 | **未测** | PIT 差（必须先解决公告日） |

门槛已被同一份文档抬到 **t ≥ 2.5** 且要求**样本外窗口独立**（2022-2024 已被价格特征用过一次）。
