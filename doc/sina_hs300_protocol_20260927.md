# 新浪沪深300与多初始持仓协议

## 范围与来源

用户指定 `data/stock_list/hs300_20260629.txt`，全部 300 个代码必须进入数据审计与模型股票池；不静默剔除失败代码。名单是 2026 年截面，历史选择偏差仍存在。

2026-09-27 实测新浪、腾讯均可返回 000001 的 HFQ 日线。选择新浪 `stock_zh_a_daily`：本机腾讯输出缺少完整 volume/turnover 字段且 amount 语义与现行官方文档不同，不伪造缺失字段。证据保存于 `reports/runs/alternative_probe_20260927`。官方资料：https://akshare.akfamily.xyz/data/stock/stock.html 。

本轮首先下载 2017-01-01 至 2026-09-25 全部 300 股的新浪 HFQ，用于独立研究版训练和评估。成交模拟仍为 `hfq_research`，不将其称为真实账户模型；未复权及公司行为适配是独立后续任务。新浪成交量股、换手率小数转换为项目规范，最终存量为股、换手率百分数。新浪 SDK 每次实际 HTTP 请求均经限速/超时/状态检查，不只在 SDK 外层等待。

## 来源契约

批次 request.provider、数据 manifest.data_source、模型 contract.data_source 必须一致。推理绑定拒绝其他来源，扩池迁移不允许换源；批次组合拒绝混合供应商。不能直接把新浪新数据喂给旧东方财富模型。重试保留原来源和价格口径。

## 日期与预算（训练前登记）

- 数据：2017 起；训练截至 2026-03-31，开发验证 2026-04-01 至 2026-06-30；2026-07-01 之后保留，不在本轮评估。
- 旧 2023/2024 已查看测试期可成为此新协议的历史训练数据，但不能再宣称未见测试；本轮不输出该旧测试期的选模绩效。
- 全池掩码模式，IPO 前或特征未热身的股票保留维度但不可买入，不以最晚上市股票强行截短全部历史。scaler 仅拟合训练截止日前的有效样本。
- GPU，网络 256/128，lookback=1，PPO n_steps=512、batch_size=128、epochs=5、学习率 1e-4，保留 target_kl=0.03；每种子 8192 步，种子 42/123/2026。其余沿用研究基线，不关闭 KL。
- 训练 episode 最长 256 步，起点仅在训练区间内随机抽取。每四次 reset 随机排列并覆盖 cash/equal/concentrated/random 四种初始账户；不会只学全现金开局。
- 初始持仓是按当日起始收盘价计价的合成已结算持仓，不是免费历史交易收益；总资产守恒、整手、单票上限、现金非负。无额外初始交易费用，但后续交易正常计费。记录初始模式实际训练步数。
- 验证固定起点，按现有全现金验证 Sharpe 选择 checkpoint；最终所选模型分别在四种账户场景与相同初始账户的等权/持有等基线比较。场景评估账户种子统一为 20260927，跨训练种子也保持起始账户相同；不能拿不同初始持仓下的收益直接评胜负。

## 验收条件

300 股文件完整、来源一致、数据单位/哈希通过，才开始正式训练；检查每只股票实际覆盖与训练样本。记录各模式持仓数量，HFQ 与整手可能造成部分场景实际投资比例低于设计值，必须披露。训练需有限参数更新、保存加载一致、全部四种初始模式均有实际采样；评估仅使用开发验证，报告不保证盈利或普适泛化。
