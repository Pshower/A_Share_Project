# 预登记：市场级杠杆强度能不能当 CPPI 的风险闸门

日期：2026-11-14。状态：**预登记，写在任何信号‑收益统计之前**。
判据、变量构造、样本记账全部在本文写死；结果另见 `doc/market_leverage_result_2026MMDD.md`。

## 1. 问题

个股截面的融资融券信号**过了 IC 门槛但组合层失败**（IC −0.0403、t −4.64；组合净超额 −1.06%、t −0.149；
拥挤度 overlay t 1.29），多头用法已经按预登记关闭。本文问的是**另一个问题**：

> 把融资余额加总到**市场层面**，它的 20 日增速能不能预测**未来 20 日的市场收益与回撤**？
> 如果能，它作为 CPPI 的 multiplier 节流阀（而不是选股信号）是否值得接。

这两件事不冲突：截面上"买哪只"失败，不代表时序上"什么时候别满仓"也失败。

## 3. 变量构造（写死，不留选项）

### 3.1 固定篮子

`B` = 同时满足以下三条的代码，**在整个检验期内固定不变**（不做逐日重选）：

1. 在保证金归档中出现 ≥ **1,382 天**（1,455 天的 95%）；
2. 在 `panel_full` 中 `unadj_close` 与 `shares` 各有 ≥ **1,382 天**非缺失；
3. 2019-01-02 ~ 2024-12-31 之间至少有一天融资余额 > 0。

### 3.2 杠杆强度

```
lev_t = 100 × Σ_{i∈B} balance_{i,t} / Σ_{i∈B} (unadj_close_{i,t} × shares_{i,t})
```

单位是"流通市值的百分比"。分子分母用**同一个篮子**，所以成分变化对两者同向作用。

### 3.3 信号（唯一主变量）

```
r20_t = ln(lev_t / lev_{t-20})
```

**20 个交易日**的杠杆强度增长率。**不取分位、不做 z-score、不试 5 日/60 日版本作为主变量**——
这些都是看到结果之后最容易悄悄换的东西，本文一律不作主判据。预测方向**为负**：
加杠杆 → 未来更弱。理由是它和个股层面的既有结论（融资余额增速取负、IC −0.0403）方向一致，
不是从数据里挑的。

## 4. 目标变量

| 名称 | 定义 |
| --- | --- |
| `fwd20_t` | `ln(close_{t+20} / close_t)`，`000300` 收盘价 |
| `dd20_t` | `-(min_{t<s≤t+20} close_s / close_t - 1)`，即未来 20 日内**最深回撤的幅度**，越大越差 |

`t` 取杠杆序列每个可得日，`t+20` 用交易日推进；日期对齐以 `000300` 的交易日为准，保证金缺失日不补。

## 5. 判据

### 5.1 有效性守卫（先判，守卫不过则**整轮作废**，既不算通过也不算失败）

| 守卫 | 要求 | 理由 |
| --- | --- | --- |
| **G1 覆盖污染** | `|corr(r20_t, Δ20 n_t)| ≤ 0.30`，其中 `n_t` 是当日有余额记录的代码数 | 归档的代码数从 819 涨到 3,718，篮子固定了，但**记录覆盖**仍可能把"成分扩张"伪装成"加杠杆" |
| **G2 市场代表性** | 篮子的流通市值占 `panel_full` 全体的 **≥ 30%** | 896 只大盘股撑不起"市场级"这个词 |

### 5.2 四条判据（**全部通过**才算通过）

| 编号 | 内容 | 门槛 |
| --- | --- | --- |
| **T1（主判据）** | `fwd20` 对 `r20` 回归的斜率，Newey-West 修正（lags = 20） | 斜率 **< 0** 且 **t ≤ −2.5** |
| **T2（分段）** | 2019-01~2021-12 与 2022-01~2024-12 两段的斜率 | **两段都为负**（不要求各自显著） |
| **T3（回撤）** | `dd20` 对 `r20` 回归的斜率，NW(20) | 斜率 **> 0** 且 **t ≥ +2.5** |
| **T4（换代理）** | 用 `399317` 重算 T1 | 斜率 **< 0** 且 **t ≤ −2.5** |

四条是**合取**，等于把假阳性的门槛抬到比单条更高；T2/T4 是稳健性，不是加分项。
**任一条不过即关闭这一族**，不许换窗口、换指数、换阈值、换持有期重试。

### 5.3 功效上限，先说清楚

1,455 个观测里有 **~1,435 个可用日**，但 20 日重叠使**有效独立块只有约 72 个**。
NW(20) 的 t 已经为此做了修正，但即便如此，t 2.5 对应的经济幅度可能仍然很小——
若斜率显著但幅度小到"降 multiplier 也省不下 0.5pp"，阶段二会自己把它否掉。

归档起点是 **2019-01**，**没有 2015 杠杆牛与股灾**。样本内真正的大杠杆事件只有 2021-02 与 2024-01/02。
这一点必须在结果里重复一次，不能因为"通过了"就假装它经过极端检验。

## 6. 样本记账

- **本检验只用 V 段（2019-01 ~ 2024-12）**。不是自愿选择：保证金归档**只到 2024-12-31**，R（2025-01~2026-06）
  与 P（2026-07~10）在这条数据源上根本不存在。
- **这是 V 段的第二次使用**（第一次是截面族：CAPM/E1/E2/各信息源）。因此本文**不主张任何"干净样本"**，
  也不因为"V 已经花过"就下调门槛——门槛照旧 2.5。若想扩到 2025+，唯一正当路径是**先把保证金归档补到最新**
  （`tools/archive_margin.py` 可续抓），那是另一个决定，不在本轮偷偷做。
- P 段仍然完全未动。

## 7. 阶段二（只有阶段一通过才执行，规则现在写死）

把 `r20` 接成 CPPI 的 multiplier 节流阀：

```
M_t = 6   if r20_t ≤ 过去 250 日 r20 的 80% 分位（含当日）
M_t = 4   否则
```

- 阈值取**80% 分位**（不是最优值，是"过热"的常规定义），只用截至当日的信息，无前视。
- 在 `tools/plan_backtest.py` 的引擎上跑 **2019-01 ~ 2024-12 之间所有可用的日频起点**（保证金可用期）。
- 判据：与未节流的同一批起点相比，**最差回撤改善 ≥ 1.0pp**，且**中位年化不下降超过 0.5pp**。
- 两条都过才算接上；否则记录"信号有预测力但不值钱"，同样关闭。

## 8. 关闭条款

1. 守卫不过 → 整轮作废，先修数据源，不许改判据。
2. 判据不过 → **关闭"市场级杠杆闸门"这一族**，并在 `implementation_plan.md` 写明关闭理由。
3. 通过但阶段二不过 → 保留 IC 层结论，关闭执行用法，措辞为"有预测力、不值钱"。
4. 不许把本文的主变量换成"分位版本""融券版本""5 日版本"来重跑——那些只能作为**诊断**出现在结果里，
   不参与判定。
