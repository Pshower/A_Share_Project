# S1 结果：剔除解禁有方向性改进，但没过 2.5 的门槛

日期：2026-11-08
分支：`research/supply-pressure`
状态：**未通过**。按[研究方向](research_direction_20261108.md) §6 预登记，**关闭"供给侧事件"这一族**。
工具 `tools/supply_overlay.py`；产物 `reports/runs/supply_overlay/`

## 1. 设计与执行

| 项 | 取值 |
| --- | --- |
| 底书 | 20 个价格特征全取负、top 30、跌出前 60 才换、20 日持有、300 万、真成本 |
| 票池 | 前 1,799 只 |
| 处理组 | 建仓时剔除**未来 20 个交易日内有解禁**的名字，用排名后一位补 |
| 对照组 | 同一构造不剔除 |
| 窗口 | 2019-01-02 ~ 2024-12-31（1,455 个交易日） |
| 配对 t | **72 个不重叠 20 日块**（不是日频，避免自相关高估） |
| 判据 | **配对差 t ≥ 2.5**，事前写定（第 8 次检验） |

**实际剔除次数：105 次**（1,455 个交易日里，只有 105 次因为解禁而跳过一个候选名字——
这正是 5.1% 覆盖率的算术后果）。

## 2. 结果

| | 年化 | 波动 | 最大回撤 | Sharpe |
| --- | ---: | ---: | ---: | ---: |
| 对照组（不剔除） | +10.70% | 25.78% | −41.16% | 0.338 |
| **处理组（剔除）** | **+12.50%** | 25.70% | **−37.92%** | **0.408** |

**配对差：**

| 项 | 值 |
| --- | ---: |
| 年化差 | **+1.80pp** |
| 平均日差 | +0.0066% |
| 不重叠块数 | 72 |
| **配对 t** | **+2.25** |
| 正块占比 | 59.7% |

## 3. 判定：不通过

**t = 2.25 < 2.5。** 方向对、幅度正、回撤更浅、Sharpe 更高——**但门槛是事前写定的，不是事后可调的。**

这正是设 2.5 而不是 2.0 的原因：如果门槛是 2.0，这次就会"通过"，
而它其实只是第 8 次在同一批数据上的检验。

按预登记：

> **失败 → 解禁这一族也关闭**，不设第二个窗口、不设第二个底书。

## 4. 不需要解释掉的三个事实

**它们是真的，但它们不改变判定。**

1. **回撤改善比收益改善更明显**（−41.16% → −37.92%，3.2pp）。这与机制一致——
   避开供给冲击主要削的是左尾，不是抬高均值。
2. **Sharpe 从 0.338 升到 0.408**（+21%）。
3. **正块占比 59.7%**，高于抛硬币。

**如果一年后要重开这条线，理由应该写在现在**：不是"t 是 2.25 很接近"，
而是"机制指向左尾，而 Sharpe 与回撤的改善幅度大于收益"——**这是一个不同的假设，需要新的预登记。**

## 5. 为什么这次结果比 E1 可信

| | E1 | S1 |
| --- | --- | --- |
| 比较对象 | 两个不同的组合 | **同一本书，改一条规则** |
| 差异来源 | 全期持仓都不同 | 只有 105 次换人不同 |
| 跟踪误差 | 10.07% | 配对差，块级 sd 很小 |
| 检验数 | 第 22 次 | 第 25 次，门槛已抬高 |

**配对设计确实提高了功效**——所以它能在同样的样本上把 t 从 E1 的 0.07 抬到 2.25。
**但提高功效不等于制造显著。2.25 就是一个没过线的数。**

## 6. 这一族的最终账

| 检验 | 结果 |
| --- | --- |
| 解禁的秩 IC（条件化） | **−0.0686（t −5.26）**，过门槛，覆盖 5.1% |
| 解禁的可执行覆盖层 | **+1.80pp，t 2.25**，未过 2.5 |

**两个数不矛盾**：IC 说明"在有解禁的名字里，解禁越大后续越差"；
覆盖层说明"把这个信息用到 30 只的书上，改进不够稳定到能认证"。

**IC 是真的，产品价值不是。**
