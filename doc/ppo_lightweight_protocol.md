# 轻量 PPO 实验预定方案

日期：2026-09-25。用户已明确要求本地轻量训练与回测。本方案在读取本次模型绩效前确定，不依据最终测试结果修改参数。

## 数据与预算

- 使用现有 `research_v3`，不下载、不重新拟合 scaler、不覆盖清洗数据。
- 股票选择规则：将当前面板股票代码排序，在 0 至 297 的索引范围用 `numpy.linspace(0, 297, 32, dtype=int)` 等间隔取 32 只，不使用价格、收益或未来完整性筛选。
- 明确股票列表和参数写入 `configs/ppo_lightweight.json`；与默认 PPO 配置仅股票池和报告目录不同。
- 保留完整训练日期至 2022-08-05，验证成交区间 2022-08-08 至 2023-10-20，最终测试成交区间 2023-10-23 至 2024-12-31。
- 先运行 512 步训练检查；仅检查实际参数更新、有限值、保存加载与回调，不据其验证收益调整参数。
- 随后从同一随机种子 42 重新初始化，运行预定 8,192 步、32 个 rollout；没有额外超参数搜索或多种子筛选。失败的技术运行也需记录，不能隐藏。
- CPU、单进程、20 个特征、lookback=1、共享 MLP 128 -> 64，其余 PPO 与 broker 参数保持默认。32 只股票的 5% 单票上限仍允许总仓位达到 100%，不因缩池调整上限或本金。

## 模型选择与回测

- 正式轻量训练在 2,560、5,120、7,680、8,192 步完成更新后评估验证集；先按 Sharpe、再按累计收益选模型。
- 冒烟运行不参与正式选模；若所有候选 Sharpe 无定义，不擅自认定最优模型。
- 所选模型与现金、买入持有、20 日等权/动量和每日等权/动量在相同 32 只股票、日期、资金与费用下回测。
- 在最终测试前写入冻结文件，绑定所选模型文件和参数指纹、完整配置、数据契约及源码；测试入口必须显式指定测试 split 和冻结文件。
- 最终测试只评估冻结模型和同口径基线一次，不用于重新选 checkpoint 或调整超参数；之后可校验产物，但不根据测试结果重训。
- 训练中记录参数变化、优化器步数、损失/KL、验证记录和时间。回测复用公共账户对账，输出净值、持仓、订单及费用。

最终交付中文详细报告和摘要，包括配置、股票池、日期切分、训练审计、验证与测试指标、基线比较、成交诊断、文件定位和限制。
