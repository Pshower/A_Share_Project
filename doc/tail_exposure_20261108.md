# 微盘尾的近似模拟与偏差来源

日期：2026-11-08
状态：**近似已跑，结论是"偏差不在幸存者，而在数据覆盖"**。
工具 `tools/tail_exposure.py`，产物 `reports/runs/tail_exposure/`。

关联：[ETF 逼近全市场](allocation_study_20261108.md)、[等权溢价的指数对照](equal_weight_crosscheck_20261108.md)

---

## 1. 近似怎么做

分档成员**每个调仓日按前一日流通市值重取**，不用全期中位市值——那层前视已经证明能造出 7.92pp 的假溢价。

## 2. 结果

| 口径 | 年化 | 波动 | 平均成员 | 观测日 |
| --- | ---: | ---: | ---: | ---: |
| 尾部（第 1,800 名之后）**等权** | **+14.89%** | 25.97% | 2,479 | 1,456 |
| 尾部**市值加权** | **+13.18%** | — | — | — |
| 三 ETF 混合（可执行基准） | +5.27% | — | — | — |

按市值看，尾部占全市场约 13%，年化 13.18%，而前 1,800 只约 5.3%——
**这正是全市场指数比三 ETF 混合高 2.7pp 的来源。**

## 3. 但缺口的来源和我原来以为的不一样

我原本按"幸存者偏差"处理，用 0 / −30% / −60% 三档折算了缺失名字的影响。**那个框定是错的。**

把 522 个缺失代码按失败原因和代码前缀拆开：

| 类目 | 数量 |
| --- | ---: |
| `404`（数据源不提供） | **310** |
| `History is empty`（区间内无行情） | 152 |
| OHLC 校验失败 | 3 |
| 未分类 | 57 |

| 前缀 | 数量 | 含义 |
| --- | ---: | --- |
| **`920`** | **355** | **北交所** |
| `301` | 59 | 创业板新号段 |
| `688` | 42 | 科创板 |
| `603` / `001` | 58 | 沪主板 / 深主板 |

**355 个（68%）是北交所代码。它们不是在退市名单里——它们今天还在上市，只是新浪的行情接口不提供。**

北交所 2021-11 才开市，所以这批名字在 2019-2021 本来就不存在，2022-2024 才是它们真实的市场段——
**而那正是最小市值的那一段。**

## 4. 所以准确的结论是

| 我原来的说法 | 实际 |
| --- | --- |
| 尾部收益被"幸存者偏差"抬高 | **主因不是退市**，是**北交所整段缺失** |
| 用 −60% 折算是保守情形 | **错**。北交所既没退市，也不必然跑输；方向未知 |
| 缺失占市值 1.5%，可以忽略 | **按市值可以，按名字数不行**：它们占尾部成员数的 17.4% |

**一句话：我测到的"微盘尾"不是真正的 A 股尾，是"剔除北交所之后的尾"。**
它高出来的 13–15%，有多少属于真微盘、多少属于"少了北交所"，**这次数据答不了**。

## 5. 因此现在能主张什么

1. **可执行的部分确定**：三 ETF 混合年化 **+5.27%**，TE 对全市场指数 0.98%（拟合）/ 2.57%（检验）。
2. **全市场指数高出的 2.7pp 确实来自 1,800 名之后**——这一点在剔除北交所之后仍然成立（13.18% > 5.27%）。
3. **但 13–15% 这个水平不可信**，因为它建立在一个缺了整段北交所的宇宙上。

## 6. 要解决它，只需要一样数据

不是 PIT 成分表（那份只到 2009 年），也不是退市名单（那只影响 152 个空行情代码），
而是：

> **一个能提供 `920xxx`（北交所）2017-2024 行情的源。**

拿到之后，把 355 个代码补进面板，重跑本工具，那一栏就不再是"近似"。
