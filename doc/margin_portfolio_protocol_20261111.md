日期：2026-11-11
状态：**预登记，写在组合层检验运行之前**。本文只固定规则；结果另写报告。
上游：[融资融券 IC](margin_ic_20261111.md)（IC −0.0403、t −4.64、覆盖 77.3%）。

## 1. 为什么还要做一次

IC 层已经过了门槛，但 IC 不是收益。0.031 的门槛含义是"这个量级**值得**做组合检验"，
不是"组合能赚钱"。[融资融券](margin_ic_20261111.md) 第 5 节已经写明这一点。

这次检验要回答的问题只有一个：**把这条信号做成 30 只的账本、付掉真实成本之后，它还剩不剩东西。**

## 2. 固定的构造（运行前写死）

| 项 | 取值 |
| --- | --- |
| 信号 | `融资余额` 的 **20 个交易日变化率**（不是水平） |
| 方向 | **负**——变化率最低的 30 只买入 |
| 滞后 | **1 个交易日**（交易所收盘后公布） |
| 票池 | **PIT 动态前 1,800**（`data/clean/e2_dynamic1800` 的全集；每日按前一日流通市值重选，池外无特征） |
| 选股 | 信号升序取 **top 30**；持仓只有**跌出前 60 名**才换（与 E1/E2 同一缓冲规则） |
| 持有 | **20 个交易日** |
| 成本 | 同一个 broker：佣金万三（最低 5 元）、印花税千五、双边滑点 10bp、整手 100 股、本金 300 万 |
| 基准 | **同池等权**、同调仓日、同本金、同成本 |
| 窗口 | 因融资余额自 **2019-01-02** 起才有，只有 **2019-01-02 ~ 2024-12-31** 一个窗口（下称 W） |

**为什么用动态池而不是 IC 报告里的静态池**：`feature_top1800` 按中位市值选成分，含前视；
[E2](e2_result_20261111.md) 已经证明动态池是可建的。信号与池子的耦合必须一次定死，
不能因为"静态池上 IC 更好看"就换回去。

**代价必须写明**：W 就是 V，是**已经花掉的窗口**。所以这次检验**不是样本外证据**，
它最多能给出"值得/不值得进影子运行"的 go/no-go。

## 3. 判据（三条全过才算通过）

| 判据 | 要求 |
| --- | --- |
| 净超额 | **> 0** |
| t（净超额 / 跟踪误差 × √年） | **≥ 2.5** |
| 随机对照 | 必须**高于** 200 次随机 30 只的中位数，且**落在 p90 之外** |

**任何一条不过 = 不通过。** 不设"换个持有期再试"、"换个池子再试"、"只取多头前 20 名再试"—
那不是检验，那是在同一个已花窗口上搜索。

## 4. 失败之后怎样（现在写死）

**不通过 → 关闭"融资融券净额"这一族**，与价格特征族、供给侧族同等处理，不再有第二次。

**通过 → 它仍然只是"可进入影子运行的候选"**，不许据此写进最终方案的收益预期；
正确的下一步是把它并进 S2 前瞻影子（只花日历时间），而不是再在已花样本上加杠杆验证。

## 5. 与已有结论的关系

- 若通过，本仓库将第一次拥有一个**既过 IC 门槛、又过组合层**的信号；但它依然不是样本外证据。
- 若不通过，则"信息源"这条线上唯一过门槛的东西也止步于 IC——**这本身是重要的负结果**，
  说明 0.031 这个 IC 门槛对 30 只的组合偏松，需要在新一轮里重新标定。
