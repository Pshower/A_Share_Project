# 行情信息与技术指标扩展方案

日期：2026-09-26。状态：设计稿，尚未实现本方案新增能力。

本次只更新文档，不调用行情 API，不下载数据，不更改模型或启动训练。现有功能见 [行情运行说明](online_market_runbook.md)；总体实施状态仍以 [实施进度](implementation_plan.md) 为准。

## 1. 目标与现状

将现有 K 线页面扩展为可检查数据来源、观察多周期走势、对照指标和研究动作的行情工作区。信息扩展不等于给出确定买卖建议，也不意味着现有日线 PPO 能处理盘中输入。

当前已实现：日 K、收盘价曲线、MA5/MA20、成交量、股票和价格口径切换、时间窗口及缩放。现有日线文件包含 `date/code/open/close/high/low/volume/amount/turnover`，成交量已转换为股。

本地批次 `h_18d10fc14d534e33` 的 000001 有未复权和后复权两套数据，各 2,364 条，覆盖 2017-01-03 至 2026-09-24。这足以开发大部分日线技术指标，无需重新下载；不代表其他股票或盘中数据已具备。

工作分两条线：

- 本地增强：充分使用已有 OHLCV、成交额和换手率，增加统计、指标及图表交互。
- 手动补充：由用户在能访问供应商的环境下载额外数据，工作台负责离线校验、归档和展示。

## 2. 官方接口与新增信息

以下接口按 AKShare 官方文档核对，仅作为适配目标，不保证当前安装版本或供应商连接可用。开发时须核对本地 AKShare 版本和用户实际导出样例；不自动升级依赖。

| 数据类别 | 官方接口 | 拟展示用途 |
| --- | --- | --- |
| 个股资料 | `stock_individual_info_em` | 名称、行业、上市日期及股本概览 |
| 行情截面 | `stock_zh_a_spot_em` | 市值、动态市盈率、市净率、量比等快照信息 |
| 五档盘口 | `stock_bid_ask_em` | 买卖档位和报价快照，不模拟连续盘口 |
| 分钟行情 | `stock_zh_a_hist_min_em` | 分时曲线及分钟 K 线 |
| 资金流 | `stock_individual_fund_flow` | 分单大小的资金流图及历史对照 |

官方来源：[个股资料](https://akshare.akfamily.xyz/data/stock/stock.html#id12)、[报价](https://akshare.akfamily.xyz/data/stock/stock.html#id14)、[行情截面](https://akshare.akfamily.xyz/data/stock/stock.html#id17)、[分钟行情](https://akshare.akfamily.xyz/data/stock/stock.html#id32)、[个股资金流](https://akshare.akfamily.xyz/data/stock/stock.html#id190)。章节锚点可能随文档生成变化，可按接口名查找。

官方限制需保留：上述分钟接口的 1 分钟数据仅覆盖近 5 个交易日且不复权；文档提示部分日期开盘字段可能为 0。个股资金流接口覆盖近 100 个交易日。不能把这些接口当作完整多年分钟或资金流历史来源。

资料和行情截面是采集时的快照，不能反填成过去每天已知的基本面。资金流属于供应商分类统计，不将“主力”直接解释为特定机构真实账户，也不把其净流入当作已验证的预测能力。

优先接入资料、行情截面、分钟数据；盘口和资金流后置。财报、公告、分红送转和行业指数作为后续独立扩展，先核对披露时间、修订机制与接口契约，再纳入设计，不在本轮承诺完整接入。

## 3. 手动下载与离线导入

### 3.1 操作路径

拟新增“导入本地行情”：选择数据类别及文件，预览列映射与元数据，校验通过后发布不可变快照。导入操作不产生网络请求。

后续提供由用户显式运行的下载导出脚本，集中记录 API 名称、参数、版本、采集时间和单位，避免每类数据手工编写导出逻辑。本方案不提供尚未实现的运行命令，不把未来脚本写成已可用功能。

兼容两种来源：

1. 下载脚本生成的结构化数据包，带完整 manifest。
2. 用户已有 CSV / Parquet，加导入表单填写缺失元数据；未知内容必须保留未知，不能根据文件修改时间伪造采集时间。

第一版不支持任意脚本执行、pickle 或自动解压外部压缩包。CSV 保留六位股票代码；支持显式编码选择，不依赖 Excel 自动类型推断。

### 3.2 元数据与校验

每个数据包登记：`schema_version`、`dataset_kind`、`provider`、`api_name`、`akshare_version`、`request_params`、`codes`、`price_basis`、`frequency`、`timezone`、`captured_at`、`data_as_of`、`units`、`files` 及 SHA-256。

- `captured_at` 是采集时间，`data_as_of` 是数据描述的业务时间，`imported_at` 是导入时间，三者不互相替代。
- 六位股票代码与交易所分开记录；市场不能仅通过一个通用首位规则猜测。
- 数值字段检查类型、有限性、合法范围；缺失值保留为 null，不自动替换为 0。
- 日线检查日期唯一、排序、OHLC 一致性；分钟数据使用独立规则，遇到已知开盘为 0 的记录不制造开盘价，也不绘制假 K 线，可保留有效收盘点用于分时曲线。
- 按接口和数据类型声明手 / 股、元、百分数单位后再转换；不能把当前日线的乘 100 规则应用于所有 AKShare 接口。
- 区分未复权 / 前复权 / 后复权，不通过价格量级猜口径；未来前复权仅用于明确标记的展示，不替换现有 HFQ 训练数据。
- 预览显示覆盖区间、重复项、缺失字段、未知元数据和错误原因；严重错误拒绝发布，展示受限项需明确标记。
- 文件路径限于受管目录，拒绝路径穿越和符号链接越界；建议初始上传上限 50 MB / 文件、200 MB / 批次，解析前后均检查规模限制。
- 相同内容可以提示重复，但不覆盖旧快照；发布失败不得留下“完整”状态。

拟将扩展数据放入 `data/online/imports/<id>/`，与当前 history / quotes / plans 分开。该新类型需要扩展快照注册与目录接口，不假定当前 `Snapshots` 已支持。原文件与标准化产物都保留哈希和转换版本。

### 3.3 时效边界

手工导入的盘口和报价显示“采集快照”，不能标为持续实时。无法证明报价时刻时显示未知，导入时间再新也不能恢复其可交易性。分时末根柱注明可能未收盘；是否完整由明确证据决定，不能只凭文件存在判断。

展示可以容纳元数据不完整但明确标记的记录；训练、日线计划和交易适配继续使用各自严格准入条件，不因能画图就自动可用于模型。

## 4. 技术指标体系

指标由本地价格序列计算，避免为每个指标新增外部 API。先复用仓库已有特征实现，建立公式与参数注册表；确有缺口才引入依赖或新增计算，不在前后端各实现一套不同算法。

以下均为拟定默认参数，可配置并恢复默认。`C/H/L/V` 分别为当前柱收盘 / 最高 / 最低 / 成交量。指标说明和公式放入独立详情面板，主图保持紧凑。

### 4.1 趋势与主图叠加

| 指标 | 拟定参数 / 定义 | 展示及边界 |
| --- | --- | --- |
| SMA | 5 / 10 / 20 / 60 / 120 / 250，完整窗口收盘均值 | 趋势层级；默认最多显示 3 条 |
| EMA | 12 / 26；递推权重 `2/(n+1)` | MACD 共用一致的 EMA 契约 |
| BOLL | 20，均值上下 2 倍总体标准差（ddof=0） | 主图通道，带宽和 %B 可作副图；分母为 0 返回 null |
| Donchian | 前 20 / 55 根已完成柱的最高和最低 | 突破参考线排除当前柱，避免“突破自身最高价”的定义错误 |
| 多周期均线状态 | 当前均线排序、价格偏离均线比例 | 描述状态，不直接转成买卖建议 |

后续可评估 Supertrend、ADX 等趋势强度指标，但第一版不堆叠多个相近通道。必须先确定公式版本及边界处理，再进入注册表。

### 4.2 动量与相对位置

| 指标 | 拟定参数 / 定义 | 展示及边界 |
| --- | --- | --- |
| MACD | DIF=EMA12-EMA26；DEA=EMA9(DIF)；柱=2×(DIF-DEA) | 明示国内常见的 2 倍柱约定，避免与其他软件误比较 |
| RSI | 14；涨跌额分别用 Wilder 平滑 | 上下界 0–100；涨跌都为 0 取 50，仅平均跌额为 0 取 100，仅平均涨额为 0 取 0 |
| KDJ | 9 / 3 / 3；RSV 用 9 根高低范围，K、D 递推，J=3K-2D | 初始 K/D=50；高低差为 0 时 RSV=50；J 不强行裁剪到 0–100 |
| ROC | 10 / 20，`C[t]/C[t-n]-1` | 以百分比显示；明确是价格变化，不冒充含分红总回报 |
| 区间位置 | 当前价格在过去 250 根高低范围中的位置 | 不称为概率或未来上涨空间 |

RSI 的 30 / 70、KDJ 的 20 / 80 仅为可调整参考线，不写成保证反转的信号。背离识别后置：使用需要未来柱确认的拐点算法时，事件必须落在确认时刻，不能回填为当时已知。

### 4.3 波动与风险

| 指标 | 拟定参数 / 定义 | 展示及边界 |
| --- | --- | --- |
| ATR / ATR% | TR=max(H-L, abs(H-Cprev), abs(L-Cprev))；Wilder14；ATR/C | 波动幅度与跨股票比例对比，不预设止损订单 |
| 历史波动率 | 20 / 60 个对数价格收益，样本标准差×sqrt(252) | 只对日线使用此年化假设；分钟周期不机械套用 |
| 回撤 | C/历史累计最高 C-1 | 说明计算起点；窗口最大回撤与全历史回撤分开命名 |
| 振幅 | (H-L)/上一有效收盘价 | 称“按前收计算的振幅”，不覆盖供应商原始字段 |
| BOLL 带宽 | (上轨-下轨)/中轨 | 展示波动收缩与扩张，不自动推断突破方向 |
| 缺口 | O/Cprev-1 | 除权、停牌复牌可能影响解释，应结合口径与数据质量提示 |

未复权价格可能因公司行动出现跳变。没有公司行动信息时不自动识别或“修复”异常，更不能把所有大幅变化判定为交易机会。

### 4.4 量价与流动性

| 指标 | 拟定参数 / 定义 | 展示及边界 |
| --- | --- | --- |
| 成交量均线 | VOL MA5 / MA20 | 与日成交量柱叠加 |
| 相对成交量 | 当日量 / 前 20 根成交量均值 | 命名 RVOL20，与供应商盘中“量比”严格区分 |
| 成交额 / 换手率 | 展示现有原始字段及滚动均值 | 换手率按百分数显示；不要再乘 100 |
| OBV | 收盘涨加 V，跌减 V，平不变；首值 0 | 起点影响绝对值，比较走势时标清起点 |
| MFI | 14，典型价×成交量按典型价方向分组 | 零流量和单边流量需有固定边界规则及测试 |
| 成交均价 | 成交额 / 成交股数 | 仅配未复权价格；不能用未复权成交额生成后复权“均价” |
| 流动性代理 | 20 根均值(abs(价格收益)/成交额) | 展示缩放单位；零成交额排除并报告有效样本数，不作为真实冲击成本 |

分钟 VWAP 仅在金额与成交量是同一时间段、非重复累计且单位已确认时计算。不能只用日 K 线重建真实盘中分时或 VWAP 轨迹。

### 4.5 统计摘要与研究对照

- 选中日期：OHLC、前收、价格变化、成交量、成交额、换手率、当前所选指标。
- 选中区间：起止日、记录数、价格变化、最高 / 最低、区间最大回撤、平均成交额、缺失记录提示。
- 周 / 月 K：从同口径日线聚合首开、最高、最低、末收及成交量 / 额之和；末周 / 月标注未完成。没有日历证据时，不把无记录日期当作交易日缺失。
- 周 / 月换手率不冒充供应商同周期指标；若展示日换手率之和，必须明确其是简单累计值。
- 跨股票对比采用同一基准日归一化价格，而非把数十元和数千元价格放在同一轴；不因价格曲线归一化而宣称复权差异已消除。
- 基准相对表现、滚动相关性、Beta 需先有对齐且口径明确的指数数据，目前只列为候选，不从单股文件编造基准。
- 历史研究动作可在 K 线上标记，但必须区分决策时点、目标仓位、实际回测成交；日线收盘决策不能画成当日开盘已成交。

## 5. 统一计算契约

所有指标登记 `indicator_id/version/parameters/required_columns/warmup/units/supported_frequency`，返回与原始日期对齐的数值和有效掩码。

1. 严格按日期升序、股票、价格口径、频率分别计算；禁止跨股票串接、跨口径拼接。
2. 滚动窗口使用当前及过去数据；缺失期不插值伪造价格，缺失区间显示断点。周期参数默认按记录条数，而不是自然日。
3. EMA 统一首个有效价格为种子、递推不回溯修正，并屏蔽前 n-1 个结果；Wilder 平滑使用前 n 个有效样本的均值为种子，之后权重 1/n。遇到数据断裂，后续重新预热。
4. 指标预热从完整可用历史开始，计算后才裁剪显示区间；缩放或切换近 30 条不重置 EMA。MACD 的 DEA 在 DIF 有效后独立预热。
5. 分母为零、不足窗口、非有限输入产生明确定义的 null / 边界值，禁止 Infinity、NaN 直接输出为可用数值。指标专属规则优先于通用规则。
6. 周期重采样后重新计算指标，而不是抽取日指标当作周指标。日线与分钟隔离；不能使用尚未结束的高周期柱提前生成低周期历史信号。
7. 单一后端计算入口供图表与测试使用；缓存键包含源文件哈希、股票、口径、频率、指标版本与参数，不缓存成独立“新行情”。
8. 基础 SMA / EMA 先与现有实现逐项对照。若现有训练公式不同，保留旧模型契约，展示用明确版本，不能为了统一图表静默改训练算法。

## 6. 页面设计

沿用工作台的紧凑布局，不做营销页面或层层嵌套卡片。

- 顶部标的栏：代码、名称、行业、最新已存价格、业务日期、口径、来源和数据时效。没有资料时不阻塞价格图。
- 主图工具栏：股票、快照、日 / 周 / 月 / 分钟周期、价格口径、区间、K 线 / 曲线模式、重置缩放图标。
- 主图叠加项：MA / EMA / BOLL / Donchian，通过菜单和复选框选择；参数用数值输入。默认 MA5、MA20，不全部开启。
- 副图默认成交量；可另选 MACD、RSI、KDJ、ATR%、成交额、换手率、资金流，最多同时增加两幅。
- 十字光标和时间缩放联动；悬停日期的数值与顶部“末条记录”摘要清楚区分。副图使用独立单位和纵轴，不将金额、百分比及价格混在一起。
- 资料 / 盘口 / 资金流独立标签页；无导入数据时只给空状态和导入入口，不自动联网、不制造示例数值。
- 指标参数保存在本地界面偏好中，不写入训练配置。切换股票保留偏好，参数不合法则阻止应用。
- 手机端主图占满内容宽度、工具栏换行，副图纵向排列；图例可滚动，坐标和悬浮信息不得遮挡价格摘要。

## 7. 与模型的关系

本方案第一阶段全部是只读展示，不改变现有 20 个特征、scaler、观察空间、股票池、模型权重或研究计划。

未来新增模型特征需单独立项：去除明显冗余，按时间可得性筛选，优先比例或有界量，训练集拟合标准化，建立新数据与特征契约版本，重新训练并做消融测试。原模型不得直接接收新增列。

RSI、MACD 等来自同一价格序列，指标数量增加不等于独立信息增加。先以少量代表性指标比较验证期结果、成本与稳定性，不能基于已查看的最终测试区间反复选参数并仍称其为未见测试。

盘中报价、基本面和资金流暂不进入日线 PPO。尤其不能把今天下载的市值或财务截面复制到过去训练日期；缺少历史可得时间时只展示，不用于回测。

## 8. 实施顺序与验收

以下为本扩展的建议工作包，不替代项目阶段一至五的进度表；所有新增工作包均未实施。

| 顺序 | 范围 | 验收重点 |
| --- | --- | --- |
| A：本地日线增强 | 详情摘要、成交额 / 换手率、参数化均线、MACD / RSI / BOLL / ATR%、周月 K | 不联网即可完成；算法、预热及重采样测试；不改变模型 |
| B：手动导入基础 | 元数据、预览校验、原文件归档、个股资料和行情截面 | 下载由用户执行；单位和时间未知不冒充已知；坏文件不发布 |
| C：分时与盘口 | 分钟独立契约、分时曲线、五档快照 | 分钟开盘缺失处理、时区、过期标识、未完成柱及成交量单位 |
| D：更多分析 | KDJ / ROC / OBV / MFI / RVOL、资金流、研究动作叠加 | 公式一致、来源可追踪、不混淆研究动作与真实成交 |

统一测试要求：

- 固定小序列验证手算结果；覆盖上涨、下跌、横盘、零量、缺失、重复、乱序、短历史及异常值。
- 前缀不变性：追加未来记录，不得改变之前已完成柱的指标结果；区间缩放前后同日期值一致。
- 与仓库既有算法或经确认的参考实现比较；不要求不同初始化约定下数值盲目相等。
- 导入测试完全离线，使用明确标识的合成样例；真实数据验收由用户提供样本，缺失类型标记“待样本”，不伪称已通过 API 验收。
- 浏览器覆盖切换股票 / 口径 / 周期 / 参数，空状态、加载失败、快速切换的旧请求覆盖保护，桌面 / 手机截图及非空画布检查。
- 查看、缩放、切换指标和导入预览不能创建网络任务、训练任务或订单；原快照和原模型文件哈希不变。

首轮优先 A，然后 B。盘口和资金流先不作为主界面依赖，避免等待额外下载才能使用已有日线。

## 9. 结合现有 PPO 的训练建议

### 9.1 先核对已存在的输入，避免重复加指标

已核对 `src/data/preprocess.py`、`configs/ppo.json`、`configs/ppo_lightweight.json` 和 `src/envs/trading.py`：

- 现有 20 维特征已有收益 / 对数收益、振幅比例、实体比例、相对成交量、换手率、RSI、价格归一化 MACD 与信号线、BOLL 位置、5 / 10 / 20 / 60 根动量及均线偏离、20 / 60 根波动率。
- 当前 RSI 使用 14 根简单滚动涨跌均值，值域为 0–1，并非第 4 节拟展示的 Wilder RSI。现有成交量比使用包含当前柱的 20 根均值，也不同于拟展示的 RVOL20。
- 现有波动率为简单收益的总体标准差、没有年化；拟展示的年化对数收益波动率是另一种统计，不能互相冒名。
- `lookback=1`，共享股票网络隐藏层为 128 / 64；指标本身携带历史摘要，但模型没有直接观察多日指标轨迹。
- 当前日奖励是扣除环境交易成本后的账户净值简单收益；收盘决策、下一开盘执行。不是按技术指标是否“猜对”奖励。

因此，第一步不是把图表的所有指标塞进模型，而是给当前特征建立可解释的原始值 / 标准化值对照。面板中标注公式版本，避免用户看到的 RSI 与模型输入不一致却误以为模型出错。

### 9.2 首批候选特征与暂缓项

以下是待验证假设，不是已证明有效的增强方案。

| 候选 | 相对现有输入的作用 | 处理建议 |
| --- | --- | --- |
| ATR14 / C | 补充跳空与日内波幅信息，区别于收盘收益波动 | 优先做单独消融，不输入绝对 ATR |
| 60 根窗口价格回撤 | 描述近期峰值距离 | 窗口内最高收盘归一化；只用当前及过去数据 |
| BOLL 带宽 | 与现有 BOLL 位置互补，描述通道宽度 | 与波动率可能冗余，作为备选，不能默认必加 |
| 相对成交额 | 当日成交额 / 前 20 根均额 | 独立单位校验；与 volume_ratio 做替换对照，而非无条件叠加 |
| 换手率相对变化 | 当前换手率相对自身历史水平 | 缺失 / 零分母设掩码，先检查极值与稳定性 |
| 市场截面摘要 | 同期有效股票的中位收益、上涨比例等 | 后续候选；池变化会改变定义，需明确是训练池还是外部基准 |

暂不直接加入绝对股价、原始市值、原始 OBV、所有均线数值、几十个高度相似指标。KDJ / RSI、MFI / 量价指标优先做替换实验，防止增维后只增加噪声。

当前单只 000001 的新数据适合验证导入和推理链，不足以证明跨股票泛化，也不能用它替代旧模型的完整输入池。现有单股目标仓位上限为 5%，单股实验的风险暴露明显不同于多股组合，不能直接比较收益率后宣称优劣；不为单股演示静默放宽上限。

### 9.3 先研究时间信息，再更换大模型

建议保留共享网络和现有动作结构，先独立比较 `lookback=1` 与 `lookback=5`。只有前者对照明确、额外时间信息有稳定价值，才评估 20 根或独立的时序编码器。

增加 lookback 会改变输入维度、预热和样本数量，须建立新契约并重新训练，不能套用旧 checkpoint。比较时使用共同有效日期，报告参数量、耗时和有效步数，不能把增加计算量带来的改善全归因于时间结构。

暂不同时引入 LSTM / Transformer、新奖励、几十个新指标和新股票池。每次改变一个主要因素，才可定位效果来源。

### 9.4 标准化与跨股票泛化

继续区分特征与执行价格：指标先尽量转成比例，再仅在训练范围拟合 scaler；回测 / 预测固定 scaler，执行和估值读取独立价格数据。当前目标权重动作不需要对预测价格“逆标准化”，因为 PPO 并不输出标准化价格。

新增稳健缩放、截尾或在线标准化均应作为独立实验。阈值只在训练集确定，记录被截断比例；不能基于全时期分位数截尾。不要再叠加一层动态 `VecNormalize` 后忘记冻结或保存其统计。

跨股票实验需同时隔离股票和时间：固定训练股票组、开发股票组、保留股票组；不按未来收益挑组。scaler 只用训练股票及训练时段拟合，调参只看开发组，保留组最后评估。当前既有 scaler 使用完整训练股票池统计，因此旧 32 股实验不是严格的未见股票测试。

共享参数能支持迁移，但不保证任意池大小下表现相同。扩池仍需显式迁移与契约核验，并报告池大小、现金占比、仓位上限触发率和实际持仓集中度。

### 9.5 奖励与交易成本

现有奖励已经体现手续费和滑点。先检查成本与换手，不直接再扣一次同等交易成本。

如多随机种子的验证结果仍显示过度交易，可单独研究 `净值收益 - lambda × 实际成交换手率`；这里第二项是额外行为正则，不是补记费用。`lambda` 只能通过预先规定的开发实验选择。评价报告仍使用实际净值和真实配置成本，而非把带惩罚奖励当收益。

回撤惩罚后置；若奖励依赖账户历史峰值或其他路径状态，应明确状态定义并检查观察是否充分。不要把“RSI 低买高卖”写入奖励来强迫 PPO 复现预设指标规则。

维持潜在动作、分布 log-prob 与目标权重映射的现有一致性。新增指标不是修改 PPO 概率计算的理由。展示买入 / 减仓来自目标与持仓差，不将某个指标阈值直接冒充智能体动作。

### 9.6 轻量研究矩阵

拟定首轮预算，后续执行前另行确认；本次不训练：

| 组别 | 唯一主要变化 | 建议用途 |
| --- | --- | --- |
| B0 | 现有 20 特征，lookback=1 | 重跑基线，检验随机种子波动 |
| F1 | B0 + ATR14/C | 波幅特征消融 |
| F2 | B0 + 60 根回撤 | 路径状态特征消融 |
| T1 | B0，lookback=5 | 时间窗口消融 |

每组先 512 步烟雾检查，再按 3 个固定种子（42 / 123 / 2026）、每种子 8,192 步做探索性比较。正式实验步数合计 98,304，不包含烟雾检查和评估；这仍是小预算筛选，不是收敛或策略优势证明。

首轮保持既有 PPO 超参数：n_steps=256、batch_size=64、learning_rate=3e-4、n_epochs=10、gamma=0.99、gae_lambda=0.95、clip_range=0.2、target_kl=0.03。不同配置保持相同的验证频率、检查点选择规则与计算预算，规则在运行前写入实验协议，不根据结果临时更换。

只有单项变化稳定后，才建立组合特征组和更大训练预算。暂不做大规模参数搜索。多种子和独立评估的原则参考 [SB3 实验建议](https://stable-baselines3.readthedocs.io/en/master/guide/rl_tips.html)；参数含义参考 [SB3 PPO 文档](https://stable-baselines3.readthedocs.io/en/master/modules/ppo.html)。官方网页版本不等于本仓库依赖版本，执行仍以已安装版本及锁定配置为准。

### 9.7 验收比单次收益更重要

开发期比较至少报告：成本后收益、Sharpe、最大回撤、换手、手续费 / 滑点、现金占比、成交拒绝原因，以及不同种子的中位数和范围。三种子的范围不是置信区间，不作统计显著性保证。

训练诊断增加：KL、clip fraction、策略熵、价值损失、explained variance、梯度异常、动作幅度、映射后权重变化和仓位上限触发率。新增日志字段是否已由现有事件接口完整暴露，实施时逐项核对，不把计划字段当已存在。

与等权、现金及既有基线在相同日期、股票池、费用和约束下比较。当前报告中 PPO 相比等权并未同时改善风险和成本，不能只按收益略高选择“升级成功”。建议晋级条件在实验前确定为：跨种子与多个时间开发窗口结果稳定、成本与风险退化可解释、没有单一股票贡献主导，不设事后挑选的门槛。

过去已查看的测试区间保持“已暴露”标识。新增数据只有在完整股票池、历史口径和时点一致性核验后，才可划定新的保留区间；单股新日线不能充当组合新测试集。供应商今日重算的复权历史也不自动具有历史时点可得性，需持续披露修订和幸存者偏差。

### 9.8 建议结论

先完成行情展示与现有 20 特征的解释对照，再开展 B0/F1/F2/T1 小规模消融。优先提高数据契约、对照实验和成本诊断的可信度；不要以指标更多、网络更大或训练步数更多替代泛化证据。手动导入的新资料、盘口与资金流先服务展示，满足历史时点和覆盖要求后再独立评估是否进入模型。
