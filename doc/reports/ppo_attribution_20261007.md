# 行情/账户分离的机制归因研究

日期：2026-10-07。**24次正式训练、48份快照和全部264条验证路径已执行完成，实际RL为98,304步，最终离线测试和独立完整性审计通过。预注册研究候选为null，actionable=false，未升级工作台或实盘默认。** 本报告把此前分阶段记录整合为完整研究结论，验收范围见末节。

## 研究结论

1. **纯行情市场摘要在长预算下有观察优势，但不是普遍胜出。** 跨fold平均、三个训练seed的4,096步结果中，pure_shared为+0.702734%，fused_shared为-0.079890%；完整factorial的fused减pure为-0.662057个百分点。2,048步时方向反过来，fused减pure为+0.656019个百分点，说明结构优势依赖预算、年份和初始行为。
2. **阻断Critic到编码器的梯度没有带来稳定收益改善。** 跨fold的detached减shared为短-0.083679、长-0.143085个百分点；不同route、年份和seed的效果不同。本轮不支持“Critic共享梯度普遍有害，所以直接detach即可改善交易”的解释。
3. **同参数初始化不能消除初始策略函数差异。** pure/fused同seed参数字节相同，但路由改变前向函数。必须分别减去自身初始化收益；该算术分解仍不能排除探索、状态访问、交易支持和学习轨迹变化。
4. **拟合指标、梯度方向和净收益需要分别看。** 某些配置Critic explained variance改善而净ROI更差；固定batch的combined编码器Critic梯度比例较小，也不能证明所有子模块均不受影响，或把几次负cosine当收益下降原因。
5. **没有可晋级模型。** 2023折全部八个cell/预算单位的最坏账户回撤都超过10%，按两fold各自通过的预定门槛，全部候选被排除。仍完整执行了2024，未因中途风险失败减少预算、挑seed或追加赢家实验。

## 同构2×2设计

| cell | market_context | critic_features | 干预 |
| --- | --- | --- | --- |
| pure_shared | pure | shared | 纯行情市场摘要，value loss反传编码器 |
| pure_detached | pure | detached | 纯行情市场摘要，阻断value loss到编码器 |
| fused_shared | fused | shared | 行情/账户融合摘要，value loss反传编码器 |
| fused_detached | fused | detached | 融合摘要，阻断value loss到编码器 |

```text
m = market_encoder(stock_features)
a = account_encoder(account_fields)
z = tanh(m + a)

pure market  = masked_mean(m)
fused market = masked_mean(z)
held         = sum(current_weight * z)
context      = [market, held, cash, receivables, allocation_context]

actor           = stock_heads([z, context])
shared critic   = value_head(context)
detached critic = value_head(context.detach())
```

各cell保持同一有效mask、个股融合z、持仓摘要、动作头、整手/T+1/费用和执行规则。无有效股票时market为有限零值；无效但仍持有的资产保留在held摘要中。纯行情摘要不随账户字段改变，但交易决策仍获得账户信息，不是丢掉持仓状态。

每fold/seed四cell的同序state_dict逐tensor字节和同basename policy.pth SHA严格相同，参数总量均125,063。同route的shared/detached初始前向相同，合法复用初始化控制；pure/fused初始前向不同，不能跨route复用收益。

**detach不是独立Critic。** value head照常训练，Actor照常更新编码器，Critic输入仍随Actor表示漂移；二者仍共用PPO优化器和global max_grad_norm=.5，value head梯度仍可通过全局裁剪影响Actor有效步长。Critic估计还会参与后续GAE和Actor训练目标，因此这不是关闭Critic、独立优化器或完全消除耦合的实验。

## 归因与交互

route主效应为平均两种Critic设置后的fused减pure；Critic主效应为平均两个route后的detached减shared。交互定义：

```text
interaction = (fused_detached - fused_shared)
              - (pure_detached - pure_shared)
```

## 梯度与Critic诊断

共96份记录，均为每个快照对应rollout原顺序前128个训练样本，pre/post使用完全相同obs/actions/old_log_prob/advantages/returns；48份batch不是额外交易经历。诊断使用autograd.grad，不执行优化、不改变参数、已有grad、优化器、RNG或buffer；状态保持检查全部通过，额外优化更新为0。

| shared设置 | combined encoder的vf加权Critic/Actor norm比中位 | cosine中位 | 负cosine数 |
| --- | ---: | ---: | ---: |
| 2023/pure | 1.4866% | -0.01648 | 8/12 |
| 2023/fused | 1.4262% | -0.01373 | 8/12 |
| 2024/pure | 1.8014% | +0.00861 | 5/12 |
| 2024/fused | 1.7168% | +0.01045 | 3/12 |

48份detached记录的Critic到编码器梯度norm均0、cosine均null，这是结构定义；value head仍有非零Critic梯度，Actor编码器梯度仍保留。combined范数比小不等于每个子模块无影响：2023 account encoder的最大比值为pure 12.5500%、fused 12.1158%。

没有看到跨年份普遍强负cosine的证据，因此不能把此前收益改善解释成已证实的严重梯度冲突消除。固定前128样本并非实际PPO shuffle minibatch；这些是裁剪前loss梯度，不是实际合并裁剪或Adam参数变化，也不是收益改善方向。不同cell后续状态/目标不同，跨cell梯度比较还混入了轨迹差异。

2024/shared下fused相对pure的tail Critic v2 explained variance均值短/长提高+0.105123/+0.120204，各2/3 seed改善；但long净ROI反而低1.166109个百分点。2024/pure中detach的tail EV短/长低0.021844/0.019822，六个seed/预算方向均负。**Critic拟合是学习诊断，不是策略效果替代指标。**

已有原生验证记录中，active size均值绝对值中位约0.004至0.021，而sigma约0.496；方向合法支持、topN和资金投影还会进一步改变实际成交。训练采样与确定性部署不匹配仍是下一轮假设，但本轮没有追加采样回测或据此挑选部署规则。

## 下一步建议

1. **保留可解释分离结构，但不将其收益优势作为定论。** 下一轮以pure_shared为一个固定参照，同时保留fused参照；按预登记多时期检验，不把本轮长预算观察优势当普遍泛化证明。
2. **优先研究决策与成交之间的投影。** 分别统计方向选择、size/priority、topN/资金过滤及最终成交的信用分配；探索预算感知、稀疏交易或HOLD门槛必须另立协议，不从本轮结果直接添加惩罚并回填成功。
3. **独立检验随机训练与确定性部署落差。** 固定模型、固定多组采样种子，对比完整路径分布与确定性策略，不挑最好随机路径，也不直接建议随机实盘。
4. **若继续Critic研究，做真正可区分的干预。** 独立Critic编码器、分组裁剪/独立优化器或动作级信用分配与本轮detach不同；需保持预算、初始函数、执行机制和自身初始化控制，并明确GAE/目标变化。固定batch梯度不足以证明这些设计有效。
5. **真实交易口径优先于进一步扩模型。** 补齐未复权成交、复权信号、公司行为与历史交易状态账本，再讨论每日收盘配置能否实际执行；保留真正未暴露时期验证，避免在同一季度反复调到盈利。

上述是后续研究建议，未在本轮实现或追加训练。没有新GRU、监督辅助任务、稀疏Actor、独立Critic或额外股票数据。
