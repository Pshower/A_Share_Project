## 已观察到的收益与动作

| 开发折 | M20 净 ROI | A 8K 净 ROI / 差 | A 32K 净 ROI | A 32K 相对差 |
| --- | ---: | ---: | ---: | ---: |
| 2023 Q2 | 5.5415074463% | 5.5415074463% / 0pp | -1.4677821307% | -7.0092895770pp |
| 2024 Q2 | 1.2086218544% | 1.2086218544% / 0pp | -1.6867165801% | -2.8953384346pp |

**8K 的部署动作不变，不等于没有探索或没有参数更新。** 前 8,192 个真实训练状态中，2023 随机采样了 1,292 次非到期额外 R、41 次到期 H；2024 为 1,225 次及 43 次。该阶段保存的训练状态中，greedy 动作尚未偏离日历。8K 的 Q2 四账户均无额外 R、无跳过到期 R，经济路径与基线相同。

| 非到期最大 P(R)，cash 账户 | .416944 | .945809 | .169191 | .641298 |
| 每个账户的额外 R 次数 | 0 | 38 | 0 | 9 |
| 每个账户跳过到期 R 次数 | 0 | 0 | 0 | 0 |

32K 同一折的四账户额外调仓日期完全相同。2024 的 9 个成交日为 4 月 2、3、8 日，5 月 7、8、9、10、13 日及 6 月 5 日；这是执行日期，不冒称同日收盘决策。账户之间概率略有区别；初始账户还可能在日历调仓后趋同，故相同日期不能单独证明模型忽略账户。

已保存概率支持一个直接解释：训练早期已改变概率，但 greedy 尚未跨过 `.5`，后来累积漂移才改变部署动作。它不证明每一次额外 R 的独立因果损失。

## R 同时改变换股与建仓速度

冻结的 `EconomicRule` 对仍入选且买入合法的股票再次产生 BUY，对落选且允许退出的股票产生 EXIT，并受每次交易上限、整手及持仓上限复核。因此 R 不是保持已投资金额不变的纯换股，也不是每次恢复固定总暴露；重复 R 同时影响换股时点、建仓速度、现金和成本。

| 四账户平均量 | 2023 M20 | 2023 A 32K | 2024 M20 | 2024 A 32K |
| --- | ---: | ---: | ---: | ---: |
| 平均现金比例 | 43.125845% | 22.034124% | 53.463874% | 37.964370% |
| 总换手 | 2.331331 | 8.743642 | 2.112123 | 4.607141 |
| 费用加滑点，元 | 3,744.425537 | 13,627.071307 | 3,356.531456 | 7,246.415801 |

额外已实现成本分别为 9,882.645770 元和 3,889.884346 元，相当于 100 万元初始资金的约 .988265pp 和 .388988pp，低于对应 7.009290pp 和 2.895338pp 的净值差量级。**不能把全部退化归于手续费。** 这只是实际两条路径上的成本比较；费用会影响后续现金与可成交数量，不能直接加回成本便声称完成了零成本反事实回测，也不能把剩余差全部独立归因于某个风险因子。

下一阶段值得检验的是：当前所谓“调仓时点学习”是否主要学成了更快使用现金和更频繁轮换。上述现金、换手、动作与收益的共同变化提供候选机制，不提供独立因果识别。

## Critic 与 bootstrap 的代数证据

仅使用保存的 64 份原始 rollout 和对应 credit sidecar，分别重算旧 V 对当时 return target 的解释方差。2023 的 64 个 buffer 中 62 个为负，2024 为 64 个。这里的 V 是采集时的旧预测，不是重新 forward，也不是训练完后用最后模型回看旧数据。

为衡量已有 target 中的 bootstrap 成分，令每份 512 步记录的 `raw_rewards` 为加入 timeout bootstrap 前保存的 float32 奖励，令 `d_t` 为保存的 done 标记，定义：

```text
M_512 = 0
M_t = raw_reward_t + .995 * (1 - d_t) * M_(t+1)
B_t = saved_return_target_t - M_t
```

`M` 只是沿已经记录的同一段轨迹累计到 done 或 rollout 末端的奖励，故在两类记录边界均停止；`B` 包含原算法在 TimeLimit 终点或活动 rollout 尾部使用的价值 bootstrap，以及浮点累计差。**M 不是缺失未来续行的无偏回报，不是完整长期真实收益，也不是建议替换当前 GAE 的新训练目标。** 对 `lambda=1` 做该分解，不会消除 bootstrap。

下表每个 RMS 先在一份 512 步 buffer 内计算，再对该分组的 buffer 取平均；不是全样本拼接后的单个 RMS，单位也不是 ROI 百分点。

| 折 / rollout | 负 EV 数 | EV 中位数 | 旧 V 的 RMS | saved target RMS | M 的 RMS | B 的 RMS |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 2023 / 1 至 16 | 16 / 16 | -2.142392 | .201211 | .141534 | .037831 | .127481 |
| 2023 / 17 至 64 | 46 / 48 | -.692752 | .054430 | .054962 | .043732 | .030313 |
| 2024 / 1 至 16 | 16 / 16 | -3.519406 | .193329 | .118684 | .040575 | .101476 |
| 2024 / 17 至 64 | 48 / 48 | -.882462 | .057028 | .051726 | .038693 | .029772 |

每折保存了 92 次 TimeLimit、44 次非 TimeLimit 的自然终止，以及 60 份尾部仍活动的 rollout；137 条 episode 记录中含 136 条已结束 episode 和最后一条未结束片段。计数只描述原生已保存训练，不能当额外样本。

证据表明：早期随机 Critic 的输出尺度，以及被传入 return target 的 bootstrap 成分，明显大于记录内已实现奖励项；旧值预测的解释能力也很弱。这使“早期 Critic/bootstrap 尺度影响动作信用分配”成为可检验候选。**尚未证明 Critic 是退化的唯一原因，更未证明删掉 Critic、取消 bootstrap 或改小 lambda 必然提高收益。** target 方差、市场路径和策略同时变化，value loss 下降也不能单独证明 Critic 变好了。

## 局部 KL 与市场经验覆盖

训练日志最后可见的局部近似 KL 分别约 `.000238/.001685`，但非到期 P(R) 已累计上移。`target_kl` 比较最近 rollout 的旧策略与当前更新，不是持仓距离，也不是相对最初日历策略的累计约束。逐次更新小，不能证明部署行为长期接近日历；它同样不证明添加固定日历 KL 惩罚就会产生正收益。

这些日期均在对应 outer-train 内。三分之一左右经历重访同一 latest 窗口，有账户和动作多样性，但没有创造新的市场路径。两折训练历史还相互嵌套，只有开发 seed42；不能将 32K 称为 32K 份独立市场实验。

线性 Actor 对 phase 与连续 context 仅作加和，确有表达条件交互的限制。不过此前 `DuePhaseActionHead` 已做过 due-context 扩展且未通过筛选，不能把同一设计重新包装为未经验证的新突破。

## 本轮结束后可预注册的受控检验

1. 优先比较默认 Critic 与价值输出层零或小 gain 初始化，保持 Actor、容量、数据、真实 PPO 预算及经济机制一致。保存初始/早期 bootstrap 尺度、Actor/Critic 梯度和全局 clipping 证据，再看同口径净收益及正 PPO 增量。该假设针对早期尺度，而不是声称只需“更大网络”。
2. 将换股时点和使用现金的速度分开检验。任何新 Agent 动作或订单预览特征都须另行预注册；预览只能来自当前可得状态，不得使用次日实际开盘、成交或未来标签。M20 强基线仍按原机制执行，不能换成容易对手。
3. 若研究日历锚定或累计漂移约束，应明确这是新目标/正则化，保留不加该项的真实 PPO 对照。避免退化不等于超过基线；静止回到日历也不证明正学习增量。
4. 覆盖改进应承认日期复用和相关性，采用固定时间/账户计划与多 seed，而不是依据这次 Q2 赢家后补样本、挑 checkpoint 或挑 seed。

这些是候选受控实验，不是当前冻结研究的追加条件或已执行结果。最终仍需完整 B、固定开发筛选及被授权的跨时间多种子确认，同时满足正学习增量和预注册风险条件；不观察保护期、不晋升默认模型。
