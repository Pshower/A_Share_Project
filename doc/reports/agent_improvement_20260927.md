# 稀疏与先验残差 Agent 研究报告

## 结论与准入

按 [训练前协议](../agent_improvement_protocol_20260927.md)，找到优于上一版稠密 PPO 的研究候选 **R1：动量先验主导的稀疏配置 Agent**。它通过了开发门槛，但不是全面优于其他策略，也没有证明 PPO 学习本身带来收益增量。

| 开发窗口 | 新候选平均收益 | 比较对象平均收益 | 候选最大回撤幅度 | 说明 |
| --- | ---: | ---: | ---: | --- |
| 2026-04-01 至 06-30，60 步 | +17.4305% | 上一轮 PPO -1.9939% | 4.6729% | 三种子、四账户；每账户均提升超过1个百分点 |
| 2025-07-01 至 12-31，126 步 | +16.6230% | 匹配 D0 +2.5869% | 9.3729% | 两种子、四账户；重新拟合 scaler、从头训练 |

这些是开发比较，不是独立最终测试证据。收益提升伴随回撤增加：2025 年控制组最坏回撤约 1.62%，R1 约 9.37%；该窗口平均 Sharpe 也从约 1.671 降至 1.578，因此不能称为所有风险指标都改善。最大回撤10%只是本轮历史开发门槛，不是未来损失保证。

资格检查结果为 `qualified_under_development_protocol=true`，但发布状态仍为 `research_candidate_only`、`actionable=false`。详见 [机器可读资格记录](../../reports/runs/agent_improvement_20260927/qualification.json)。

R1用当前有效股票的20日动量截面排名作为主要评分，再加有限幅度的神经网络残差；只保留评分最高的20股，经仓位上限映射得到目标比例。未入选股票权重为零，可表达退出意图；买卖数量仍由目标与现有持仓差产生，尚无独立的“完全不下单”动作。

## 核心发现：不要把先验收益当成学习收益

| 阶段/方案 | 训练后四账户平均收益 | 未训练初始化平均收益 | 判断 |
| --- | ---: | ---: | --- |
| 筛选 D0：原稠密映射 | -2.0203% | -1.9775% | 训练未改善 |
| 筛选 D1：低噪声及较小学习率 | -1.9734% | -1.9775% | 改善极小 |
| 筛选 S1：稀疏20股 | +13.5880% | +14.7496% | 改善主要来自结构/初始化，训练反而退化 |
| 筛选 R1：动量先验残差 | +17.4315% | +17.4314% | 基本相同 |
| R1 三种子确认 | +17.4305% | +17.4314% | 学习增量约 -0.0009 个百分点 |
| R1 两种子2025年窗口 | +16.6230% | +16.6472% | 学习增量约 -0.0242 个百分点 |

R1 的低种子方差主要因为先验支配决策，不能据此宣称强化学习训练已经稳定。若目的是纯粹追求当前开发结果，未训练的先验本身几乎解释全部收益，神经网络残差暂时没有证明必要性。本轮不通过挑选某个种子或中途 checkpoint 来掩盖这一点。

## 强基线比较

下表为四账户平均收益；最大回撤取各账户中的最大幅度。所有对照使用同一窗口、同一初始账户种子、同一成本和 HFQ 执行假设。

| 窗口 | 策略 | 平均收益 | 最大回撤幅度 |
| --- | --- | ---: | ---: |
| 2026年4—6月 | R1（三种子平均） | +17.4305% | 4.6729% |
| 2026年4—6月 | 每日等权 | -1.9952% | 2.6242% |
| 2026年4—6月 | 每日动量 | +17.5852% | 5.4359% |
| 2026年4—6月 | 20日调仓动量 | +25.1558% | 3.7786% |
| 2025年7—12月 | R1（两种子平均） | +16.6230% | 9.3729% |
| 2025年7—12月 | 每日等权 | +2.8240% | 1.6161% |
| 2025年7—12月 | 每日动量 | +16.9797% | 10.4010% |
| 2025年7—12月 | 20日调仓动量 | +21.9204% | 8.9333% |

R1 相比每日动量牺牲少量收益、降低了回撤；20日动量在两个窗口仍然更强。不能省略这个基线后宣布 PPO 最优。策略调仓频率、实际仓位漂移和成本不同，均属于策略差异，不应仅按收益排序发布。

R1 的费用加滑点平均约为：2026年确认期 13,418 元，2025年窗口 45,042 元；后者 D0 约 5,059 元。新方案不是“更高收益且更低成本”的全面占优方案，净收益已经扣除上述成本。

- 每四个训练 episode 有一个取训练期末尾窗口，其他随机，最大256步。增加逐股有效观察次数审计。2026年筛选每股至少64次有效观察；确认至少128次。但001280仍只有17个不同训练特征日，重复采样不能创造独立信息。
- 2025年训练中001280、600930没有有效观察，保留维度并掩码处理，没有偷偷删除；这是晚上市股票的冷启动局限，不宣称全部300股都拥有充分学习证据。
- 所有候选均使用固定最终 checkpoint 比较，未以最高中间回测收益选 checkpoint。2026-07-01以后没有执行策略绩效评估。
