# 轻量 PPO 训练与回测详细报告

日期：2026-09-25。简版结论见 [报告摘要](ppo_lightweight_20260925_summary.md)。

## 1. 结论与完成范围

本次按 Pipeline 完成了“本地数据校验 -> 轻量训练检查 -> 预定预算训练 -> 验证选模 -> 冻结模型及配置 -> 最终测试回测 -> 共同基线比较”。没有下载行情，没有重新拟合标准化参数，也没有根据最终测试表现修改模型或超参数。

PPO 在验证集获得 12.02% 累计收益，在最终测试获得 29.71%。但验证集未超过简单等权；最终测试相对 20 日等权仅多 0.41 个百分点收益，同时 Sharpe 更低、回撤和交易成本更高。因此结论是 **端到端训练框架已运行验证，策略优势尚未成立**，而不是已经找到可实盘的盈利策略。

本次结果只适用于固定 32 只股票、单随机种子和小预算。阶段四的轻量训练与日期留出测试已经执行；全 298 只股票训练、滚动研究、跨股票留出与成本压力测试仍未完成。

## 3. 模型、行为与执行假设

模型为共享股票 MLP 128 -> 64，共 40,901 个可学习参数。输入为 `[32, 1, 20]` 标准化相对特征、当前持仓/现金/应收比例和有效/买卖掩码。输出 33 个潜在分数，经过掩码、softmax 和单票上限，得到 32 个目标股票权重及剩余现金。

目标仓位增加、减少或归零，分别表达买入、卖出或清仓意图。执行器以次日开盘时的价格和账户计算订单，处理 T+1、整手、费用与成交限制。PPO 不直接输出股数，也没有独立的“不下单”动作。

| 设置 | 本次值 |
| --- | --- |
| 初始资金 | 每个 episode / 每段回测独立 1,000,000 |
| 佣金 | 成交金额 0.0003，单笔最低 5 |
| 卖出税费 | 0.0005，固定研究场景费率 |
| 单边滑点 | 0.001 |
| 买入单位 | 100 股；允许卖出零股 |
| 单票目标上限 | 5%，不因缩池调整 |
| 成交量预算 | 前一日成交股数的 1% |
| 时序 | t 日收盘决策，t+1 开盘尝试成交，t+1 收盘估值 |
| 价格口径 | `hfq_research`；未标准化但仍为后复权报价 |
| 奖励 | 本日净值 / 上日净值 - 1，费用不重复扣除 |

没有额外回撤惩罚、换手惩罚、在线奖励归一化或现金利息。手续费是模拟参数，不声称符合历史真实费率；当前没有权威停牌/ST/涨跌停和公司行为全量数据。

## 4. 训练过程与真实更新证据

运行环境为 Conda `Graduate`、Python 3.11、PyTorch 2.7.1 CPU、Stable-Baselines3 2.7.1、Gymnasium 1.2.3；单进程、单 PyTorch 线程。PPO 参数为 `n_steps=256`、`batch_size=64`、`n_epochs=10`、学习率 0.0003、gamma 0.99、GAE 0.95、clip 0.2、target KL 0.03、熵系数 0、价值系数 0.5、梯度范数上限 0.5。

| 检查项 | 512 步修正后检查 | 8,192 步正式轻量运行 |
| --- | ---: | ---: |
| 实际环境步数 | 512 | 8,192 |
| 实际优化器更新次数 | 69 | 1,178 |
| PPO 已进入的 epoch 数 | 18 | 298 |
| 发生变化的参数张量 | 17 / 17 | 17 / 17 |
| 参数变化整体 L2 范数 | 0.550839 | 1.863816 |
| 参数是否全部有限 | 是 | 是 |
| 保存加载后的确定性动作一致 | 是 | 是 |
| `learn()` 及其验证回调耗时 | 11.95 秒 | 54.11 秒 |

耗时不包含数据加载、初始模型保存和最后的完整基线比较，且受当时其他进程影响，不是硬件性能基准。epoch 数不是优化器步数；KL 提前停止部分 epoch，所以正式运行并非固定 32 × 10 × 4 次优化器更新。

正式运行保存 32 条更新诊断，概况如下：

| 指标 | 首条 | 最后一条 | 全程范围 |
| --- | ---: | ---: | --- |
| Value loss | 0.000875 | 0.000197 | 0.000052 至 0.001431 |
| 近似 KL | 0.009900 | 0.015910 | 0.009900 至 0.048101 |
| 裁剪样本比例 | 0.1363 | 0.1570 | 0.1328 至 0.3165 |
| Explained variance | 0.1236 | -0.1156 | -0.3803 至 0.7945 |

关键损失与参数保持有限，但价值解释度波动明显，最后仍为负，不能宣称已经收敛。近似 KL 有时超过目标值并不等于硬约束失效：该参数用于更新过程的提前停止，而非保证记录的所有 KL 都不超过目标。

训练日志中的 episode reward 是单步奖励之和，不是复利累计收益；本报告不将它作为投资收益率。训练行为带随机探索，回测采用确定性动作，二者也不能直接作绩效比较。

两次冒烟最终模型的参数指纹完全一致，说明修正只影响诊断，不改变成交、奖励或训练结果。两次冒烟均未参与正式选模，没有将技术问题隐藏为一次成功运行。正式运行日志所有已记录数值均有限；CSV 空白为该行未记录对应指标，不代表数值溢出。

2. 股票池：固定后见名单和代码等间隔取样不保证行业、市值或流动性代表性；不是未见股票泛化实验。
3. 执行：缺失历史 ST/停牌/涨跌停等状态，统一 100 股整手、固定费率、前日成交量预算均为简化假设。
4. 统计：单种子、小股票池、约 6.31 个训练 episode 长度、四次验证选模；未证明收敛、显著超额或跨市场稳定性。
5. 比较：PPO 与等权高度相关，风险、现金、费用不同；未做风险匹配或因子归因，无外部指数、容量压力或无成本反事实实验。
6. 测试使用：该日期区间现已被查看，不应继续当作 untouched test 调参。后续需预先定义新的时间留出或滚动协议。
7. 工程：没有精确续训 CLI、动态股票池训练、自动实盘风控或券商下单；Graduate 中原有 SHAP/slicer 依赖冲突仍未调整。

建议先分析目标仓位与实际成交的偏离及最低佣金影响，再补数据并做多种子、滚动窗口和费用压力实验。当前结果不足以支持进入实盘，也不足以仅凭测试收益略高就替换低成本等权基线。
