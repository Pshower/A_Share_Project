# 规则锚定调仓控制器研究摘要

日期：2026-10-14。正式研究执行与独立审计封存完成，**没有超过强基线，不部署、不改默认模型**。最终 `qualified=false`、候选为空、`actionable=false`；证据审计通过不等于经济胜出。

## 做了什么

复用新浪300只股票、20项训练期标准化特征和既有HFQ研究数据，不新增下载，不评价2026-07-01以后保护期。RL只学习两个动作：HOLD和调用未修改M20规则调仓；股票排名、数量、冻结、整手、费用及Broker完全保留。它不是新的神经选股模型。

模型为129维因果状态、线性categorical Actor和64/64 Critic，共12,805参数。日历margin2仅一次初始化，全部权重可训练；确定性初策略精确复现20日基线，不将规则收益算作RL增量。两独立账户分别真实执行并扣费，筛选只比较log_net与relative_log奖励。

## 实际结果

2023/2024的四个8K筛选trial均无学习增量，两种奖励所有排序指标打平，按登记的字典序固定选择log_net，不是收益胜出。随后在2025/2026各以三seed从头训练16K，只有最终checkpoint参与确认。

先在每seed内平均两fold的基线差，再对三个seed汇总：**-0.942373pp，样本SD1.632237pp**，低于要求的+0.5pp。三seed是描述性配对结果，不声称统计显著；自身初始化等于基线，因此初始化增量与基线差是同一数字。

2025全部seed及2026的seed123/2026仍复现基线。2026/42每账户少调仓一次，平均净ROI15.219062%，落后基线5.654236pp。成本下降没有抵消收益损失。最坏确认账户回撤2025为5.922599%、2026为3.262570%，风险门槛通过，但收益、初始化增量和种子胜出门槛均失败。

## 为什么没有晋升

参数更新并不等于有益交易改变。筛选Actor权重确实变化、随机采样有16.53%至19.75%的调仓，但944个训练后评价决策的greedy日历翻转为0。全量诊断已完成：确认训练观察有523次greedy偏离，1,440个确认评价决策仅2026/42的四账户各跳过1次日历调仓。每账户少12个实际成交股票日、省手续费187.64元、滑点348元，却损失净ROI5.654236pp。因此不能将失败全部归因于动作锁死，也不能将正绝对收益或训练损失下降冒充学习成功。

cash路径的唯一分支发生在6月1日收盘至6月2日执行：HOLD当日净收益1.839115%，基线调仓1.094165%，即时领先0.744951pp，但期末仍落后5.654236pp。后续宏动作均HOLD，不同持仓继续影响收益；这说明单日节费不能代替长周期评价，不是HOLD在所有状态下的因果结论。

该结论由只冷读封口账本的[单分支sidecar](../../reports/runs/ppo_timing_20261014/diagnostics/timing_all/single_branch_sidecar.json)核对此前Portfolio一致和唯一宏动作差异，没有新增金融步；SHA256为 `80ebca120f3be7b01298c47d061184a656209f4a286054a67572c9afddbdd848`。

本批实际10trial、10最终checkpoint、131,072 Agent RL日步、131,072平行训练基线日步、5,120次Adam；554个开始片段、544个完整片段及512步尾段。评价/身份控制共208条账本路径、12,392真实日步，另外计量，不冒充RL。纯CPU单线程；10trial训练/保存/诊断累计8,163.46秒，不是并行墙钟或包含后续评价的总时间。
