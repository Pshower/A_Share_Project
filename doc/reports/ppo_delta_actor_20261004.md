## Actor、状态与成交

### 股票增量与现金残余

`action_mode=stock_delta`，映射版本为 `stock_delta_frozen_residual_cash_topn_v3`。Actor 只有 300 个股票 latent 坐标，没有第 301 个现金动作；现金比例及应收比例仍是 Actor 与 Critic 的状态输入。

原始股票样本为 `a_i`，申请的市值比例增量为 `delta_i = 0.05 * tanh(a_i)`。这不是“把仓位设为 delta_i”，也不是“每次必须改变 5%”。正、负、零分别申请增仓、减仓及保持；实际股数仍受价格、整数/整手、资金含费用、可买可卖、成交量与数量预算约束。

**人为零增量保持原股数，而不是保持原权重。** 价格变化会自然改变市值权重和净值；执行已知事件仍须正常记账。不能把零增量转换成昨日目标权重后再次重平衡，否则次日价格漂移会引发主动交易。

剩余现金来自股票实际买卖、费用、应收结算和自然事件。高现金可能意味着主动未买入、卖出回款、冻结或不可成交，不能直接解释成学会择时，也不表示策略被强制满仓。当前没有独立的全局现金预算动作。

### 观察与网络

基础观察保留原技术特征、持仓/现金比例、应收比例和有效/买卖掩码。新增逐股票执行特征形状为 `[300,3]`：`lot_value_ratio`、`sellable_weight`、`freeze_flag`。全局 `allocation_context` 为 6 个字段：

| 顺序 | 字段 | 含义 |
| --- | --- | --- |
| 1 | `top_n_per_pool` | K / 300 |
| 2 | `max_weight` | 单股新增/加仓上限 |
| 3 | `minimum_fee_ratio` | 最低佣金 / 当前净值 |
| 4 | `held_count_per_pool` | 实际持仓数 H / 300 |
| 5 | `locked_count_per_pool` | 冻结或部分锁定的持仓数 F / 300 |
| 6 | `new_slot_slack_per_pool` | max(0,K-H) / 300 |

状态仅使用决策时可知信息。模拟账本依据已知锁定到期/T+1规则判断下一执行日可卖股数，不读取未来行情；执行层在次日真实开盘仍重新检查约束。

共享股票编码器宽度 256/128，当前每股输入为 20 个特征加 7 个持仓/掩码/执行字段。市场与持仓摘要各 128 维，现金、应收及 6 维数量上下文组成全局 264 维上下文。每股 Actor 头与价值头共享相应编码；Actor 末层正交小 gain `0.01`、零 bias，Critic 保持自身初始化。没有显式动量先验，但原动量特征仍在输入中。

实际参数数为 **124,547**，不能沿用旧小网络的 155,525。P4 审计记录 13 个参数张量变化、参数有限及保存加载检查通过。小 gain 只保证网络均值接近零，未训练均值动作不自动等于人为全零动作。

### topN 与 grandfather 例外

训练每个 episode 从 K=10/20/40 中均匀采样，episode 内固定；条件 RNG 与历史起点、初始账户 RNG 分离并记录。主开发回测固定 K=20，K=10/40 只作全部公开的辅助敏感性，不参与选择。

本轮 K 的语义是新增持仓受到的**总持仓数预算目标**，而不是额外再买 K 只股票。已有持仓、完全冻结和部分锁定股票均占用名额；只有实际股数已清零才释放名额，计划清仓或未完全成交不释放名额。

`grandfather_existing_actual_exit_releases_slot` 保留原有超预算持仓。例如已有 25 只、K=20 时，全零动作仍保留 25 只；不为满足 K 偷偷清仓，超额期间阻止新增股票，允许合法减仓。因价格漂移、事件或冻结产生的既有超权重也不通过零动作强制归位。因此不能声称所有时点实际持仓数必定不超过 K，或实际仓位权重永远不超过目标上限。

### 概率、KL 与时间线

状态支持集上的股票坐标使用 Gaussian；固定状态下完全不可行动坐标置零并从 log-probability、熵和联合 KL 中省略，部分可交易坐标继续保留。动作相关 topN 筛选后的未入选坐标不能再从旧概率比中删除。记录的 KL 是 latent 条件分布变化，**不是仓位变化比例**；整手和数量约束使 latent、申请增量、请求股数及真实成交分别不同。

t 日收盘观察决定动作，t+1 日开盘成交，奖励为前一收盘至下一收盘的净值收益，包含费用、原持仓隔夜变动及新持仓日内变化。训练与回测使用统一执行/记账框架。单步收益或价值拟合指标不能单独证明 Actor 的因果贡献。

## 训练期 pilot 已完成

四个配置均为 seed42，从头初始化，仅使用训练期 2,048 步。每个配置 4 个 512 步 rollout，batch128、epochs5，计划最多 80 次 Adam 更新；总 pilot 实际训练量 8,192 步，没有开发或保留期收益筛选。

合格条件是参数/诊断有限、保存加载及工程检查通过、实际优化器步数大于零、真实成交总额大于零、最后四分之一 rollout 记录的平均联合 KL 不超过 0.045。此处“最后四分之一”就是第 4 个 rollout 的已登记平均诊断，不另挑较小 minibatch。真实成交额只求和非零 `filled_shares`，不能将未成交缺价项的 `0*NaN` 当作成交或数值污染。

| Pilot | 学习率 | 初始 log_std | 实际环境步 | 实际 Adam | 尾段平均联合 KL | 真实成交总额（元） | 合格 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| P1 | 1e-5 | -3 | 2,048 | 80 | 9.655149654e-3 | 71,585,287.01 | 是 |
| P2 | 1e-5 | -1.5 | 2,048 | 80 | 3.398385597e-4 | 326,250,940.36 | 是 |
| P3 | 1e-6 | -3 | 2,048 | 80 | 8.078943938e-5 | 71,819,532.98 | 是 |
| P4 | 1e-6 | -1.5 | 2,048 | 80 | 4.777801223e-6 | 323,362,567.47 | 是 |

四配置均达到计划 80 次更新；因此第一排序项并列，第二项最低尾段 KL 选择 **P4**。较低初始 sigma、较高学习率是后续平局规则，本次未决定胜者。此选择不依据训练奖励、value_loss、开发 ROI 或未来收益，也不证明 P4 的收益最优。

P4 初始 sigma 为 `exp(-1.5)=0.223130160`，pilot 结束直接读取可学习参数所得 sigma 为 **0.223126799**。sigma 是 latent 股票噪声尺度，不能把掩码熵除以 300 后反推出它，也不能将其当作真实仓位变化标准差。`target_kl=0.03` 保留，SB3 实际提前停止检查阈值为 `1.5*target_kl=0.045`。

P4 的 8 个非零步 episode 中，K=10 为 5 段/1,280 步、K=40 为 3 段/768 步；K=20 在该短 pilot 中未采样。均匀抽样不保证八段样本均衡；pilot 通过不等于所有 K 已充分检验，正式课程覆盖须按实际 episode/步数补报。

## 指标、候选门槛与审计限制

| 指标 | 本报告使用的定义 |
| --- | --- |
| 净 ROI | 期末净值 / 初始净值 - 1；费用与滑点已计入，不重复扣减 |
| 样本标准差 | 每 seed 四账户平均后的三个值的样本 SD；四账户不是四个独立训练种子 |
| 初始化学习增量 | 同 seed、同预算、同账户的训练后净 ROI 减该 seed 未训练初始化 ROI，再跨账户/种子汇总 |
| 旧策略配对差 | 同 seed、同预算、同账户匹配旧 small prior/random；披露动作/状态/优化设置差异 |
| 长减短 | 同 seed 长快照减短快照，描述继续训练变化，不当作独立训练重复 |
| 最坏回撤 | 取全部三个 seed、四账户的最大绝对回撤；不以平均回撤替代风控门槛 |
| 成本 | 分别披露费用和滑点，以及二者之和占初始资金比例；净 ROI 已含成本 |
| 总换手/成交额 | 仅依据真实 `filled_shares`；未成交请求不算真实成交 |
| 实际现金 | 账户现金 / 当前净值；与意图中的残余现金及应收资产区分 |
| 实际持仓变化 | `positions.parquet` 中股数变化；与权重因价格变化而漂移分开 |
| 实际 Adam | optimizer state 的实际更新计数，与短/长计划上限320/2,560比较 |
| KL 与 clip | 状态支持集上的联合 latent 诊断及 PPO ratio 裁剪比例，不是实仓变化百分比 |
| sigma | 直接读取 `exp(network.log_std)`；掩码熵/每维熵只是辅助指标 |
| 课程覆盖 | K10/K20/K40实际episode与步数、账户/日期及条件状态哈希；重复历史不等于新增独立信息 |

## 解释边界与下一轮假说

HFQ研究价、100股整手及缺失的未复权成交/公司行为账本，可能改变购买力、可达仓位和成本；固定2026名单存在选择/幸存者偏差。本地日期并集不是独立交易所日历，缺行情不能直接认定停牌，历史 ST、涨跌停和退市状态不完整。

实际行情文件没有权威公司行为、停牌及涨跌停记录。本轮冻结/部分锁定的工程能力由合成案例与模拟结算账本证明，不能写成已验证真实历史停牌、公司行为或锁定数据的有效性；实际可知掩码与数据缺失状态也须区分。

本轮同时改变动作、状态、初始化、条件与优化尺度。即使正式更新稳定或收益改善，也只形成同数据开发观察，不能因果归于现金头移除、冻结处理、topN或 Critic 单一因素。未见评估与真实成交适配尚未建立，不发布为实盘默认；`actionable=false`、`global_optimality_claim=false`，本轮保留期绩效评估关闭。

本轮结果是“优化工作量稳定，但均值动作与成交粒度/成本不匹配”，不是有效交易策略已找到。下一轮合理但尚未实现的独立假说：以整手/最低经济成交额表达可执行动作；在固定价格与费用口径下比较最小增减仓和成本门控；把更新稳定与有意义的均值动作并列验收，预登记健康KL范围或停滞下界而非只追求最低KL；分别记录Actor、Critic和共享编码器梯度，检验是否需要分离优化尺度。它们不能倒改本轮P4规则，也不是已证明的收益修复方案。
