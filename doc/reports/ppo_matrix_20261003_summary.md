# PPO 二乘二矩阵摘要

2026-10-03，已完成。沿用已下载新浪沪深300数据，没有重新下载；GPU真实训练6次，保存12个固定快照，正式采样393,216步。三个训练种子各在四种初始账户下回测，2026年7月后的保留期未评估。

## 主要结果

训练预算扩大8倍，参数约扩大61倍。表为2026年4至6月开发窗口的四账户均值，再计算三种子的平均净收益及样本标准差。

| 训练预算 | 小模型：155,525参数 | 大模型：9,501,701参数 |
| --- | ---: | ---: |
| 短：8,192步 | 17.4305% +/- 0.0011 | 17.4040% +/- 0.0301 |
| 长：65,536步 | 17.4238% +/- 0.0090 | 17.4072% +/- 0.0663 |

初始化先验为17.4314%，每日动量17.5852%，20日调仓动量25.1558%。四格平均均未超过这些对照，扩大容量或继续训练没有稳定的收益增量。小模型短预算均值最高，但差距很小，不宣称统计显著或普遍最佳。

## 经历确实增加

每个种子的256步训练段从32段增加到256段，优化器从320次增加到2,560次。独特初始账户从23至25个增加到174至179个；不同历史日期仅增加15至136个。更多账户/动作轨迹不等于更多独立市场信息。

大模型为2048/1024，已按显存余量选择最大可用候选。4096/2048虽完成试跑，但reserved达4.891GiB且明显减速，不适合本轮4GiB GPU预算。六次正式训练累计约2小时21分钟，准备阶段另有4,096步，不混入矩阵成绩。

## 边界与处置

有效Critic训练指标总体改善，但配置收益未改善。冻结v1额外`critic/*`存在重置buffer采集缺陷：无效短快照与末段平均值已从派生汇总剔除，原模型、回测和审计保留不动。后续代码已缓存rollout修复并通过三项回归；没有用无效诊断支撑结论。

最终239项离线回归通过、13项联网测试排除，624个原始登记文件SHA核验一致。修复提交为`b484a4a`，正式训练来源为`ce2db04`。

实际平均现金约57%，费用加滑点约1.34万元/100万元账户。这仍是HFQ整手研究执行，不是现实成交模型。验证期已暴露、仅60步、仅三个训练种子，并有固定股票名单偏差；本轮不晋升实盘默认，也不重跑保留期选模。

下一轮优先研究真实成交口径、调仓门控/成本与先验残差的学习空间，然后独立测试更长lookback或时间/股票交互编码，不再只增加相同MLP和训练步数。
