# 新 Agent 研究摘要

找到符合本轮开发门槛的 **R1 动量先验稀疏配置 Agent**：

| 窗口 | R1平均收益 | 旧/匹配PPO | R1最坏回撤 |
| --- | ---: | ---: | ---: |
| 2026年4—6月 | +17.43% | -1.99% | 4.67% |
| 2025年7—12月 | +16.62% | +2.59% | 9.37% |

- 共11次训练、73,728步、2,518次参数更新，所有组保存加载与审计通过。保持新浪来源、300股和四种初始账户。
- **收益改善主要来自动量先验和稀疏配置，不是已证实的PPO学习增益。** 相对未训练先验，两个窗口的平均学习增量都略为负。
- 回撤和成本比旧PPO高，2025年Sharpe也略低；20日动量规则在两段窗口仍然更强。不能称为全面最优。
- 候选可加载并生成最多20股的研究目标权重，但仍是HFQ执行模拟，未发布实盘模型，也未评估2026年7月后的保留期绩效。
