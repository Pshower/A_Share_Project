# 数据与 PPO 改进及多种子验证报告

日期：2026-09-26。训练代码提交：`492f305`。本报告描述工程交付和开发验证，不是最终样本外或实盘验收。协议在正式训练前登记于 [多种子协议](../ppo_multiseed_protocol_20260926.md)。

## 1. 结论

工程链路已完成核心闭环：固定实验配置 -> 来源预检 / 数据准备 -> 每种子配置检查 -> 显式批准训练 -> 验证选模与基线比较。高级参数、学习率日程、风险选模门槛、真实优化器与组合诊断均已接入。

正式运行全部完成：19 股、3 个配置、每配置 3 个种子，每次 8,192 步，共 73,728 步。没有正式任务失败，没有下载新行情，也没有运行最终测试集。

研究结论并非“已经战胜等权”：三组平均收益都低于 20 日等权，但平均 Sharpe 较高、回撤较小、成本显著更高。低学习率 H1 是可继续验证的候选，不据此修改项目默认参数或自动选择部署模型。

## 2. 实验边界

- 新版本：`research_multiseed_20260926`，数据 ID `e5bffb69ce84e5c038ea`；19 股、1,943 个日期、20 列基础特征。
- 股票仅按训练期连续有效覆盖不少于 756 条的预定规则筛选，完整名单见协议；没有按未来收益挑选。
- 实际共同训练区间：2018-10-18 至 2022-08-05，925 条记录，每个完整训练 episode 对应 924 个转移。
- 验证：2022-08-05 收盘初始化，成交期 2022-08-08 至 2023-10-20，291 个转移，各策略独立以 100 万研究资金初始化。
- scaler 使用这 19 股在配置训练截止前的 24,099 个完整股票 / 日期行拟合，包含早于共同连续训练起始的历史，不包含验证日期。不构成未见股票实验。
- 原 2023-10-23 至 2024-12-31 测试区间已暴露，本轮未重跑；它在数据版本中存在不等于本轮用它选模。
- 设备统一 CPU，仍使用 AShareGPU 环境。短预算设备检查显示 CPU 更适合当前小型共享 MLP，具体数字见协议；不宣称一般情况下 CPU 比 GPU 快。
- 每股 5% 上限、19 股意味着股票理论总敞口至多约 95%；研究成交价格仍为 HFQ，不能等同于现实报价和股数。

## 4. 同条件基线

已核对九次运行的基线指标完全一致，股票池、日期、初始资金、费用、仓位上限与执行假设相同。

| 策略 | 收益 | Sharpe | 最大回撤幅度 | 成本 | 平均现金 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 现金 | 0.00% | 不可计算 | 0.00% | 0.00 | 100.00% |
| 买入持有 | 15.92% | 0.837 | 13.49% | 845.80 | 32.20% |
| 20 日等权 | 15.87% | 1.024 | 9.26% | 1,999.26 | 28.18% |
| 每日等权 | 15.82% | 1.058 | 9.40% | 6,707.86 | 24.66% |

本轮动量基线的 top_k 沿用模板值 20，但股票池只有 19 股，因此动量选择覆盖所有有效股票，结果与对应频率的等权完全相同。它不是一个额外独立的选股对照；本轮没有在看到结果后修改该参数。

九个 PPO 中，3 个收益超过 20 日等权，8 个 Sharpe 更高，8 个回撤幅度更小，但全部成本更高。与每日等权相比，三组平均收益也较低，而平均 Sharpe 较高；这属于风险 / 收益 / 成本取舍，不是全面占优。

PPO 与 20 日等权的日收益相关约 0.955–0.988，整体路径仍高度接近。风险改善可能与现金和敞口行为有关，不能直接认定为独立选股能力。信息比率基于逐日算术主动收益，和累计净值差不是同一个量，二者的符号也不必相同。

## 5. 行为与数值审计

- 所有正式模型均记录代码提交 `492f30574b60db78175c972c9cf425259f94884b`，dirty=false；运行中未修改参数或源码。
- 每次实际完成 8,192 步，17/17 个参数张量变化，全部参数有限，保存加载的确定性动作一致，`test_evaluated=false`。
- 实际优化器 step 总计 9,225；这不是 SB3 的 Epoch 计数，也不是训练交互步数。

| 组别 | seed 42 的优化器步数 | seed 123 | seed 2026 | 训练段合计秒 |

| B0 | 1200 | 1096 | 1223 | 351.07 |

训练段合计约 568.64 秒，包含阶段内验证，不包括所有启动、排队及最终对照收尾。B0 前两次耗时明显较长，受到共享机器负载、缓存等影响；不能把墙钟差异全部归因于学习率。H2 的优化器更新数较少是可直接确认的计算量差异。

模拟订单记录拒绝比例为 69.21%–81.17%，记录的限制原因集中于 `buy_lot`。原因可能出现在部分成交等记录中，原因计数不等同于拒绝记录数。这也不是真实交易所拒单率。

例如 B0 / seed 42 的首日 000001 目标权重约 5%，但在 HFQ 研究价格和 100 股整手规则下请求约 29 股，未达到一手而被拒绝。它暴露了当前研究报价与整手约束的结构性影响，不能把这个现象当作现实股票价格下必然存在的交易困难。

部分种子最终选中 2560 步，而不是 8192 步，说明增加训练步数并不保证验证效果持续提高。本轮按预定预算完成全部更新，没有事后提前停止或更换 seed。

## 6. 工程异常与处理

最终工程回归为 129 项离线 Python 测试、24 项全量浏览器测试通过，13 项外部联网测试被排除。浏览器的短训练和停止测试不计入本报告九次正式运行。

首次正式监控进程在轮询本地 HTTP 时遇到一次保活连接断开。工作台中的九个任务已经持久化，训练继续运行；恢复过程只做 GET 监控，没有重发训练请求或重复参数更新。

全部正式任务结束后，修复了监控客户端：使用短连接，对幂等 GET 的连接错误 / 超时做有限重试，POST 不自动重发，并增加测试。模型仍归属于训练时的 `492f305`，未重写模型元数据。

## 7. 后续判断

1. H1 可作为下一轮开发候选，但不替换默认参数、不挑一个幸运 seed 自动部署。H2 降低计算量和平均成本，也值得保留对照。
2. 优先处理执行口径：补齐不复权历史与可靠公司行动后再验证现实整手 / 费用表现。当前 HFQ 研究收益不能作为实盘依据。
3. 可研究已知价格下的整手成本 / 净值比例等执行状态，以及一致的最小调仓规则。它们应进入新的环境 / 模型契约，不能使用下一开盘价作为当前决策特征。
4. 增加风险预算匹配的等权 / 现金对照，以区分降低敞口和真正的择时价值；需要重新模拟费用和整手，不直接缩放已画出的净值曲线冒充可执行对照。
5. 下一轮做预登记滚动窗口或新的保留区间，再评估时间窗口 / 特征消融。当前同一验证区间已经用于挑 checkpoint 和比较配置，不能称为独立样本外胜出。
6. 没有证据支持立即换成 LSTM / Transformer。多环境、时序网络、分钟 / 财务入模仍未实施，不把本轮工程闭环当作这些研究项已经完成。

本轮与原 32 股轻量实验的股票池、共同区间及 scaler 不同，不能用本报告收益和旧报告数字直接做“升级前后提升”比较。
