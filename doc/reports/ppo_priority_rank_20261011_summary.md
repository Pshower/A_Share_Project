# 排序动作与辅助训练研究摘要

日期：2026-10-11。**当前为工程准入阶段，正式金融训练尚未执行；没有本轮收益结论或候选模型。** 用户选择每 trial 最长16,384步，本轮不追加32K。

## 本轮做什么

固定纯行情均值摘要、共享 Critic 和每日扣成本收益，做动作与方法的二乘二对照：

| | 普通 PPO | PPO + 五日 rank 辅助任务 |
| --- | --- | --- |
| quantity/priority 耦合 | coupled_ppo | coupled_rank |
| quantity/priority 解耦 | decoupled_ppo | decoupled_rank |

统一3N动作：方向、quantity、BUY priority。quantity决定整手数量，priority参与资金/名额排序；HOLD/REDUCE/EXIT以及冻结、T+1和剩余现金不改。coupled的BUY priority是quantity拷贝原子，decoupled增加独立Normal；联合概率精确计入实际采样坐标，不拿裁剪或成交结果代替动作。

所有cell总参数 **125,322**，同seed初始张量一致。同Actor内两方法初始随机策略一致，跨Actor确定性初始排序/成交一致；**跨Actor随机执行函数不同**，必须保留各自初始化控制。

辅助任务只用market encoder和零初始化signal head预测训练期五日gross收益的截面rank；系数0.05、Huber delta0.1，每次接受的PPO Adam更新抽1,024个stock-date样本。同次Adam合并，不追加optimizer，KL拒绝前不抽标签，未来标签不进入观察。构造前物理截断到train_end，最后五个决策日purge。

这轮不是完整稀疏selector，仍保留mapper的topN/现金过滤；没有新风险奖励、BC、GRU、动量先验或新下载数据。

## 固定预算与验收

复用新浪300股、20特征、2023/2024训练折及Q2验证窗口，三seed42/123/2026。**24 trial、8,192/16,384共享前缀、48快照、393,216新增RL步**是预注册预算，尚非完成量；快照步数和589,824含196,608共享前缀，不能重复计为训练。

针对性合成验收已实际 **154 passed（动作/模型/加载100 + 辅助54），25.85秒，exit0**；root集成验收实际 **4 passed，27.98秒**。最终全仓离线验收实际 **1,293 passed、13 deselected、11 warnings，442.59秒**，13项联网测试未执行。针对性/集成数已包含于全仓覆盖，不重复相加。

工程验收不计入金融预算，也不证明收益改善。prepare、24次正式训练及独立研究审计仍待执行；用户确认每trial长预算16,384步，总393,216步。

合成batch128更新benchmark：CPU4线程371.83ms，CUDA20.309ms，GPU内核约快18.3倍；非金融训练，也不保证整体墙钟同幅加速。本轮使用CUDA，真实耗时另记。

正式评估同时比较扣成本收益、最坏回撤、初始化增量及种子稳定性。每配置在两个fold都须通过DD≤10%、均值初始化增量>0、≥2/3 seed正、超过同机制20日动量，才可成为历史研究候选。不因中途收益扩预算或挑种子，不发布默认模型/真实订单。
