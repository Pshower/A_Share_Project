# 规则锚定调仓控制器研究协议

日期：2026-10-14。状态：训练前登记。正式运行前核实实现、数据与源码哈希；冻结后完成进度和结果另写报告，不回改本协议。

## 研究目标

在相同股票池、行情、费用和整手执行机制下，训练强化学习调仓控制器，使确认回测净收益超过原 20 日动量基线及自身未训练初始化，并满足风险和种子一致性要求。不能降低基线、改评价窗口后仍称同一确认、只挑获利 seed，或将规则选股本身的收益归因于 RL。

前轮原始 BUY 请求约 4.04% 成为成交，900 维请求的信用分配被资金与名额投影稀释。本轮先降低 RL 的动作维数，保留强基线的股票选择与真实模拟执行。它检验的是调仓时机的学习增量，不宣称已实现新的神经选股或完整无放回稀疏 selector。

## 策略与初始化

RL 动作为单个 `Discrete(2)`：

| 编码 | 动作 | 执行 |
| --- | --- | --- |
| 0 | HOLD | 原经济 HOLD 请求，不主动改变股数 |
| 1 | REBALANCE_M20 | 原 `EconomicRule(momentum_20, interval=1)` 生成股票整手请求 |

强基线始终是未修改的 `EconomicRule(momentum_20, interval=20)`，K20、原排序、rank-dependent 数量、冻结、T+1、整手、经济门槛、手续费及 Broker 完全一致。股票排序属于固定规则引擎；RL 只决定当天是否调用调仓。

Actor 为可训练线性 categorical 头，Critic 为 64/64 MLP，共12,805参数，每 trial 独立训练。前 20 个输入是已知调仓 phase 的 one-hot。一次性初始化为：phase0 的 REBALANCE logit=2，其他 phase 的 HOLD logit=2，其余 Actor 权重及 bias=0。确定性初策略应逐请求、逐股数、费用、现金与净值精确等于原 20 日基线。

这是可修改的参数初始化，不在 forward 中永久叠加日历先验，不限制残差幅度，不使用 BC。初始随机策略与确定性基线不同，采样约有非基线动作，必须披露探索与初始化控制。初始化收益不可算作 RL 学习增量。

只对 RL 实际采样的 macro token 保存 logP、value 和动作。派生的 2N 股票方向/数量及原生订单另存，不得把派生股票请求的概率冒充神经策略 likelihood。

## 输入与因果状态

固定 129 维 Box 观察：phase20、有效市场特征均值20、Agent持仓特征汇总20、独立基线持仓特征汇总20、当前动量 top20 候选特征均值20、两个账户各14维摘要、当前净值 log 比值1。

候选排序必须与原 EconomicRule 的有效性及代码 tie-break 一致；全部特征为当前收盘及以前的状态。基线账户在两奖励方法中都运行，因而观察空间与算力口径相同。不得输入未知次日价格、交易状态或未来累计回报；已知 T+1 到期可以参与原规则可卖量计算。

phase 由过去交易计数及 episode 初始 phase 得出。第一批不引入无法从单次快照恢复的峰值回撤或距上次调仓隐式记忆。真实收盘推理仍需要正确账户与日历锚点，不因研究 controller 输出就成为实盘订单。

## 两种训练奖励

两独立账户从相同实际股数、可卖/锁定信息、现金、应收和起点开始，之后分别真实执行自己的订单。基线不能随 Agent 动作复制持仓或重置，两账户都扣自身费用。

```text
log_net = log(NAV_agent[t+1] / NAV_agent[t])
relative_log = log_net - log(NAV_baseline[t+1] / NAV_baseline[t])
```

只比较这一奖励因素，不同时加入 BC、第三动作、资金模板、新排名、风险惩罚或动量先验残差。费用已经计入两净值，相减不是再次收取手续费。

共同 gamma=.995，因此奖励是折扣学习代理，不能声称折扣和严格等于最终净值之比。240 步训练 episode 沿用 Gym 时间截断和标准 PPO bootstrap，优势不跨 reset；评价只看独立原始净 ROI、回撤和成本，不只看相对 reward。

1. 工程准入：合成测试、calendar 初始化等价、双账户独立、原生账本、概率、保存加载、裁剪与冻结边界。合成 CPU/CUDA 微基准不算金融 RL。
2. 筛选：仅 2023/2024 Q2 已曝光开发折，两个奖励方法，各 seed42 从头训练 8,192 步，共 32,768 RL 步；只评价预算终点，不挑较早快照。
3. 固定选择：全部四个筛选 run 封存后，按最差折基线差、平均差、最坏回撤、成本、方法名依次排序，锁定一个方法与配置。初始化检查不等价则阻断，不参与排序。

本批总计 10 trial、131,072 RL 步。32K 筛选与 98K 确认分别计量，不重复叠加 checkpoint。每步推进一天，不将一次 20 天 macro 推进伪计为一个可与旧研究比较的日步。

2023/2024/2025 复用旧历史折；2026 使用原新浪版截至 2026-03-31 的训练 scaler 和 2026-06-30 的评价边界。provider 在训练/评价前物理裁剪，2026-07-01 以后不用于绩效或特征观察。2025/2026 也被旧研究使用过，只能称本轮选择未使用的时间确认，不能称从未曝光的盲测。

## 初始账户与训练覆盖

每 episode 240 步，固定 K20，cash/equal/concentrated/random 四模式，日期分 early/middle/latest 三层，初始 phase 分四个五日桶。48组合分块轮换：每个 phase 块随机覆盖四账户×三日期的12组合，避免短筛选全部集中于某个账户或时期。日期、phase 和实际持仓的随机流独立。

最新层采用可完整容纳240步的末端窗口；其他层从合法过去起点采样。基线复制的是生成后的实际 Portfolio，包括现金、股数、可卖、锁定与应收，Broker 和市场游标独立，不共享后续可变状态。

末端窗口可能在市场训练边界自然终止，其他窗口通常在240步时间上限截断；保留原 TradingEnv 的两种结束语义，不人为统一 bootstrap。两奖励方法使用相同结束排程。

8,192=34×240+32，16,384=68×240+64；必须记录完整 episode 和未完成尾段，不宣称旧研究的32/64完整片段或每模式精确相等。方法配对使用相同 seed、分层排程与初始状态；报告真实覆盖，而非把重复行情称为新数据。

## 胜出标准

时间确认每折先平均各 seed 四账户，再报告三 seed 均值与样本SD。至少同时满足：

- 每个确认折平均扣成本 ROI 超过未修改的20日动量。
- 每折至少2/3 seed 的四账户平均 ROI 超过基线。
- 两折平均优势至少0.5个百分点，排除微小数值胜出。
- 每折自身初始化增量平均为正；det初策略应与基线等价。
- 最坏账户回撤不超过10%，且不比基线最坏回撤恶化超过2个百分点。

不能凭开发筛选胜出或一个幸运 seed 宣布目标实现。未通过则保留失败研究结果，下一批重新登记，不将根据确认结果改过的配置继续称为同一确认。本轮不自动部署真实账户或改工作台默认模型。
