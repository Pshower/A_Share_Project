# 仓位控制分阶段规划（2026-11-05）

本文件是**执行前的规划与预登记**。阶段一的判据、阶段二的样本切分与采用条件在跑任何数字之前写定；阶段三、四的形式也已固定，只有阶段一的输出能决定"要不要走到下一阶段"，不能决定"改成什么形式"。

背景：20 只组合里 **84% 的收益方差来自市场因子**（个股口径 20.6%），而现有全部工作——20 个量价特征、单因子 IC、市值筛选、调仓日敏感性——只作用在剩下的 16%。仓位是唯一能触碰那 84% 的杠杆。

## 0. 目标与非目标

**目标**：给建议程序加一个显式的目标仓位 `e_t ∈ [0.2, 1.0]`，并验证这个仓位规则本身是否值得使用。

**非目标**：不改进选股；不做日内；不做行业或风格轮动；不预测指数点位。

## 1. 样本账本（唯一稀缺资源）

指数历史可回溯到 2005-04，但要按"用掉就不能再用"的方式分配：

| 代号 | 区间 | 用途 | 状态 |
| --- | --- | --- | --- |
| D | 2005-04 ~ 2018-12 | **设计与度量**：估计 σ*、确认机制存在 | 阶段一、二可看 |
| V | 2019-01 ~ 2024-12 | **一次性验证**：只准看一次，看完即封存 | 阶段二第一次也是唯一一次 |
| R | 2025-01 ~ 2026-06 | **保留**：仅当 V 段判定失败且确认是结构性问题时，允许一次修正后复测 | 未使用 |
| P | 2026-07 ~ 2026-09 | **未触碰**：最终合体测试 | 未使用 |

阶段一**只在 D 段描述**。理由：如果阶段一顺手看了 2019–2024，阶段二的"验证"就变成第二次观察同一批数据，那一次机会就作废了。多花 14 年样本换一个真正干净的验证段，值得。

## 3. 阶段 1：机制度量（只看 D 段，不设交易阈值）

三项度量，全部是描述性统计，输出分布不输出规则。**跑完按第 3.4 节的表决定登记哪一层，不临场改标准。**

### 3.1 已实现波动的可预测性

- 计算 `σ20_t`（20 日已实现波动，年化）。
- 输出：`σ20` 对 `σ20` 滞后 5/10/20/60 日的自相关系数；`σ20_{t+20} / σ20_t` 的分布（中位、10/90 分位）；`σ20` 的年度中位数序列。
- 要回答：**今天的波动能不能预测未来一个月的波动？** 如果自相关低，缩放就是在追噪声，规则会高频换手。

### 3.2 MA200 的历史分段

- 把指数按"收盘在 MA200 上方/下方"切成连续段，每段记录：起止、交易日数、段内收益、段内最大回撤。
- 输出：段表；"处于下方"与"处于上方"时未来 20/60 日收益的均值、标准差、样本数。
- 要回答：**下跌段有多长、MA200 是早退出还是晚退出、退错之后的反弹有多猛。**

### 3.3 假信号的机会成本

- 每次"由上方向下穿越 MA200"记一次出信号，统计其后 20/60 日指数收益。为正即踏空。
- 输出：信号次数、假信号占比、假信号的平均踏空幅度、累计踏空成本；与"避开的回撤"（每次有效信号后 20/60 日的跌幅）放在同一张表。
- 要回答：**这条规则用省下的回撤，够不够付踏空的账。**

### 3.4 预定的判定表

| 度量结果 | 结论 | 动作 |
| --- | --- | --- |
| `σ20` 的 20 日自相关 < 0.30 | 波动不可预测 | L1 出局，不登记 |
| 自相关 ≥ 0.50 且比值分布的中位在 [0.8, 1.25] | 波动可预测且稳定 | L1 具备登记资格 |
| 下方 vs 上方的 20 日收益差 < 0.5σ | 趋势无可分离结构 | L2 出局 |
| 收益差 ≥ 0.5σ 且在 D 段四个子区间符号一致 | 趋势有结构 | L2 具备登记资格 |
| 累计踏空成本 > 避开的回撤 | 趋势净负 | L2 降级，不作独立层 |
| 两者都具备资格 | — | **先登记 L1**，L2 相对 L1 检验 |
| 两者都不具备 | — | 停止本方向，回报"仓位规则在 D 段无证据" |

**"两者都具备"时先登记 L1 不是偏好，是依赖**：L2 的检验标准是"打败 L1"，没有冻结的 L1 就没有正确的对照。

## 4. 阶段 2：L1 波动率缩放（一次验证）

### 规则（冻结）

```
e_t = clip( min(1, σ* / σ20_t), 0.20, 1.0 )
σ*  = D 段（2005-04~2018-12）年化已实现波动的中位数
```

`σ*` 由"平均暴露≈1"定义，是定义性选择，不再调整。**唯一可变项是 0.20 的下限**，它在阶段一之后、看到验证结果之前固定。

### 对照

同平均暴露的恒定杠杆。若 `e` 在 V 段平均为 0.78，对照组为恒定 0.78 倍全池等权。**赢不了这一组，说明只是少买点，不是择时。**

### 判据（三条同时满足）

1. V 段 Calmar 高于同暴露对照；
2. V 段年化收益不低于对照 2 个百分点以上；
3. 换手成本已计入（单边 30bp + 卖出印花税 5bp，沿用 `configs/research.json` 的 broker 参数）。

### 失败处理

- 若 Calmar 未提高但回撤明显下降 → 记录为"风险工具，不是收益工具"，**不进入 L2**，先决定是否作为可选的风险档位保留。
- 若回撤也没下降 → L1 关闭，整个方向重新评估。

## 5. 阶段 3：L2 趋势（相对 L1 检验）

```
e_t ← e_t × (0.5 if 指数连续 20 个交易日收在 MA200 下方 else 1.0)
```

- 只允许**打折**，不允许加杠杆，因此 L2 的平均暴露必然低于 L1。
- 检验方式是"L1+L2 vs L1"，**不是 vs 满仓**，并额外报告同平均暴露对照，避免把"平均仓位更低"记成择时能力。
- 判据与阶段二相同三条。
- 失败即关闭，不改回看长度重试（回看长度在阶段一之后固定，不许搜索）。

## 6. 阶段 4：L3 宏观否决（只降不升）

```
e_t ← min(e_t, cap_t)
```

- `cap_t ∈ {0.3, 0.6, 1.0}`，由**一条**预登记的宏观条件决定，条件从阶段一的宏观段落表中挑，且必须在 D 段内确定。
- 设计上只能压低仓位，因此不可能成为收益来源；它的价值必须由**回撤下降**来支付。
- 判据：在 L2 基础上，最大回撤下降 ≥ 3 个百分点，且年化收益损失 ≤ 2 个百分点。两条同时满足才算通过。
- 已知风险：D 段（2005–2018）只包含约 4–5 次宏观制度切换，因此 L3 的结论**无论通过与否都不构成验证**，只能标为"观察"。

## 7. 阶段 5：集成（显式仓位 + 整手联动）

### 建议程序接口

```
--exposure {1.0|0.7|0.4|auto}    # auto 表示由冻结的规则给出
--capital  3000000
```

### 预算与整手

```
每只预算 = capital × e / n
```

被判为不可执行的名字（一手价 > 预算）**跳过并顺位补入下一名**，不保留 0 权重。这样"仓位"与"持几只"解耦：`e` 低时是少数高价股被跳过，而不是每只都买不到。

### 本金建议

按全池一手价分布（2026-10-30：中位 2,231 元，95 分位 17,910 元，99 分位 48,023 元）：

| 本金 | `e=1.0` 每只 | `e=0.4` 每只 | `e=0.2` 每只 |
| --- | ---: | ---: | ---: |
| 100 万 | 50,000 | 20,000 | 10,000 |
| 200 万 | 100,000 | 40,000 | 20,000 |
| **300 万** | 150,000 | 60,000 | 30,000 |

规则：`capital × e_min / n ≥ 被选中 20 只的一手价 95 分位`。注意被选中的名字不是随机样本（高动量常伴随高价），所以阈值要用**被选中集合**算，不是全池。当前建议按 300 万设计，`e` 可低到 0.2 仍能覆盖 95% 的选股。

## 8. 预先承诺

- 阶段一跑完只出分布与判定表结论，不产出任何交易规则。
- 每个阶段只改一层；上一层冻结后才动下一层。
- V 段只评一次。若 L1 在 V 段失败，允许用 R 段复测的唯一情形是：失败可归因于**结构性原因**（如波动机制在 2019 后消失），且该原因必须在 D 段内被独立观察到，而不是事后编故事。
- P 段（2026-07~09）在最终合体前不读取。
- 任何阶段的结论都必须同时报告"同平均暴露对照"，否则不成立。
