# ETF 拿不拿得到股息，以及 5.31% 应该改成多少

日期：2026-11-08
分支：`research/supply-pressure`
状态：**已实测**。工具 `tools/dividend_yield.py`，产物 `reports/runs/dividend_yield/`

起因：三 ETF 混合报的年化 +5.31% 是价格指数收益，被问到"真实 ETF 也会有指数股息么"。

---

## 1. 会拿到，机制是这样的

ETF 持有成分股，股票派现金时：

| 环节 | 结果 |
| --- | --- |
| 上市公司派现 | 现金进入**基金资产** |
| 基金层面税 | **公募基金**取得股息通常不缴企业所得税（与个人直接持股的差别化税率不同） |
| 分配方式 | **分红型**发给你；**累积型**留在净值里 |
| 两条路的共同点 | **都进了持有人的总回报** |

所以**用价格指数去衡量一个 ETF，会系统性低估它的收益，低估的幅度就是股息率。**

三条会削弱它的因素：

| 因素 | 量级 |
| --- | --- |
| 管理费 + 托管费 | 宽基 ETF 约 **0.15%–0.5%/年** |
| 跟踪误差与现金拖累（留 1–2% 现金应付赎回） | 约 0.1–0.3%/年 |
| 分红型产品若把现金取走不再投入 | 取决于你 |

**我没有核实过基金层面的税收优惠条文**——这一条是从"基金净值已经反映分红"这一事实推的，
不是查证来的。真正的净值数据才能确认。

## 2. 实测股息率（按市值分档）

用 `stock_history_dividend_detail` 取每只股票的派息与除权日，
**除以当日的未复权收盘价**（复权价会把历史股息相对缩小，越往前错得越多），按中位流通市值加权：

| 档位 | 只数 | 派息事件 | 2019-2024 平均股息率 |
| --- | ---: | ---: | ---: |
| **前 300**（大盘） | 300 | 1,792 | **2.58%** |
| **301–800**（中盘） | 500 | 2,675 | **1.83%** |
| **801–1500**（小盘） | 700 | 3,207 | **1.68%** |

逐年（大盘档）：2019 2.22% → 2020 2.40% → 2021 2.44% → 2022 **3.00%** → 2023 2.84% → 2024 2.58%。

**股息率随市值单调下降**：大票给得多，小票给得少。这正好削弱了"微盘超额"的优势。

## 3. 所以正确的数字是多少

三 ETF 权重 50/30/20，对应大盘/中盘/小盘股息：

```
0.5 × 2.58% + 0.3 × 1.83% + 0.2 × 1.68% = 2.18%
```

| 口径 | 年化 |
| --- | ---: |
| 价格收益（之前报的） | +5.31% |
| **加股息** | **+7.49%** |
| 减 ETF 费率（按 0.2–0.5%） | **约 +7.0% ~ +7.3%** |

**之前那个 5.31% 低报了约 2.2 个百分点。**

## 4. 与国证A指的缺口也变小了

| | 价格 | 加股息（估） | 全收益 |
| --- | ---: | ---: | ---: |
| 三 ETF 混合 | +5.31% | +2.18% | **+7.49%** |
| 国证A指 | +8.01% | 约 +1.7% | **约 +9.7%** |
| **缺口** | **−2.70pp** | — | **约 −2.2pp** |

缺口从 2.7pp 收窄到约 2.2pp——**因为全市场指数里小票占比更高、股息更低**。
**它变小了，但没有消失。**

## 5. 不能主张的

1. **这不是官方全收益指数。** 我用自己按市值取的前 300/500/700 只做代理，
   不是中证 300 的真实成分。中证全收益指数代码（`H00300` 等）在东方财富接口返回空，**试过，不通**。
2. **股息率的算法是"每次派息 / 除权日股价"再按年汇总**，没有做再投资的时间加权。
   对每年派一次的公司足够准，对年内多次派息的有小误差。
3. **没有建模 ETF 的实际跟踪误差与折溢价**，用的是费率区间。
4. **2019-2024 的股息率**不能外推到更早年份——A 股分红率这几年在系统性提高。
