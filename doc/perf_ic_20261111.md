# 信息源第 7 条：业绩报表 —— 覆盖 99%，效应为零

日期：2026-11-11
状态：**未通过**，而且是最干净的一种不通过：覆盖率几乎满分，效应量近乎零。
工具 `tools/perf_ic.py`；产物 `data/online/yjbb/`、`reports/runs/perf_ic/`

## 1. 先说 PIT：这才是这条源原本被判"不可用"的原因

[信息源清单](information_sources_20261108.md) 把业绩报表标为 **PIT 质量差**，判断是"若用报告期而非公告日，就是读未来"。
这次实测确认了：

- `stock_yjbb_em` **确实有** `最新公告日期` 字段，但它**不是首次公告日**。
- 以 **2024Q1** 为例：5,889 行里 **5,440 行的"最新公告日期"落在 2025 年 4 月**——
  那是后来覆盖这一行的定期报告日期。2024 年 4 月公告的只有 73 行（1.2%）。
- 如果直接用它当可得日，信号会被推迟**整整一年**，测的就不是同一件事了。

**所以改用法定披露截止日当锚**：年报与一季报 **4/30**、半年报 **8/31**、三季报 **10/31**。
报告不可能晚于截止日公布，所以以截止日为可得日**永远不可能前视**；
代价是把早披露的公司当成最后一天披露，是保守的一侧。

## 2. 事前定下的两件事

- **用哪个量**：`净利润-同比增长`。已经是比率、已经带符号，留给事后选择的编码空间最小。
- **方向**：**正**——业绩加速的公司会继续漂移（PEAD）。

## 3. 结果

| 项 | 值 |
| --- | ---: |
| 报告期 | 28 个季度（2018Q1 ~ 2024Q4） |
| 记录 | 213,869 行 |
| **池内覆盖** | **98.6%** |
| 期数 | 72 |
| **平均 IC** | **+0.0041** |
| **t（Newey-West）** | **+0.24** |
| 正号期占比 | 54.2% |

判据 \|IC\| ≥ 0.031 且 \|t\| ≥ 2.5：**IC 只有门槛的 13%，t 0.24——连方向都谈不上。**

## 4. 怎么读这个结果

- **这不是"PIT 没解决所以测不出来"。** PIT 解决了（用截止日锚），覆盖率 98.6%，样本 72 期，
  统计量依然接近零。**净利润同比增速在 20 日尺度上不预测截面收益。**
- **不能用"如果用真实公告日会更好"来辩护。** 更好的时点最多让信号早几周，而效应量差了一个数量级；
  这不是时点问题，是没有效应。
- 与之前的候选放在一起，结论是一致的：**A 股 20 日尺度上能测到的东西，不在财务报表里。**
