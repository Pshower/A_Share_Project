# 信息源 1：限售解禁的秩 IC

日期：2026-11-08
状态：**过门槛，但只覆盖 5%。这是本次项目第一个过预设门槛的信号。**
工具 `tools/unlock_ic.py`；产物 `reports/runs/unlock_ic/`

---

## 1. 构造

| 项 | 取值 |
| --- | --- |
| 数据 | `akshare.stock_restricted_release_detail_em`，2019-2024 逐年缓存，**14,506 条解禁事件** |
| 因子 | **未来 20 个交易日内解禁的市值 / 解禁前流通市值**（原表已给该比例） |
| PIT | **干净**。解禁日由定价时的规则决定，公告在很早之前，不存在披露滞后 |
| 池 | 前 1,799 只（`feature_top1800`） |
| 判据 | 仓库自己的盈亏平衡 IC = **0.031**（20 日持有、8 年、组合层 t=2） |

方向事前就定了：解禁 = 卖出压力 → **负号**。

## 2. 结果

| 口径 | 期数 | 平均 IC | t | 负号期占比 | 覆盖率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全截面（无事件记 0） | 72 | **−0.0133** | −1.94 | 66.7% | **5.1%** |
| **条件化（只算有解禁的）** | 72 | **−0.0686** | **−5.26** | **77.8%** | 5.1% |

- **方向正确**：负号，77.8% 的期次为负。
- **条件化 IC −0.0686，是门槛 0.031 的两倍多**，t = **−5.26**。
- **但覆盖率只有 5.1%**：任一决策日，1,800 只里只有约 90 只落在 20 日解禁窗口内。

## 3. 这意味着什么

**这是一个"避开"信号，不是一个"排序"信号。**

| 用法 | 可行 | 理由 |
| --- | --- | --- |
| 用作全池排序因子 | **不可行** | 95% 的股票取值为 0，无法区分 |
| 用作**排除规则**（建仓前剔除 20 日内有解禁的） | **可行** | 5.1% 的股票里，解禁带来的后续收益显著更差 |
| 用作**风控覆盖层**（已在持仓里、临近解禁的减仓） | **可行** | 同上，且方向明确 |

全截面 IC 只有 −0.0133（t −1.94），**低于门槛**——这正好说明它不是排序因子：
它的信息集中在 5% 的子样本里，摊到全池就被稀释。

## 4. 为什么这个信号比前面 20 个可信

| 特征 | 价格特征 | 解禁 |
| --- | --- | --- |
| 方向来源 | 数据挖出来的 | **机制决定的**（供给冲击） |
| 是否事后挑符号 | 20 个全为负，符号可疑 | 事前就写定负号 |
| 是否与其他因子共线 | 互为衍生 | **与价格无关** |
| 信息何时可得 | 价格本身就是滞后量 | **解禁日在数年前就定了** |

**它是本次项目里唯一一个"机制先于数据"的信号。**

## 5. 不能主张的

1. **不是可交易策略。** 5.1% 覆盖率意味着单靠它建不出一个组合；它只能做排除或覆盖层。
2. **没有扣成本。** 这是 IC，不是净收益。把它变成"避开"规则的收益要单独测。
3. **没有做多空对称检验。** 解禁可能只是"坏消息的代理"（解禁多的公司本来基本面就弱），
   需要与同期基本面变量做条件检验才能排除。
4. **样本外只到 2024。** 2019-2024 全程都用于测 IC，没有留独立窗口。
5. **这是第 22 次检验**（20 个价格特征 + E1 + 特征筛选之后）。门槛虽然定在 0.031，
   但多重检验下 t = −5.26 仍应打折看待——**它比 2.5 强得多，但不是一个"发现"。**

## 6. 下一步

按顺序还剩两个源：业绩预告（第二位）、资金流（第三位）。

解禁这条本身值得做一件具体的事：**测一次"避开解禁"的净效果**——
在同一本 top 30 的等权书上，加一条"建仓前剔除 20 日内解禁"的规则，看净收益与回撤的变化。
那是从 IC 走到可执行的第一步，且不需要新数据。
