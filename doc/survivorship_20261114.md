# 幸存者偏差：本地面板根本测不了，只能给上界

日期：2026-11-14。工具 `tools/survivorship.py`，产物 `reports/runs/survivorship/`。
样本：`data/clean/panel_full`，5,056 只，2017-01-03 ~ 2024-12-31；窗口 2019-01-01 ~ 2024-12-31。

## 0. 结论

1. **本地面板看不见退市**：5,056 只里只有 **3 只**在 2024-12-31 之前停止报价。它是"建库时仍在上市"的快照，
   不是时点宇宙。**用这份数据做任何"幸存者偏差修正"都是自欺。**
2. **交易所口径**：2017-2024 年两市共退市 **213 只**（上交所 80、深交所 133）。
3. **上界**：等权宇宙年化被高估 **0.54 ~ 0.78pp**（按退市残值 0%/20%/50% 三档），
   相对于 5,000+ 只的基数，**退市数量太少，这一项不是主要误差**。
4. **它在哪里会咬人、在哪里不会**：
   - **不会**咬 E1 的判定：那是**同一个池子内**的两条腿之差（−0.78pp），两条腿共享同一份偏差；
   - **不会**咬方案的 +5.3%：那是四只 ETF 的 CPPI，**不碰股票池**；
   - **会**咬"298 只池子年化 +18.4%"这种**绝对**数字，以及任何以池子为基准的绝对收益主张。

**更正我先前的说法**：我说过"把 +5.3% 变成带误差条的数字"——这是错的。方案层的收益来自 ETF 价格，
与股票池的偏差无关。真正需要加误差条的是**股票池的绝对收益**，不是方案。

## 1. 面板能看见什么

| 检查 | 结果 | 含义 |
| --- | ---: | --- |
| 代码数 | 5,056 | 建库时的在册股票 |
| 到 2024-12-31 仍在报价 | **5,053** | 99.94% |
| 提前停牌（>20 个交易日） | **3** | 即面板里几乎**没有退市样本** |
| 窗口内新上市 | 2,368 | 入场端是时点的，退出端不是 |

面板的入场是时点的（IPO 才出现），**退出端缺失**：真实退市的股票在面板里干脆不存在。
所以它只能回答"现在还活着的股票当年什么样"。

## 3. 上界怎么算，结果是多少

设宇宙有 `N` 只，漏掉 `d` 只退市股；幸存者在窗口内的累计倍数是 `M`（2019-2024 的等权买入持有是 **3.06 倍**），
退市股的期末残值是 `r`。则真实等权倍数 ≈ `((N−d)·M + d·r) / N`，年化高估 = 两者年化之差。

| 退市股按残值 | 等权宇宙年化高估 |
| ---: | ---: |
| 0%（归零） | **0.78pp** |
| 20%（−80%） | 0.68pp |
| 50%（−50%） | 0.54pp |

**这个量级说明：在 5,000 只的宇宙里，退市不是误差的主要来源。** 主要误差来自**池子的构造**（见下）。

## 4. 池子选得比全市场好多少：这才是大的数

同窗口、同口径（2019-01-01 ~ 2024-12-31）：

| 宇宙 | 买入持有 | 每日再平衡 |
| --- | ---: | ---: |
| 全市场 5,056 只 | **+8.89%/年** | +12.76%/年 |
| 研究池 298 只 | **+18.39%/年** | +22.65%/年 |
| 差 | **≈ +9.5pp/年** | ≈ +9.9pp/年 |

**这个 9.5pp 才是需要解释的数**，而它**不是**幸存者偏差——上界只有 0.8pp。它是三样东西的混合：
流动性/规模溢价、风格暴露、以及**按 2026 年存续选池**带来的选择效应。用本地数据**无法把三者拆开**，
因为拆它需要的正是退市股的完整价格历史，而面板里没有。

顺带说明两个口径差异，避免以后再混：

- **买入持有 vs 每日再平衡差 3.9pp（全市场）/4.3pp（池子）**，这是再平衡溢价（≈σ²/2），不是收益能力；
  任何"池子 +22.65%"与"方案基准 +17.10%"的对比都是错的口径（前者日频再平衡，后者买入持有）。
- `plan_backtest` 里的同池等权是 **+17.10%**，本文的买入持有口径是 **+18.39%**，差 1.3pp 来自起点与取价细节，
  两者都是买入持有，属于同一量级，可以互相印证。

## 5. 该怎么用这些数字

- 对外说"研究池 2019-2024 等权 +18.4%/年"时，**必须同时说**：它比全市场等权高约 9.5pp，
  其中至多 0.8pp 能归给幸存者偏差，其余**无法归因**。
- 任何"策略跑赢同池等权"的结论（例如 E1 的 −0.78pp）**不需要**加幸存者偏差的误差条：两条腿同池。
- 方案层的 +5.3% **不涉及**股票池，不受本文影响。

## 6. 若要把这件事做实，需要什么

1. 退市股的完整日线（现在没有）：没有它就只能给上界，不能给修正；
2. 或改用**指数**做基准（中证全指、国证2000 等），指数编制本身处理了退市与新股，
   这是更省事、也更诚实的路——`equal_weight_crosscheck_20261108.md` 已经证明过这一点。
