# 本地研究工作台运行说明

更新日期：2026-09-25。首版前后端已实现并启动，设计提交为 `039e04c`。设计契约见 [工作台设计](frontend_workbench_design.md)，实现进度和最新验收见 [实施进度](implementation_plan.md)。

## 1. 启动与依赖

从仓库根目录执行，后端及任务工作进程均使用启动服务的 Python 解释器。当前运行环境为 Conda `Graduate`。

```powershell
conda activate Graduate
python -m pip install -r requirements-web.txt
npm --prefix web ci
npm --prefix web run build
python -B -m src.web.serve --port 8765
```

正常情况下打开 `http://127.0.0.1:8765`。端口被占用时依次尝试后续 19 个端口，以终端打印的实际地址为准。页面与 API 同源，只监听本机，不提供公网/局域网访问。

当前机器已完成安装与构建，服务正在后台运行；无需为了查看页面重复启动。`web/dist`、`node_modules` 不纳入 Git，其他机器需先构建静态资源。源码开发可使用 Vite，但最终验收和日常使用采用后端托管的已构建页面。

前端版本由 `web/package-lock.json` 固定：React、TypeScript、Vite、ECharts、Lucide 与 Playwright。后端新增 FastAPI/Uvicorn，研究依赖仍复用原清单。本次只安装软件依赖，没有下载市场行情。原有 SHAP/slicer 环境冲突不由 Web 功能自动调整。

## 2. 页面与已实现流程

| 页面 | 首版功能 |
| --- | --- |
| 训练工作台 | 查看任务及历史实验；选择数据版本/股票，配置步数、种子、窗口、rollout、batch、epochs、学习率与验证频率；检查或启动训练 |
| 数据管理 | 查看版本和股票质量；选择股票及训练/验证/研究日期，从本地原始文件构建新版本 |
| 模型库 | 查看已有可信 checkpoint、搜索、修改显示名称、核验文件哈希、转入回测/预测、显式迁移股票池 |
| 回测评估 | 验证回测、显式冻结测试、历史曲线与指标、按日期查订单/持仓、导出报告和明细 |
| 动作预测 | 指定模型、历史日期、全现金/手工/已存预测账户，生成目标权重和买卖意图，筛选关注股票并导出 JSON |
| 任务记录 | 查看排队/运行/成功/失败/取消状态、训练曲线、验证结果、日志、配置快照、真实参数更新审计与产物 |
| 联网行情 | 显式历史/报价采集、新日线研究绑定与租约监控；真实供应商可用性及账户适配仍受限，见 [联网说明](online_market_runbook.md) |

页面的“检查配置”不更新模型参数；“开始训练”才会产生真实优化器更新。所有模型和报告自动保存，不依赖浏览器下载才能保留。每次任务使用独立 ID 与目录，成功版本不覆盖。

初始 298 股与轻量 32 股配置均可选择。更改训练股票不会偷偷重拟合原版本的 scaler；若修改日期划分或拟合股票，需要构建新版本。构建表单中所选股票同时作为新数据版本与 scaler 拟合股票池，现有版本不受影响。

当前 Web 表单继承已有资金、费用及其余 PPO 默认配置，共享 MLP 固定 128/64，CPU 单线程。未提供所有 CLI 参数的编辑器，也不允许任意命令或文件路径输入。

## 3. 训练、监控与停止

工作台保存请求配置，使用 `Graduate` 中同一个解释器启动独立 worker。训练、数据构建、回测、预测等研究任务共用一个持久执行槽；新增历史下载和报价各有一个受控槽并共享网络限速。重复请求通过幂等键去重，多服务实例通过 SQLite 事务认领队列，避免重复执行。

训练详情通过 SSE 观察阶段、步数、价值损失、KL、裁剪比例及验证记录。原始 SB3 日志仍可查看/下载，任务完成后展示参数变化、优化器更新和保存加载审计。网络断开后重新连接，刷新页面不会创建第二个任务。

“请求停止”是协作取消，不是暂停。排队任务立即取消；运行中的任务在安全边界抛出取消信号，跳过后续最终评估与保存。只能保留之前已经完整保存的 checkpoint，不承诺保存正在优化的状态，也不能精确续训。构建期间只发布完成版本，取消留下的 `.building_*` 目录不会登记为可训练版本。

异常退出不自动重训：工作进程心跳和结果文件用于恢复状态；无法确认存活的任务标记中断。关闭服务时对自己拥有的工作进程请求停止，超时才终止该进程，不操作其他 Python 进程。

## 4. 模型与冻结测试

模型目录只扫描本仓库受管运行目录，要求 `model.zip` 与 `metadata.json` 完整且哈希一致。初始化模型不能作为正式评估候选；迁移模型明确显示来源步数与优化器重置状态。

模型名称只写入工作台数据库，不修改权重或原始元数据。普通推理/回测仍执行数据、特征顺序、股票池、窗口、资金和成本契约校验。不能从页面绕过模型不兼容。

验证回测默认与六条基线一起运行。最终测试必须先成功冻结验证选出的模型，再明确选择冻结记录并确认测试曝光；不会自动接着训练运行最终测试。历史报告可以直接查看。

新增 Web 和运行时模块改变了 `src` 源码哈希，因此早期冻结文件可能拒绝在当前源码下重跑。不得修改旧冻结记录来消除报错，也不得把重复回测当成首次样本外评价。工作台记录历史测试报告、测试请求和测试日期的动作查看；它不是不可篡改审计系统，也不能自动识别所有外部数据谱系。

本轮浏览器验收只运行验证集回测，冻结记录验证到创建成功，不额外执行或调参最终测试集。

## 5. 动作预测与账户

预测使用完整模型股票池、截至所选日期的特征与账户状态。勾选一只“关注股票”仅改变展示筛选，后台仍返回完整组合的动作。真正改变模型股票池需从模型库显式迁移。

- **全现金假设账户**：按模型配置的初始资金，没有股票持仓。
- **手工研究账户**：录入现金、股票总股数与可卖股数；目前表单支持一笔应收分红。
- **已存预测账户**：复用以前保存的只读预测输入，保留其日期与全部应收条目；不能把它当作已经执行过订单的账户。

手工表单不能在未提示时截断多笔应收：含多笔应收的已存快照可以完整复用，但转为当前单笔手工编辑模式会被阻止。快照不是完整交易账本，不能用于精确还原成本、锁定日程或恢复训练。

打开历史预测结果时，上方日期、账户和关注股票恢复为对应快照；修改输入会清除旧结果，避免把上次计算误认为新输入的结果。结果另提供代码筛选，不重新计算模型。

页面同时展示持仓/可卖股数、市场买卖状态、当前/目标权重和收盘参考调整金额。市场允许卖出不代表当前可卖股数大于零；下一日能否成交仍由执行时的约束决定。价格为 HFQ 研究口径，不输出真实报单或确定成交承诺。

## 6. 文件位置与可复现性

| 位置 | 内容 |
| --- | --- |
| `.workbench/state.sqlite3` | 任务、名称标签和测试查看记录 |
| `.workbench/jobs/<job_id>/` | 不可变请求、配置快照、追加事件、日志、心跳、停止标记和最终状态 |
| `reports/runs/workbench/<job_id>/` | 训练 checkpoint、审计、回测报告、预测快照或冻结记录 |
| `data/clean/<new_version>/` | 新建数据版本及其研究配置 |
| `web/test-results/` | 本轮浏览器测试 JSON、截图，失败时保留 trace |

`.workbench`、运行产物、前端构建与依赖均被 Git 忽略。备份模型时需同时保留引用的配置/数据版本和工作台任务快照，不能只拷贝 ZIP。数据库可以重新建立索引，但不要随意删除 `.workbench/jobs` 中模型仍引用的研究配置或股票名单。

任务事件时间存为 UTC，界面按本机时区显示；交易日期始终是数据表日期，不做隐式时区换日。

## 7. 测试方式

```powershell
python -B -m pytest -q -p no:cacheprovider
npm --prefix web run build
npm --prefix web run test:e2e
```

浏览器测试要求服务已启动、本机 Chrome 可用；默认访问 8765，其他端口可通过 `WORKBENCH_URL` 指定。测试会真正创建小预算训练、验证回测、预测及两只股票的新数据版本，所有产物留在本地独立目录，不覆盖原研究产物。

Python 测试仍默认排除外部网络。Windows 的 asyncio 内部 wakeup pipe 使用本机回环连接，仅标记 `local_ipc` 的 API 测试允许数值 loopback 地址，外部地址和一般 `create_connection` 仍被阻止。

最新测试数量、浏览器截图与问题修复记录见 [工作台验收报告](reports/workbench_acceptance_20260925.md)。浏览器功能验收不用于选择更盈利的策略。

## 8. 已知边界与后续优化

- 本地单用户版本，不提供多用户权限体系、远程部署或陌生模型上传。
- 默认研究流程只用本地数据；单独联网工作区需显式许可，监控需有效租约，不接实盘。已有金融数据与撮合限制继续适用。
- 暂无精确暂停/续训、任意存储根目录选择、模型备注/收藏或全部超参数可视化编辑。
- 回测采用数据版本固定的验证/测试区间与模型成本契约；任意区间和成本压力研究仍需独立设计。
- 手工账户暂为单笔应收编辑，已有多笔快照可完整复用，不能导入完整真实交易账本。
- 长任务日志当前仍需读取本地事件文件，超长实验可继续优化为字节游标、分段归档和更细的分页。
- 首屏脚本已拆分，图表按需加载；图表分块约 512 KB，构建仍给出超过 500 KB 的体积提示，不影响构建成功，未通过提高告警阈值隐藏它。
- 继续扩展研究功能前，应保持 API/CLI 一致性、因果性和冻结测试纪律，不能为了让界面“成功”而放宽核心契约。
