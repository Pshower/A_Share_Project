# 调仓控制器多步收益归因研究协议

日期：2026-10-15。训练前登记，正式prepare前核对实现与协议一致并冻结，结果另写报告。

## 依据与假设

margin控制实验完成六trial、49,152 RL步：较弱初始化增加探索与确定性变化，但主要学成少调仓、更多现金，未产生跨开发折增量，因此未授权确认。

此前margin2确认的唯一分支在6月2日跳过调仓，当日净收益多0.744951个百分点，期末却少5.654236个百分点。该例说明单日优势不能替代持续持仓评价，但不证明GAE是唯一根因，也不证明更长归因必然改善。

当前每日奖励本来就经PPO多步学习，不能称只优化次日。本轮改变优势估计的trace长度，不给Actor未来数据，不换股票选择、数量或交易执行。

## 因子与共同设置

以2×2比较两因素，除此之外不改实现：

| 奖励 | GAE lambda=0.95 | GAE lambda=1.0 |
| --- | --- | --- |
| log_net | 原配置控制 | 较长归因 |
| relative_log | 原相对奖励控制 | 相对奖励与较长归因 |

gamma始终0.995。GAE历史TD误差的权重衰减分别为(0.995×0.95)^k和0.995^k；无限序列近似尺度为18.3与200步，而非保证真实收益的预测期限。实际受240步episode、512步rollout与终止/时间截断影响，沿用标准SB3 bootstrap，优势不跨reset。lambda0.95不等于只看18天，TD误差仍含对更远未来的V(next)；lambda1也不是直接完整240步真回报。较长trace减少中间V误差的影响，但可能提高目标方差和样本相关性。

继续使用129维因果输入、线性categorical Actor、64/64 Critic、12,805参数、可训练calendar_margin2一次初始化、HOLD/REBALANCE两个macro动作。所有四cell同fold/seed的初始Actor及Critic应逐tensor一致，确定性初策略精确等于未修改20日动量。

log_net=Agent净NAV日对数收益；relative_log减去独立20日动量账户的净NAV日对数收益。两账户同实际初始现金/股数/可卖/锁定/应收，之后独立执行、扣费和推进。两奖励方法共用完整状态及基线算力，不将相对reward冒充净ROI。在参考账户与等长horizon独立于Agent动作的理想条件下，减去参考折扣收益不改变最优折扣log目标，主要检验数值方差与Critic建模；相关性不足时相对奖励方差也可能增加。

数据、scaler、初始账户与48种分层、资本/Broker/冻结/T1/lot/经济门槛/K20均继承[原协议](ppo_timing_protocol_20261014.md)。保留CPU单线程、LR3e-4、n_steps512、batch128、epochs5、clip.2、targetKL.03、ent0、vf.5、gradclip.5。不同时换Actor、提高LR或增加第三动作。

不下载新数据，不改变原96份src或已签实验，保持同源新浪300股20特征。新编排放独立tools文件，显式登记runner/测试/协议SHA及上一轮完整审计；所有真实输入和模型契约绑定，不能冒用旧样本。

## 开发筛选

2023/2024 Q2各四cell，seed42，每trial8,192日步，共八trial、65,536 Agent RL步、同量独立基线推进。只评价预算终点，不挑较早checkpoint。

lambda0.95的两控制cell必须本轮重新实际训练，并与最早同reward/fold/seed、margin2的封存结果冷读核对初始/最终tensor和完整原生数组；复现对照不额外模型前向或环境推进，旧结果不能充作本轮样本。

八trial完整封口后按最差折四账户平均净ROI基线差、两折平均差、最坏账户回撤、费用加滑点排序。完全平局优先lambda0.95，再优先log_net。只锁定一个配置，不按某账户或greedy翻转次数选优。

选中配置须两开发折各平均基线差至少0.0001（1bp），且至少一条同路径同时有确定性macro及经济账本变化，才授权确认。未准入则实际确认0，不补挑第二名，不把开发seed42局部收益叫胜出。

## 条件确认与结论

若准入，固定配置在2025/2026 Q2各自从头训练seed42/123/2026，每trial16,384步，共六trial、98,304 Agent RL步。最高十四trial、163,840步；未准入只有八trial、65,536步。独立基线、初始化/终点评价和引用控制按实际单独计数，不将计划当已执行。

最终门槛保持每确认折四账户/三seed平均净ROI胜未修改20日动量、至少2/3 seed胜出、两折平均优势至少0.5个百分点、自身初始化增量为正，最坏账户回撤不超过10%且相对基线恶化不超过2个百分点。全部条件同时成立才产生候选，不因少费用或critic loss下降晋升。

## 诊断与审计

完整保存原始macro/action logP/value/129维输入与实际PPO buffer、原始经济奖励与bootstrap后的训练奖励、每更新实际Adam/KL/GAE/return尺度、两独立原生账本、覆盖及尾段。oldV对GAE的诊断不是后拟合价值精度，更不能代替收益评价。

比较不同lambda的优势/回报目标尺度、熵与确定性日历偏离、实际成交/现金/费用和持续净值；确认较长trace是否反而增加方差或训练不稳。账本、概率、输入和CRC独立全量核对，解码器固定每chunk首末真实REBALANCE抽样并分别披露范围。所有阶段先全封口再汇总，失败也写完整报告、摘要并提交。
