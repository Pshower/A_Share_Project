## 1. 为什么做

仓库里所有市场因子此前都是 `000300`——自由流通市值加权、300 只大盘股。用它检验等权 32 只的书时，
规模与权重差被全额记进 α；补了 `000905 − 000300` 的规模因子之后 α 反而升高，说明偏差在**选了哪些股票**，
不在因子暴露。

CAPM 的市场组合是**全部可投资资产**的市值加权组合。本地从来没有这样一条序列，也从来没有按 β 排序的组合。
本文把两件事一起补齐。

## 2. 数据与市场组合

| 项 | 取值 |
| --- | --- |
| 宇宙 | 新浪 A 股全市场快照 **5,578 只**（2026-11-07），按流通市值降序 |
| 已下载 | **4,555 只**（97.1% 的流通市值），2017-01-01 ~ 2024-12-31 |
| 价格基准 | `hfq` 算收益、`unadjusted` 算市值 |
| 流通股数 | 保存的文件**没有** `outstanding_share`，由 `volume × 100 / turnover` 反推；在 600519 上得 1.2562e9，与供应商值 1.256198e9 吻合 |
| 市场组合 M | 每日 `w = 未复权价 × 流通股 / Σ`，权重滞后一日，缺报价的股票当日剔除并重新归一 |
| 无风险利率 | 年化 2%（沿用 `alpha_budget`） |

**构造校验**（对两个公开指数，同一区间）：

| 指数 | 相关 | β | 跟踪误差 | 指数年化 | M 年化 | 差 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `000300`（300 只大盘） | 0.960 | 0.918 | 5.43% | +4.81% | +8.99% | **+4.40pp** |
| `399317`（全 A 市值加权） | 0.994 | 0.909 | 2.74% | +8.50% | +8.99% | **+0.71pp** |

两件事同时成立：**相关 0.96–0.99 说明权重对**，但**与 000300 差 4.4 个点说明相关不能证明等价**。
与全 A 指数只剩 **0.71pp**，那部分来自"只持有现存股票、且按当前市值排序"——即选样偏差。
随覆盖率从 57.6% 升到 97.1%，这个差从 **+3.38pp 降到 +0.71pp**。

**跟踪误差的走向是构造正确的最强证据**：

| 覆盖率 | 对 `000300` 的跟踪误差 | 对 `399317` 的跟踪误差 |
| ---: | ---: | ---: |
| 57.6%（351 只，全大盘） | 3.43% | 7.99% |
| 97.1%（4,555 只，全市场） | **5.43%** | **2.74%** |

**补齐小盘之后，组合离全 A 指数更近（7.99% → 2.74%）、离 300 只大盘指数更远（3.43% → 5.43%）。**
如果权重或价格基准算错了，这两条不会朝相反方向各走各的。

## 3. 机件验收

结论可信的前提是估计量先通过对照。

| 对照 | 构造 | 结果 |
| --- | --- | --- |
| 正对照 | 收益 = β × 市场 + 噪声 | 不拒绝 CAPM，γ1 与溢价一致 |
| 负对照 | 斜率植为 0 | 拒绝 CAPM，`gap_t < −2` |
| 置换对照 | 每个区间内把 β 在股票间随机重排 30 次 | 真实 γ1 +0.0035，重排均值 ≈ 0、标准差 **0.0007**，**p = 0.000**（观测值 5 倍） |
| 重建一致性 | 同一批名字从不同面板取出分别测 | γ1 复现（差 ≤0.0004）；γ0 不复现，其全区间只跨约 1 个标准误 |
| 规模 | 5,600 只 × 2,086 日跑完全套检查 | **122 秒** |

**置换对照是最重要的一条**：它把"β 与收益的配对"与"标签噪声"分开。p = 0.000 说明配对真实存在，
所以后面所有"不显著"都是**精度问题，不是没有关系**。

## 4. 结果

### 4.1 T1：十分位 α 随 β 单调下降，但没有一组显著

| 十分位 | 平均 β | α（对市场，每 20 日） | α 的 t |
| ---: | ---: | ---: | ---: |
| D1（最低 β） | 0.323 | **+0.0044** | +0.79 |
| D4 | 0.936 | +0.0077 | +1.52 |
| D5 | 1.043 | +0.0074 | +1.47 |
| D9 | 1.584 | +0.0011 | +0.20 |
| D10（最高 β） | 1.974 | **−0.0034** | **−0.52** |
| 极差 D10−D1 | | **−0.0078** | |

**方向与 CAPM 相反**：β 越高，α 越低，最高一组已经是负的。这个模式在覆盖率各点上大体单调
（极差 −0.0004 → −0.0049 → −0.0071 → −0.0086 → −0.0077 → −0.0074 → −0.0078）。
**但没有一组的 α 显著**（D10 的 t 只有 −0.52），所以 T1 **不构成拒绝**。

### 4.2 T2：斜率与截距

| 指标 | 值 |
| --- | ---: |
| SML 斜率 γ1（均值） | **+0.0035** |
| γ1 的 t | **+0.71** |
| 同期市场区间超额 | +0.0074 |
| **γ1 − 市场超额（t）** | **−0.0040（−0.82）** |
| 截距 γ0（t） | +0.0085（**+1.29**） |

CAPM 的两条限制是"斜率等于市场溢价"和"截距为零"。两条**都没有被拒绝**，但也都远没有被确认——
斜率的读数已经降到市场溢价的**一半以下**。

### 4.3 个股 α 普查

| 项 | 值 |
| --- | ---: |
| 股票数 | 4,500 |
| \|t\| ≥ 2 的比例 | **0.69%**（显著为正 0.49%、为负 0.20%，低于 5% 的噪声水平） |
| α 中位数（年化） | **+4.14%** |
| α 的 t 中位数 | **+0.23** |
| β 中位数 | 1.145 |
| α 与 β 的相关 | +0.047 |

个股 α 的标准误约 **15%/年**，所以 +4.1% 的 α 的 t 只有 0.23。**α 在点估计里，在检验里看不见。**
显著比例 0.69% 甚至**低于** 5% 的噪声预期——不是"没有 α"，是"没有可辨识的 α"。

### 4.4 T3：市值加权 vs 1/N

| 组合 | 年化收益 | 年化波动 | 超额 Sharpe |
| --- | ---: | ---: | ---: |
| 市值加权 M（买入持有） | **+8.99%** | 18.52% | 0.378 |
| 1/N 月频（毛） | +13.70% | 23.47% | 0.498 |
| **1/N 月频（净）** | **+13.51%** | 23.47% | **0.490** |

1/N 的年化换手 **0.53 倍**、成本约 0.17%/年。**净差 −4.52pp/年。**

分段看（同一面板、同一口径）：

| 区间 | 区间数 | γ1 | γ1 的 t | γ1−溢价（t） | M 年化 | 1/N 净 | 差 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 2019-2021 | 37 | +0.0026 | 0.39 | **−1.90** | +20.93% | +25.42% | **−4.49pp** |
| 2022-2024 | 36 | +0.0044 | 0.65 | +0.91 | **−2.14%** | +1.81% | **−3.95pp** |

三件事：
1. **前半段的斜率与溢价之差已经到 t −1.90**，离协议拒绝线 −2 只差一点。**合并样本的 −0.82 是两段（−1.90 与 +0.91）互相抵消的结果**，掩盖了这个结构。
2. **等权的优势在两段里几乎相同**（4.49 对 3.95pp）。早先在 81.9% 覆盖上看到的"差三倍"（−12.89 对 −4.13）是**小宇宙的产物**，已经收窄到基本一致。
3. 市场组合收益的 regime 依赖仍然极端：**+20.93%/年 对 −2.14%/年。**

### 4.5 覆盖率收敛

| 覆盖率 | 股票数 | γ1 | t | γ0（t） | γ1−溢价（t） | M 对 1/N 净 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 57.6% | 351 | +0.0153 | 2.23 | — | +0.90 | −10.49pp |
| 76.0% | 928 | +0.0098 | 1.48 | +0.0044（0.85） | +0.17 | −9.34pp |
| 81.9% | 1,320 | +0.0079 | 1.25 | +0.0059（1.14） | −0.07 | −8.30pp |
| 87.4% | 1,868 | +0.0064 | 1.09 | +0.0070（1.30） | −0.28 | −7.33pp |
| 92.2% | 2,601 | +0.0049 | 0.88 | +0.0081（1.40） | −0.52 | −6.36pp |
| 94.0% | 2,966 | +0.0046 | 0.87 | +0.0081（1.36） | −0.57 | −5.94pp |
| 96.2% | 3,545 | +0.0040 | 0.79 | +0.0083（1.31） | −0.70 | −5.05pp |
| **97.1%** | **3,872** | **+0.0035** | **0.71** | **+0.0085（1.29）** | **−0.82** | **−4.52pp** |

**覆盖率越高：斜率越低、与溢价的差越负、等权的优势越小。** 意味着 **CAPM 在越宽的横截面上越不成立**——
因为占比越来越大的是小盘股，而它们的收益不由 β 解释。早先 57.6% 时"β 被定价（t 2.23）"的读数是大盘宇宙的产物。

**两个曾经的判断都被后续点推翻过**，写在这里作为方法提醒：
- 94.0% 时 γ1 相对 92.2% 只降 0.0003，我写过"趋势在饱和"；96.2% 又降 0.0006。
- 更早的"宽度单调上升"也是同一个错误：**用单步变化判断趋势**。

## 5. 判据判定

协议的主判据是 T2 的斜率。按预登记的四级顺序：

1. 差值显著为负（t ≤ −2）？**否**（合并样本 −0.82）
2. 差值 \|t\| < 2 且 γ1 显著（t ≥ 2）？**否**（γ1 的 t 0.71）
3. 差值 \|t\| < 2 但 γ1 不显著 → **命中**

**判定：无法区分。** 斜率的符号与量级对，精度不足以认证。

**但分段给出了一个更强的信号**：2019-2021 单看，差值是 **t −1.90**，已经在拒绝线边上。
合并样本之所以"无法区分"，是因为后半段（+0.91）把前半段的负偏差抵消了。
**协议判的是合并样本，所以判定不变**；但这个结构必须写出来，否则"无法区分"会被读成"两段都没有信号"。

辅判据：
- **T1**：十分位 α 随 β 下降（极差 −0.0078），**方向与 CAPM 相反但不显著**（D10 的 t −0.52）。
- **个股普查**：显著比例 0.69%，低于噪声水平，无个体 α 可辨识。
- **T3**：市值加权被等权碾压 **4.52pp/年**。

## 6. 这个样本能测出什么

所有"不显著"都能还原成一个具体的分辨率。由各统计量的 t 值反推标准误：

| 统计量 | 点估计 | 标准误 | t = 2 需要 |
| --- | ---: | ---: | ---: |
| SML 斜率 γ1 | +0.0035 | **0.0048 / 期** | 与溢价差 ≥ **0.010 / 期 ≈ 11.7%/年** |
| 截距 γ0 | +0.0085 | **0.0066 / 期** | \|γ0\| ≥ **0.013 / 期 ≈ 16.0%/年** |
| D1 的 α | +0.0044 | 0.0056 / 期 | \|α\| ≥ 0.011 / 期 |
| D10 的 α | −0.0034 | 0.0065 / 期 | \|α\| ≥ 0.013 / 期 |
| 个股 α | +4.1%/年 | **约 15%/年** | \|α\| ≥ 30%/年 |

**任何小于约 12%/年 的斜率偏差、小于约 16%/年 的零 β 超额，这个样本都测不出来。**
这不是数据不够干净，是 72 个不重叠区间的算术上限。

反过来，**这个样本能确定的是什么**——都是不需要小标准误的东西：

| 结论 | 为什么有功效 |
| --- | --- |
| β 与收益的配对真实存在 | 置换对照 p = 0.000，观测值是重排标准差的 **5 倍** |
| 市场组合构造正确 | 与 `399317` 相关 **0.994**、β 0.909、跟踪误差 2.74% |
| 1/N 胜市值加权 **4.52pp/年** | 这是两条**组合收益序列之差**，不是截面系数 |
| 降级到 1/N 的成本算术 | 换手 0.53 倍、成本 0.17%/年，直接可算 |

## 7. 不能主张的东西

1. **不是"CAPM 被证伪"**。合并样本所有不显著都源于精度。**但分段里前半段的 t −1.90 是真实的信号，不是噪声**——只是协议判的是合并样本。
2. **不是"β 不重要"**。置换对照 p = 0.000 说明配对真实；γ1 点估计始终为正。
3. **不是"等权一定赢 4.52pp"**。分段是 −4.49 与 −3.95pp，且这个数还会随覆盖率再动。
4. **不是"全市场"**。宇宙只含**现存**股票，退市的拿不到；且权重按**当前**市值排序，等于把后来的赢家提前放进历史。
   对 `399317` 的 0.71pp 差额是这个偏差的度量，不是它的修正。
5. **不是样本外**。正式样本 2019-2024 属于已花的 V 段；本检验是结构性描述，不构成部署资格。
